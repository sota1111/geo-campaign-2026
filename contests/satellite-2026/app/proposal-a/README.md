# 提案A デモ: 衛星で絞り、地中レーダで確かめる 路面下リスクの二段階調査

衛星データ活用アワード2026–2027 提案Aの流れを、地図上で一通り体験するための最小限の静的Webアプリです。初期応募にプロトタイプは必須ではなく、提案の実現性を説明するための補助です。立場は「衛星は空洞を直接見つけず、地上調査の投入先を選ぶ」。

**衛星・道路・下水道台帳は実データ（豊中市北東部）です。地中レーダの結果だけは架空（乱数のシミュレーション）です。** 画面右上のバッジ、パネル上部、出典モーダルに同じ旨を表示しています。

## 衛星データと提案書の関係（要確認事項）
- 提案書（`submission/proposal-A.md`）は **Sentinel-1 の解析を主に想定（ALOS-4 は比較検証）**。このデモは、公開済みの**国土地理院の成果（だいち2号・4号）で代用**しています。Sentinel-1 の解析結果ではありません（画面にも明記）。
- 使った成果: 国土地理院「衛星SAR地盤変動測量成果」の変位速度（準上下方向 `qu`、2014-08〜2025-11 の観測、2026-03-31 公開分）の地理院タイル。ALOS-2/4（Lバンド）、約90m、凡例 -3〜+3 cm/年 を16階級（**1階級 3.75 mm/年幅**）。
- 値は**階級の幅でしか言えません**（階級の中央値で計算するが、小数の精度はない）。国土地理院は「数百m四方より狭い変動の把握は困難」としており、生活道路単位の値ではありません。
- 利用条件: 地理院コンテンツ利用規約。クレジット『解析：国土地理院 原初データ所有：JAXA』を画面に表示し、加工（色→階級→区画集計）した旨を明記。**基本測量成果の複製・使用の承認が要る場合がある（SAR 解析結果は個別条件）ため、静的な派生データ（`data/toyonaka.json` の区画の階級）の公開可否は未確認。憲兵の確認か地理院への問合せが要る。** **地理院への確認が済むまで、このデモは公開・デプロイ・応募への添付をしない（ローカル実行とスクリーンショットでの説明に留める）。**

## 体験できる流れ（既存の流れのまま）
1. **絞る**: 区画（約90m）の衛星の階級と、下水道台帳の竣工年の古さを重み付きで足して道路区間に点数を付ける。重みはスライダーで動かせる。**既定は台帳中心（衛星の重み 10%）で、利用者が上げて試す形**。画面に「台帳のみの上位20区間に無かった区間が上位20に入った数」「1位と同点の区間数」を出し、衛星で絞れない様子が分かる。
2. **選ぶ**: 走らせられる延長（仮の値）の範囲で、未調査の生活道路から地中レーダの投入先を選ぶ。上位から自動選定、または地図で区間をタップして手で調整。予算超過だと次へ進めない。
3. **戻す**: 選んだ区間の走査結果（**架空**）を見て、調査済みの全結果（**架空**）に対し重み（0〜100%）ごとの当たりやすさ（AUC）を比べ、最大の重みに更新して第2回へ。空洞あり／なしが各3件未満なら「データ不足」として重みを変えない。

**この地区は衛星でほとんど絞れません**。区画の階級は2種類だけ（-3.75〜0 mm/年が 325 区画、0〜+3.75 mm/年が 597 区画。道路のある区画のみ）で、デモの正規化では衛星の点数は最大 0.23。重みを上げると順位は「どちらの階級か」で二分され同点が増える。**この地区の2階級の差は階級幅（3.75 mm/年）以内で、沈下の兆候とは言えない**（画面にも同じ一文を出している。地図でも2階級は同じ扱いで、斜線の有無で区別するだけ）。**絞れない地域では、台帳（竣工年）と過去の調査の重みが前に出る**（第3段階の較正では、通し確認で衛星の重みが 20% に下がった。架空の結果に対する値）。

### 取得した件数（`data/toyonaka.json` の `stats`）
- 範囲: 経度 135.470〜135.510、緯度 34.795〜34.825（豊中市北東部、千里地区周辺。約 3.6 km × 3.3 km）。**この範囲は、豊中市周辺（経度135.43〜135.51、緯度34.74〜34.83）を調べたうえで、階級が複数に分かれて見えた所**として選んだ。調べた範囲のタイル画素（約576万）の約 91% は 0〜+3.75 mm/年の1階級（-3.75〜0 が 5.9%、+3.75〜7.5 が 2.6%）。他の地区の下水道台帳・衛星の組合せは試していない。
- 衛星の区画: 範囲内 1,517（階級 -3.75〜0: 508、0〜+3.75: 1,009）。道路のある区画は 922（325 / 597）。
- OSM 道路: 1,533 本 → 区間 5,136（8m 未満 154 を除く）。豊中市の管渠が 100m 以内にない 1,451（市外・台帳範囲外）と衛星の区画が無い 113 を除いた **3,418 区間**（幹線 998、生活道路 2,233、台帳なし 187。延長はそれぞれ 69.7 / 107.7 / 10.3 km）。
- 突き合わせ率: 3,418 区間のうち 15m 以内に紐づいた区間は 3,016（**88.2%**）。しきい値 10m で 85.3%、25m で 92.7%。紐づかない 402 区間の内訳は生活道路 187＋幹線 215。生活道路の 187 は「台帳なし」として点数の対象外（地図に点線で表示。理由は未特定: 私道・未整備・位置のずれ等）、幹線 215 は台帳の有無にかかわらず「調査済み（架空）」。※ 3,016 は幹線を含む。
- 竣工年: 生活道路 2,233 区間のうち不明 78（3.5%）。判明分は 1962〜2025 年。不明は「不明」と表示し、古さは中立の 0.5 で扱う（デモ上の約束）。
- 管径: 生活道路 2,233 区間のうち 2,231 区間に付与（詳細表示のみ。点数には使わない）。
- JSON サイズ: 約 870 KB（区画のリングは緯度経度6桁）。生の大きなファイル（タイル、ZIP、シェープ、OSM JSON）は `tools/cache/`（git 管理外）。

## データの再生成
```
cd contests/satellite-2026/app/proposal-a
python3 tools/fetch_insar.py            # GSI タイル（z15、約90枚、1秒間隔、GET のみ）と凡例 -> tools/cache/
python3 tools/fetch_osm.py              # Overpass（GET、UA ヘッダ必須）-> tools/cache/osm.json
# 豊中市下水道: https://data.bodik.jp/dataset/272035_gesuido の gesui.zip を tools/cache/gesui.zip に置き、tools/cache/sewer/ に展開
python3 -I tools/build_data.py > data/toyonaka.json   # 統計は標準エラーに出る
```
依存: Python 3（numpy, Pillow, pyproj）。シェープは `tools/shp.py`（外部ライブラリ不要）で読む。`tools/generate_sample.mjs` と `data/sample.json` は旧版（架空の街「サンプル市」）で、**統合ダッシュボードの sat-a（`contests/dashboard`）がまだ読んでいる**ため残している。

## 限界
- 点数の正規化（-8mm/年で1、60年で1）、重みの探索、AUC・除外精度の表示は、デモのための単純な設定。AUC などは架空の空洞結果に対する計算で、実際の精度・効果・費用を示さない。
- 衛星の階級は 3.75 mm/年幅で、この地区ではほぼ全域が -3.75〜+3.75 mm/年の範囲。測定誤差の範囲を超える沈下の検出は示していない。「-3.75〜0」の区画は沈下の兆候ではなく、変動がほぼない範囲のうちの負側。
- 管渠の位置は道路の中心線の下とは限らない。竣工年は「近くの管渠の台帳の竣工日」であり、実際にその道路の下にある管の竣工年とは限らない。
- 豊中市以外・他の沈下地域での検証はしていない（強い沈下のある地域の下水道台帳の公開データは確認できていない）。
- 衛星の解析（InSAR処理）とレーダ解析は未実装。「管内カメラ調査への引き継ぎ」は画面に注記するのみ。
- 底図は使っていない（外部通信なしのため）。道路と区画だけの表示。
- 画面の既定の重み（10%）と、ダッシュボード側 sat-a（旧版の架空データ、既定 50%）は別。
