# 提案A デモ: 衛星で絞り、地中レーダで確かめる 路面下リスクの二段階調査

衛星データ活用アワード2026–2027 提案Aの流れを、地図上で一通り体験するための最小限の静的Webアプリです。初期応募にプロトタイプは必須ではなく、提案の実現性を説明するための補助です。

**画面の道路・衛星指標・下水道台帳・レーダ結果はすべてサンプル（架空）データです。実在の場所・精度・効果を示しません。** 画面右上のバッジ、パネル上部、出典モーダルにも同じ旨を表示しています。

## 体験できる流れ
1. **絞る**: 区画ごとの衛星由来の地表変位の指標（サンプル値）と、下水道台帳の布設年の古さを、重み付きで足して道路区間に点数を付ける。重みはスライダーで動かせる。
2. **選ぶ**: 走らせられる延長（仮の値）の範囲で、未調査の生活道路から地中レーダ（GMS3等）の投入先を選ぶ。上位から自動選定、または地図で区間をタップして手で調整。予算超過だと次へ進めない。
3. **戻す**: 選んだ区間の走査結果（乱数シミュレーション）を見て、調査済みの全結果に対し重み（0〜100%）ごとの当たりやすさ（AUC）を比べ、最大の重みに更新して第2回へ。順位が入れ替わる。空洞あり／なしが各3件未満なら「データ不足」として重みを変えない。

## 起動方法
サーバー・APIキー・外部通信は不要です（MapLibre GL JS は `vendor/` に同梱、底図なし）。

```
cd contests/satellite-2026/app/proposal-a
python3 -m http.server 8822 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8822/
```

## テスト
```
node --test tests/logic.test.mjs          # ロジックの単体テスト（node 22）
node tests/ui_check.mjs http://127.0.0.1:8822/ screenshots   # 画面の通し確認（要 google-chrome、サーバー起動済み）
```
`ui_check.mjs` はデスクトップ幅(1366)とスマホ幅(390)で通し操作し、スクリーンショットを `screenshots/` に保存、コンソールエラー・横スクロール・予算超過時のボタン無効化などを確認します。

## データと出典（すべてサンプル）
| 項目 | 内容 | 実データか |
|---|---|---|
| 道路網・区画 | 乱数による架空の格子状の街（「サンプル市」、12×9ブロック、区画3×3）。座標は便宜上の位置 | 架空 |
| 衛星由来の指標 | 区画ごとの地表変位（mm/年, 負=沈下）を人が決めた式と乱数で生成 | 架空（Sentinel-1の解析結果ではない） |
| 台帳属性 | 布設年を乱数で付与 | 架空（実在の下水道台帳ではない） |
| 地中レーダ結果 | 乱数シミュレーション（`sim_cavity`）。過去の調査済み区間の結果も同様 | 架空（実際のGMS3結果・製品画面ではない） |

生成: `node tools/generate_sample.mjs > data/sample.json`（固定シード 20261111）。底図は架空の街のため使っていません。

ライブラリ: MapLibre GL JS 4.7.1（BSD-3-Clause。`vendor/LICENSE-maplibre.txt`）。

## 限界
- 点数の正規化（-8mm/年で1、60年で1）、重みの探索、AUC・除外精度の表示は、デモのための単純な設定。画面の数字は架空データ上の計算で、実際の精度・効果・費用を示さない。
- 衛星の解析（InSAR処理）とレーダ解析は未実装。生活道路の幅に対する衛星画素の粗さ、反射点の偏りなど、提案書が挙げる課題は実データで未検証。
- 過去の調査結果は幹線に偏って与えており、較正の母集団の偏りは扱っていない。
- 「管内カメラ調査への引き継ぎ」は画面に注記するのみで未実装。
- 実在の道路中心線（OSM、国土数値情報など）への差し替えは、`data/sample.json` と同じ形式（区間の座標・区画ID・布設年等）を用意すれば可能だが、本デモでは行っていない。

## ファイル
- `index.html` / `style.css` / `app.js`: 画面
- `logic.js`: 点数・選定・較正の純関数（画面とテストで共通）
- `data/sample.json`: サンプルデータ
- `tools/generate_sample.mjs`: サンプル生成
- `tests/`: 単体テスト・画面確認
- `screenshots/`: 画面確認のスクリーンショット
