# 提案A: 衛星で絞り、地中レーダで確かめる 路面下リスクの二段階調査（実データ版）

衛星データ活用アワード2026–2027 提案Aの流れを、地図上で一通り動かす最小限の静的Webアプリです（初期応募にプロトタイプは必須ではなく、実現性を説明する補助）。立場は「衛星は空洞を直接見つけず、地上調査の投入先を選ぶ」。

**2026-11-21 の作り直し**: 衛星・道路・下水道台帳は豊中市の実データ。**地中レーダの結果（空洞の有無）は同梱していません**（公開された位置つきの空洞・陥没の実データは見つかっていない。情報部 `reports/intel/satellite-2026-cavity-realdata-20261121.md`）。画面の既定の状態に架空のデータは出ません。
- 第3段階は、**一次審査を通った後、カナン・ジオリサーチ社の GMS3 のデータで較正する**ための受け皿です。**GMS3 のデータは手元になく、使っていません。GMS3 の出力書式は未確認**のため、次の2つの書き方の CSV のどちらでも受け取り、同じように較正します（処理はブラウザ内だけ）。
  - A. 区間ID ＋ 空洞あり/なし（`segment_id,cavity`）
  - B. 緯度・経度の点 ＋ 空洞あり/なし（`lat,lon,cavity`。20 m 以内で最も近い区間に結び付け。台帳なしの道路は除く）。見本: `data/format_sample_by_segment.csv`・`data/format_sample_by_point.csv`（書式の見本で、結果ではない）
- 「説明用デモ」（架空の結果、`data/demo_sim.json`）は**既定オフ**。オンの間は画面上部に「架空」と出し続け、切替で入れた結果・較正は初めからになる。
- 第4タブ「検証」: 実データでできる範囲（下記）。因果・精度は言わない。

## 実データでできる検証（`data/verify.json`、`tools/verify_incidents.py`）
- **国交省「道路陥没発生箇所の詳細」令和6年度（02.xlsx）**: 列は 道路管理者・路線名・地名・要因施設・大きさ。**座標はない**。地名は「市区町村＋町名＋地先」まで（丁目・番地なし）。全国 9,865 件（直轄 72／都道府県 1,169／市町村 8,624）、大阪府内 332 件、豊中市管理 50 件（下水道 38、要因未確定 10、その他 2）。ライセンスはページ個別の表示がなく国交省サイト既定（PDL1.0）で**要確認**。豊中市の陥没を区間・道路には結び付けない（町名まで）。出典: <https://www.mlit.go.jp/road/sisaku/ijikanri/r6hasseijoukyou.html>（取得 2026-11-21）。
- **豊中市の町単位の照合**: 50 件を町名で、台帳（町丁境界 e-Stat 令和2年国勢調査で町ごとに集計した竣工年の中央値）と照合。比較に使う 100 町・下水道起因 38 件。古い方の3分の1の町は 100 km あたり 5.7 件、真ん中 4.2、新しい方 1.5。順位相関 0.27、件数が出た町が古い確率 0.65（0.5 で差なし）。件数を管の延長に比例して無作為に配り直す 5,000 回で同じ以上は 0.2%／0.6%。**1年度・38件、町ごとの件数は 0〜3 件。通報・点検の濃淡、町の大きさ・人口・交通量・地盤は未調整。因果や精度は示さず、このアプリの点数（衛星を含む）の検証でもない。**
- **全国の文脈**（02.xlsx から計算）: 市町村管理で下水道が要因とされた割合 14.9%（1,289/8,624）。特別区 48.1%（87/181）、政令市 21.6%（604/2,798）、それ以外の市町村 10.6%（598/5,645）、都道府県管理 3.4%（40/1,169）。情報部の報告にある「20%」は 14.9% の誤りとみられる（件数の PDF との一致は 8,624・1,289・604・87 で確認）。
- **全国特別重点調査**（別紙2、令和8年2月末。管径 2 m 以上・1994 年度以前）: 豊中市は対象 4.42 km（優先）＋19.135 km、**空洞が確認された箇所 0**（全国 96）。ただし**空洞調査の実施済み延長も 0 km**で、「空洞がない」ことを示す数字ではない。位置つきの「当たり」として使えるものはない。
- 再現: 取得物は `sandbox/` の新しい空ディレクトリに置き、`python3 -I tools/verify_incidents.py --mlit02 02.xlsx --tokujuten b2.xlsx --sewer 管渠.shp --chome r2ka27203.shp > data/verify.json`（標準ライブラリ＋pyproj。xlsx は `tools/xlsx_read.py`）。町丁境界は e-Stat の利用規約に従う（**要確認**）。

## 衛星データと提案書の関係（要確認事項）
- 提案書（`submission/proposal-A.md`）は **Sentinel-1 の解析を主に想定（ALOS-4 は比較検証）**。このデモは、公開済みの**国土地理院の成果（だいち2号・4号）で代用**しています。Sentinel-1 の解析結果ではありません（画面にも明記）。
- 使った成果: 国土地理院「衛星SAR地盤変動測量成果」の変位速度（準上下方向 `qu`、2014-08〜2025-11 の観測、2026-03-31 公開分）の地理院タイル。ALOS-2/4（Lバンド）、約90m、凡例 -3〜+3 cm/年 を16階級（**1階級 3.75 mm/年幅**）。
- 値は**階級の幅でしか言えません**（階級の中央値で計算するが、小数の精度はない）。国土地理院は「数百m四方より狭い変動の把握は困難」としており、生活道路単位の値ではありません。
- 利用条件（**要確認**）: クレジット『解析：国土地理院 原初データ所有：JAXA』を画面に表示し、加工（色→階級→区画集計）した旨を明記。**出典間に食い違いがある**: 同じ成果のデータ登録（data.e-gov.go.jp）は「政府標準利用規約」、国土地理院のページ・README は測量法上の承認の要否を明記していない（地理院コンテンツ利用規約の適用も未確認）。どちらも採用せず、静的な派生データ（`data/toyonaka.json` の区画の階級）の公開・応募添付の前に確認する（地理院への問合せは総司令官の判断）。公開は総司令官が許可済み（2026-11-21「公開して良い」）だが、承認の要否は未確認のまま。実際の公開・デプロイ・応募フォームへの添付は総司令官が行う。

## 体験できる流れ（既存の流れのまま）
1. **絞る**: 区画（約90m）の衛星の階級と、下水道台帳の竣工年の古さを重み付きで足して道路区間に点数を付ける。重みはスライダーで動かせる。**既定は台帳中心（衛星の重み 10%）で、利用者が上げて試す形**。画面に「台帳のみの上位20区間に無かった区間が上位20に入った数」「1位と同点の区間数」を出し、衛星で絞れない様子が分かる。
2. **選ぶ**: 走らせられる延長（仮の値）の範囲で、未調査の生活道路から地中レーダの投入先を選ぶ。上位から自動選定、または地図で区間をタップして手で調整。予算超過だと次へ進めない。
3. **戻す**: 一次審査後に GMS3 の結果を入れる枠。自治体の調査結果 CSV（区間ID、または緯度・経度の点 ＋ 空洞あり/なし）を入れると、重み（0〜100%）ごとの当たりやすさ（AUC）を比べ、最大の重みに更新して第2回へ。空洞あり／なしが各3件未満なら「データ不足」として重みを変えない。結果が入っていない既定では較正しない。

**この地区は衛星でほとんど絞れません**。区画の階級は2種類だけ（-3.75〜0 mm/年が 325 区画、0〜+3.75 mm/年が 597 区画。道路のある区画のみ）で、デモの正規化では衛星の点数は最大 0.23。重みを上げると順位は「どちらの階級か」で二分され同点が増える。**この地区の2階級の差は階級幅（3.75 mm/年）以内で、沈下の兆候とは言えない**（画面にも同じ一文を出している。地図でも2階級は同じ扱いで、斜線の有無で区別するだけ）。**絞れない地域では、台帳（竣工年）と過去の調査の重みが前に出る**（第3段階の較正では、通し確認で衛星の重みが 20% に下がった。架空の結果に対する値）。

## 限界
- 点数の正規化（-8mm/年で1、60年で1）、重みの探索、AUC・除外精度の表示は、デモのための単純な設定。AUC などは架空の空洞結果に対する計算で、実際の精度・効果・費用を示さない。
- 衛星の階級は 3.75 mm/年幅で、この地区ではほぼ全域が -3.75〜+3.75 mm/年の範囲。測定誤差の範囲を超える沈下の検出は示していない。「-3.75〜0」の区画は沈下の兆候ではなく、変動がほぼない範囲のうちの負側。
- 管渠の位置は道路の中心線の下とは限らない。竣工年は「近くの管渠の台帳の竣工日」であり、実際にその道路の下にある管の竣工年とは限らない。
- 豊中市以外・他の沈下地域での検証はしていない（強い沈下のある地域の下水道台帳の公開データは確認できていない）。
- 衛星の解析（InSAR処理）とレーダ解析は未実装。「管内カメラ調査への引き継ぎ」は画面に注記するのみ。
- 底図は使っていない（外部通信なしのため）。道路と区画だけの表示。
- 画面の既定の重み（10%）は、ダッシュボード側 sat-a と同じ（実データ版に付け替え済み）。
