# 盛土巡視台帳（提案B コンセプトデモ）

衛星データ活用アワード2026–2027 提案B「盛土の変化を衛星で見つけ、巡視を絞り込む」の、実現性を説明するための最小限の静的Webアプリ。**既定は実データ版（神奈川県横須賀市）**。画面上部のボタンで架空サンプルに切り替えられる（どちらのモードかはバナーに常に表示）。

自治体の盛土規制担当が、次の流れを体験できる。

1. 台帳（点数順の一覧。各行に「前（1974〜78年）」と「現在」の空中写真、点数の内訳、地図）
2. 巡視計画（巡視可能件数を入れ、上位N件を回り順に並べる。CSV書き出し）
3. 巡視結果の記録（localStorage に保存。CSV書き出し）
4. 検出条件の見直し（結果を型ごとに集計し、重みを職員が手で調整。順位に即反映）

## 起動方法
サーバー側処理・APIキーは不要（写真はブラウザが地理院タイルを直接GETする）。

```
cd contests/satellite-2026/app/proposal-b
python3 -m http.server 8823 --bind 127.0.0.1
# http://127.0.0.1:8823/             実データ版（既定）
# http://127.0.0.1:8823/?mode=sample 架空サンプル（画面上部のボタンでも切替可）
```

## テスト
```
node tests/lib_test.mjs                                        # ロジックと実データの整合性（18件、node 22）
node tests/ui_shot.mjs http://127.0.0.1:8823/ ./screenshots    # 要 google-chrome。両モード・デスクトップ/390px の操作確認、スクリーンショット、コンソールエラー検査
```

## 実データ版（既定）
対象: 神奈川県横須賀市の大規模盛土造成地 716か所（A54 の整理番号が重複するものは枝番を付与）。

| 項目 | 出典 | ライセンス・条件 | 取得日 |
|---|---|---|---|
| 造成地の位置・形・型（谷埋め/腹付け/区分なし） | 国土交通省 国土数値情報「大規模盛土造成地」A54（2023年版、神奈川県） | CC BY 4.0 | 2026-11-11 |
| 規制区域（区域内外・区分・告示番号） | 国土交通省 国土数値情報「宅地造成等工事規制区域・特定盛土等規制区域」A56（2025年版、データ基準日 2025-07-18、神奈川県） | CC BY 4.0。概略的な位置で法的図書ではなく、申請・根拠資料には使えない | 2026-11-11 |
| 標高差・平均傾斜 | 国土地理院 標高タイル（DEM5A、無い場合 DEM10B。今回は 711件が DEM5A） | 国土地理院コンテンツ利用規約 | 2026-11-11 |
| 前後の写真 | 国土地理院 地理院タイル（年代別の写真 1974〜78年 `gazo1`／シームレス空中写真）。ブラウザが直接取得し、リポジトリには含めない | 国土地理院コンテンツ利用規約 | 閲覧時 |

データの再生成: `python3 -I tools/fetch_raw.py <dir>` → `python3 -I tools/build_data.py <dir> data/real.js`（numpy・shapely・Pillow 要。GET のみ）。

**出せた項目**: 位置、型、面積（ポリゴンから算出）、造成地ポリゴン内の標高差と平均傾斜（DEM）、規制区域の内外と区分、前後の写真、巡視計画（直線距離での回り順）、巡視結果の記録と書き出し、型ごとの集計。

**出せない項目（推測値で埋めていない）**:
- 衛星由来の変化量・変化の開始時期・SAR の変位: 未接続。画面では「未接続（実運用では Sentinel-1/2 で算出）」と表示し、点数に含めない。
- 許可・届出の有無、盛土の高さ・土量、造成の時期: 取得できていない。
- 巡視結果: 利用者が入力するもの（初期値は空）。
- 衛星画像そのもの: 本デモでは使っていない（無償で使えるものの利用条件を未確認のため）。写真は撮影年代の異なる航空写真で、直近の変化を示すものではない。

点数の入力は実指標のみ（型・区域・面積・標高差・平均傾斜）。しきい値と点数は仕組みを見せるための仮置きで、根拠のある値ではない。標高差は「造成地ポリゴン内の最大−最小」で、盛土の高さそのものではない（自然地形の高低差を含む）。DEM の画素が4未満の小規模な造成地は「算出不可」。市役所の位置は巡視計画の出発地の仮置き（概略）。

## 架空サンプルモード
全件架空のデータ（`data/sample.js`、12地点）。変化・許可届出などを含む。記録と重みは実データ版とは別のキーで保存する。

## 限界
- InSAR・光学時系列などの衛星解析、盛土らしさの推定は実装していない（提案書の中核だが本デモの範囲外）。
- 巡視の回り順は地図上の直線距離の最近傍法で、道路・立入可否は考慮しない。
- 巡視結果による調整は、集計表示と手動の重み変更のみ。自動学習はしない。件数が5件未満の区分は率を出さない。
- 記録はブラウザ内のみ。複数職員での共有・認証・監査ログはない。個人情報を入れない運用を前提とする。
- A56 は概略データで、横須賀市では市全域が「宅地造成等工事規制区域」として収録され、区域外の造成地は3件。特定盛土等規制区域は含まれない。
- 写真タイルは外部（地理院）から取得するため、オフラインでは「写真なし」と表示される。
- 衛星は「どこを先に見るか」の端緒で、違反の判断は職員が現地で行う。
