# クマ対策：藪払いの優先地図（提案yabu コンセプトデモ）

衛星データ活用アワード2026–2027 向けの**比較用の新案**。既存の proposal-a / proposal-b / proposal-alpha は変更していない。

## 目的
集落のまわりで、クマが身を隠しながら人里に近づく帯（耕作放棄地・藪・林縁）を衛星で絞り、クマ出没の履歴と人家・学校との近さを重ねて、刈り払い（緩衝帯整備）の優先順位を自治体の鳥獣担当が決められるようにする、その流れが実際に動くことを示す。

流れ：衛星で候補を絞る → 出没履歴と人家の近さで順位付け（根拠を表示） → 現地確認の記録 → 刈り払い計画のCSV出力。

## 実データか架空か（先に読む）
**架空のデータは使っていない。** すべて公開データを実際に取得して処理した（`tools/build_data.py`）。ただし次の限界がある。

| 項目 | 内容 | 区分 |
|---|---|---|
| 候補区画（605） | Sentinel-2 から求めた植生指数・林縁度（100m四方・約1ha） | 実データ（粗い目安。藪かどうかの確定ではない） |
| クマ目撃 | 京都府公開データのうち対象範囲内 1,534 件（**2009〜2018年度。最新ではない**） | 実データ |
| 建物・学校 | OpenStreetMap（建物 1,434 棟、学校・園 20）。**未登録の建物がある**（市街地中心部は特に少ない） | 実データ（不完全） |
| 点数の配点・基準値（藪払い順位） | `lib.js` の `DEFAULT_WEIGHTS` / `CAPS` | **説明用の仮置き**（根拠のある値ではない）。画面で重みを変えられる |
| 現地確認の記録 | 利用者が入力。初期は空 | デモ中の入力は実際の確認ではない（CSVにも注記が入る） |

## 対象地域と選定理由
京都府与謝野町（旧 加悦町・野田川町）周辺（東経135.06–135.17、北緯35.45–35.55）。目撃位置（緯度経度つき）の CSV を公開しており、実際に取得できたため。範囲内に目撃が多く（京都府データで最も密な区画の一つ）、水田の谷と山地の境（林縁）がはっきりしている。

## 処理の内容（`tools/build_data.py`）
1. 5月（新緑期。水田は水が張られて NDVI が低い）と2月（落葉期）の NDVI を 10m 画素で計算。雲・雲影・雪（SCL）は除外。
2. 5月の NDVI 0.6 以上を「茂っている」とし、開けた所（NDVI 0.45 未満＝水を張った水田・裸地など、OSM建物）の約30m以内にある茂った画素を「林縁」とする。
3. 100m 格子ごとに、林縁の割合・NDVI平均・夏冬差を集計。建物から400m以内、NDVI平均0.5以上、林縁度0.10以上、建物画素15%以下、欠測が少ない格子を候補（605）にする。
4. 各候補に、500m以内の目撃件数、最寄り建物までの距離、300m以内の建物数、最寄り学校・園までの距離を付ける。
5. 点数は `lib.js` で計算（衛星由来30点＋目撃・建物・学校由来70点、仮置き）。「衛星だけで並べる」で重ねたデータの効果（順位の変化）が見える。

衛星の取得は自作の最小COG読み取り（`tools/cog_window.py`。HTTP Range の GET のみ、標準ライブラリ＋numpy）。再作成：`python3 tools/build_data.py --cache <作業ディレクトリ>`（要 numpy・scipy・pyproj）。

## 既知の限界
- 藪・耕作放棄地を直接判別していない。林縁にある茂った植生を絞るだけで、水田の畦・庭木・果樹園・植林との区別は現地確認が必要。
- 目撃履歴は2009〜2018年度で古い。最近の傾向は反映されない。また目撃件数は人の多い所で多くなる偏りがある。
- 建物は OSM の登録分のみ。最寄り建物までの距離・300m以内の建物数は実際より不利（遠く・少なく）に出る地域がある。
- 通学路データは未入手。学校・園までの直線距離で代用。
- 雲・雪で欠測した画素は除外しており、欠測が多い格子は候補から外れている。単一年・2時期だけの画像。
- 点数の重みは仮置き。出没の予測や、刈り払いによる出没減少の効果は示さない（根拠となるデータを持たない）。
- 5月の画像は 2026 年、目撃は 2009〜2018 年度で、時期がずれている。

## クマが出やすい範囲（論文ベース）と実データでの検証（2026-11-21 追加）
地図の紫の塗り（高＝塗りつぶし、中＝斜線、低＝塗りなし）は、論文の数値に基づく**「出没しやすさ」の判定**。藪払い順位の点数（上の仮置きの配点）には入れていない（表の列・並び替え・根拠の欄で見る）。調査の根拠は `reports/intel/satellite-2026-bear-habitat-factors-20261121.md`。出没の予測ではない。

**式**（`lib.js` の `HAB`、`tools/build_habitat.py`）：100m 区画ごとに **S ＝ R × 集落係数 × 市街地係数**。S ≧ 3.74 を高、S ≧ 1.81 を中、それ未満を低。

| 要因 | 使い方 | 数値と出典 | 根拠の強さ |
|---|---|---|---|
| 林縁への近さ | R：画素（10m）ごとに exp(b×exp(−0.01×d))、b＝ln3.74÷exp(−0.2)＝1.611。区画内の最大値 | 林縁20mで選択オッズ 3.74、100mで 1.81（雌。雄は 7.00 と 2.40）。Takahata ほか 2014, PLoS ONE 9(1): e86181（長野県・GPS 24頭）。式から求めた100mの値 1.809 が論文の 1.81 と一致（スクリプトが確認） | 強（選択であって目撃ではない。長野県） |
| 川に接する林縁 | 林縁20m以内かつ川（OSM）20m以内の画素は R＝21.45 | 同上（雌。雄 18.01） | 強（長野県のみ） |
| 集落から500m圏 | 集落係数：建物から500m以内＝1、外＝0.5（**仮**） | 夏は人里から500m圏内を主に利用（Takahata ほか 2017。高畠 2021 の表より）。係数の値は論文になく仮 | 中（向きのみ） |
| 人口の多い市街地 | 市街地係数：建物用地が区画の半分以上＝0.5（**仮**） | 人口密度が高いほど避ける（三谷ほか 2001。1頭・73地点、R²＝0.162） | 弱 |
| 果樹園 | **入れていない** | 京都府立大 ACTR A22 に果樹園との相関（数値なし）。国土数値情報 L03-b（令和3年）は果樹園を「その他の農用地」に含み取り出せない | 数値なし |
| 針葉樹率・学校・NDVIの濃さ | **入れていない** | 針葉樹率は文献間で向きが割れる。学校・NDVI の濃さに根拠なし（学校は表に「被害を受ける側」として残る） | ― |

仮の係数（0.5 と 0.5）と、論文に数値のない部分は、**検証の結果で調整していない**（先に決めた値のまま）。林縁は、Sentinel-2 の5月 NDVI 0.6 以上の画素を森林（田・その他農用地・建物用地・道路・ゴルフ場の土地利用を除く。欠測は L03-b の森林で補う）、それ以外を開けた所として境目までの距離を求めたもので、論文の林縁の定義とは異なる（ずれる）。

**使ったデータと利用条件**（取得 2026-11-21、すべて GET）：国土数値情報 土地利用細分メッシュ L03-b（令和3年・5335）＝国土交通省、国土数値情報の利用約款に従う／OSM の建物 24,178 棟・河川（river・stream）1,786 本＝© OpenStreetMap contributors（ODbL）／Sentinel-2 `S2C_53SNV_20260517_0_L2A`／京都府クマ目撃情報（CC BY 4.0）。再作成：`python3 tools/build_habitat.py --cache <作業ディレクトリ>`（要 numpy・scipy・pyproj・fiona。Overpass が混むと十数分かかる）。

**検証**（画面の折りたたみ「この判定は当たっているか」に全表）：範囲は地図より広い丹後〜福知山の一部（東経135.00〜135.40、北緯35.34〜35.70。国土数値情報 5335 メッシュと衛星タイルに収まる範囲）、100m 区画 115,934、目撃 6,072 件。区画ごとの「目撃があったか」と S を比べる（判定は目撃で作っていないので学習・検証の分割はなく、年度で分けて安定性を見る）。基準は「最寄りの建物に近いほど高い」だけの判定。

| 範囲・期間 | 論文ベース S の AUC | 林縁・川だけ R の AUC | 人家距離だけ（基準）の AUC |
|---|---|---|---|
| 全区画・2009〜2018年度 | 0.79 | 0.80 | 0.70 |
| 全区画・2010年度を除く | 0.79 | 0.80 | 0.69 |
| 全区画・2009〜2013年度 | 0.78 | 0.79 | 0.69 |
| 全区画・2014〜2018年度 | 0.79 | 0.81 | 0.70 |
| 建物500m以内・2009〜2018年度 | 0.61 | 0.67 | 0.60 |
| 建物500m以内・2010年度を除く | 0.62 | 0.67 | 0.60 |
| 建物500m以内・2009〜2013年度 | 0.59 | 0.65 | 0.60 |
| 建物500m以内・2014〜2018年度 | 0.62 | 0.68 | 0.60 |

等級ごとの目撃密度（件/km²、2009〜2018年度）：建物500m以内の区画で 高 14.0／中 9.8／低 5.3、全区画で 高 14.9／中 9.7／低 1.6。年度別・2010年度除外でも 高＞中＞低の順は変わらない。人家からの距離を 0〜100m・100〜250m・250〜500m にそろえても 高は低より高い（17.6 対 11.5、12.6 対 8.2、13.2 対 2.5）が、0〜100m の中は高より僅かに高い（18.1）。

**読み取り（結果は良し悪しともそのまま）**：
- 検証範囲全体では、S は人家距離だけの基準を上回る（0.79 対 0.70）。ただし山奥（人家から遠く通報されにくい）を含み、人家距離が有利に働く表でもある。
- 人里の周り（建物500m以内）に限ると、S の AUC は 0.61 で基準 0.60 とほぼ同じ。論文の「林縁・川」だけを使った R は 0.67 で、S（市街地係数を掛けたもの）より高い。市街地を下げる仮の係数は、目撃（通報）が多い市街地近くで逆効果だった可能性がある（推測。係数は調整していない）。
- 目撃は住民・市町村・警察の通報で、府は真偽を精査していない。人の多い所ほど通報されやすく、AUC や密度は「クマの出やすさ」ではなく「通報されやすさ」も反映する。AUC は出没の予測精度の保証ではない。
- 区画は100mのみで確かめた。目撃データは2009〜2018年度、衛星・土地利用は2020〜2026年で時期がずれる。OSM の建物は未登録がある。

## 表示の修正（2026-11-22。憲兵監査 要修正-2〜4・要確認-6への対応）
- 衛星の利用に「Contains modified Copernicus Sentinel data（2026）」を画面の出典欄と検証欄に入れた。
- 出典欄に OSM のライセンス（openstreetmap.org/copyright）・ODbL での提供の旨、京都府データ（CC BY 4.0）のライセンスへのリンクと「取得した CSV から範囲内を抽出・集計して加工」の旨、国土数値情報 L03-b（国土交通省。加工して作成）の出典を入れた。
- 「判定は論文の数値だけで作り」を、「林縁・川の部分は論文の数値、集落・市街地の係数（各0.5）は仮置き。どちらも目撃で調整していない」に直した（検証欄・上部の注意・地図の注記）。
- 検証欄の自動文は、S と基準の AUC の差が 0.02 未満なら「基準とほぼ同じ（差0.02未満）」と出す（「上回る」「下回る」は 0.02 以上のとき）。
