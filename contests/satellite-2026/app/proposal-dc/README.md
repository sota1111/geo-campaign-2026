# データセンター候補地の一次スクリーニング（福岡県 直方市・鞍手町・北九州市西部）

衛星データ活用アワード2026–2027 向けの新案（2026-11-22）。初期応募にプロトタイプは必須ではなく、実現性を説明する補助。提案書は作っていません（テーマと枠は総司令官が選ぶ）。

**立ち位置**: 国の GX 戦略地域（データセンター集積型）に福岡県（北九州市・直方市・鞍手町）が認定された（福岡県発表 2026-09-11。情報部 `reports/intel/satellite-2026-datacenter-20261122.md`）。その周辺で、衛星から見つけた造成地・遊休地の候補、または地図で指した地点について、検討の最初に確かめる項目を出典つきで並べる。**点数・順位・立地の良し悪しの判定は作りません**（立地の定量基準は公的資料で見つからなかった。情報部 §0-5）。

## テーマへの当てはめの選択肢（選ぶのは総司令官）
協賛企業テーマ「衛星と地中のデータでインフラのリスクを可視化し、災害に備える」に文言が最も近く、共通1（インフラマネジメント・都市活動の課題解決）・共通2（防災・災害対応）にも読める。ただし「各テーマへの応募は1提案まで」で、既存案は A＝協賛＋共通1、B・α・sugi・yabu＝共通2。選択肢は、(a) A を外してこの案を「協賛＋共通1」に置く、(b) 共通2 の1枠で B・α・sugi・yabu のいずれかと入れ替える、(c) この案を「協賛＋共通2」にして A を共通1だけにする（A の協賛テーマへの適合が弱まる）の3つ。協賛企業（カナン・ジオリサーチ）の主用途は路面下の空洞調査・埋設管・橋梁で、データセンター用地の地盤調査は含まれない。接点は「衛星（地盤変動）で絞り、地中探査で現地確認」の二段階に限られる。審査は「衛星データの重要性」を見るので、衛星の役割（地盤・熱・土地の状態と変化、候補地の発見）を前に出す必要がある（以上、情報部 §1-3）。

## 画面
- 地図（画面の約 65%）に、造成地の候補（橙の番号）・遊休地の候補（紫の番号）の輪郭、変電所・送電線。地図をクリックすると、その地点（周囲 約 75 m）の確認項目が出る。
- 右（スマホは下）: 選んだ候補地・地点の**確認項目 8 つ**（洪水・土砂・津波・高潮の該当／非該当、干渉SARの沈下の階級、夏の地表面温度、最寄りの変電所・送電線までの距離、土地の状態と 2020→2026 の変化）。各項目に出典・利用条件・注意。
- 「防災・都市課題にどうつながるか」を畳まずに常時表示（浸水しない場所に置けば地域のデータ・防災拠点になりうる、造成地・遊休地の優先、地盤の二段階調査、排熱の活用の確認）。「限界」（折りたたみ）と「使っているデータ・出典」（ID・日付・利用条件）。
- 比べる表: 残した候補地（最大3件）に、選択中の候補地・指した地点を「選択中」の一時列として自動で足す。候補地の一覧は「災害の該当なし」を先に並べる。スマホは選択後に結果の先頭へ寄せ、凡例は既定で畳む。
- 地図に重ねる層: 衛星（土地の状態、植生→裸地等の変化、地表面温度、干渉SAR）、重ねる層（洪水・土砂・津波・高潮・電力）。

## 重ねる層（商用可のものだけ）
国土数値情報 A31b（洪水浸水想定、想定最大規模、令和7年度版。メッシュ 5030、国管理・都道府県管理等）、A33（土砂災害警戒区域、福岡県、2025-08-01 時点）、A40（津波浸水想定、福岡県 2016 年版）、A49（高潮浸水想定、福岡県 2020 年版）＝CC BY 4.0（一部制限。県別の条件に従う）。「国土数値情報（国土交通省）を加工して作成」。OSM の変電所・送電線（取得は Overpass の GET）＝ODbL、© OpenStreetMap contributors。`data/dc.js` の変電所・送電線は OSM の派生データベースで、**ODbL で提供する**。
**使わない**: 非商用（P03・L05・P20・A30b）、条件が不明（JAXA 土地被覆・活断層・J-SHIS・液状化・電力会社の空容量マップ）。

## 限界
国土数値情報の災害区域は縮尺 1/25,000〜1/50,000 程度の概略（位置の誤差は数百 m 規模。公共測量・重要事項説明には使えない）。干渉SARは約 90 m・数百 m より狭い変動は読めず、植生・水面は値が取れない。国土地理院 SAR の測量法上の承認の要否は**要確認**（情報部 Q1）。電力は OSM の登録分だけで、空き容量・接続可否は分からない。通信・水・地震・活断層・液状化は扱っていない。

## 再現と起動
```
# 取得（GET のみ。生データは sandbox などの新しい空ディレクトリへ。コミットしない）
python3 -I tools/fetch_insar.py CACHE/insar
python3 -I tools/fetch_sat.py CACHE/sat
python3 -I tools/fetch_osm.py CACHE/osm
# 国土数値情報の zip（A31b-25_10_5030・A31b-25_20_5030・A33-25_40・A40-16_40・A49-20_40）を GET して展開し CACHE/ksj に置く
python3 -I tools/build_data.py --insar CACHE/insar --sat CACHE/sat --osm CACHE/osm --ksj CACHE/ksj   # -> data/dc.js（要 numpy・scipy・pyproj・fiona・shapely・PIL・cv2）
python3 -m http.server 8822 --bind 127.0.0.1                                                       # サーバー・APIキー・外部通信は不要（背景地図の地理院タイルを除く）
node --test tests/lib_test.mjs
node tests/ui_check.mjs http://127.0.0.1:8822/ screenshots   # 要 google-chrome
```
`tools/cog_window.py`・`insar_cells.py` は提案 yabu・A と同じ処理の複製。
