# 案 sugi（全国版）: 都市から森の市町村へ資金を渡す仕組みを比べる

総司令官の指示（2026-11-22）で、関東の対策マップを**日本全国の市町村地図**にし、「花粉の被害が多い都市の市町村が、スギ人工林の多い森の市町村に予算を渡す仕組み」を検討できる画面にした。入口は `index.html`（全国版）。関東版は `kanto.html`、青梅の旧版は `ome.html` に残してある。事実整理は reports/intel/satellite-2026-sugi-national-fund-20261122.md。

## 画面（index.html。1画面・1513×784 と 390×844 で確認）
- 地図（左60%、スマホは上46%）: 市町村の塗り分けを4つに切り替え。**配分先**（選んだルールでの予算の割合。候補外は緑の濃さ＝スギ人工林）／**スギ人工林**（発生源側、26年生以上の面積）／**現行の譲与額**（令和6年度）／**衛星の樹木被覆**。赤い●は人口10万人以上の市区（被害側、大きさが人口）。点線は半径、番号は配分の上位8。
- パネル: 1 都市を選ぶ（人口10万人以上の市区のプルダウン、または地図クリック。初期は世田谷区）と半径（20/30/50/75/100 km。初期50 km）→ 2 仮の予算（万円）とルール → 3 結果（候補数・圏内の面積・予算と現行譲与額の比、上位8市町村の表に **現行譲与額とA〜Eの配分額を並べる**、上位3の割合・1%以上の受け取り数・Dからの動き）。制度の事実と限界は3行で常時表示、詳細は「出典・計算方法…」。
- 表の行・番号の●をクリックすると、その市町村の人口・面積・現行譲与額・各ルールの配分額・衛星の樹木被覆が出る。

## 配分ルール（利用者が切り替えて比べる。適正・最適とは言わない）
| | ルール | 重み |
|---|---|---|
| A | 圏内の面積比 | 半径内の26年生以上スギ人工林の面積 |
| B | 近さ重み付き | 圏内の面積 × (1−距離÷半径)。形は仮置き |
| C | 市町村全体の面積比 | 候補の市町村全体の26年生以上スギ人工林 |
| D | 現行の譲与税の比率 | 令和6年度の譲与額の実額（私有林人工林50%・林業就業者20%・人口30%で国が決めた額）に比例 |
| E | AとDの混合 | A の割合をスライダーで（初期50%、仮） |
候補 = 圏内の26年生以上スギ人工林が10 ha以上の市町村（都市自身を除く。仮）。単一の都市では人口は全ルールに同じ倍率で掛かるため、人口は重みに入れていない（都市の選択と、譲与額の比較にだけ使う）。**譲与税は国から各市町村への譲与で市町村間の移転ではなく、他市町村への支出が可能かは未確認**と画面に書いた。効果（花粉が何%減る等）は書かない。

結果: スギ人工林 4,650,982 ha（26年生以上 4,468,537 ha）、市町村1,741（政令市は区をまとめ、東京23区は区ごと）。関東1都6県の合計は393,314 haで、関東版の386,445 haと1.8%差がある（原因は未特定。図郭の重複は関東西部の系で無いことを確認）。データ: data/nat.js 約3.2MB、data/nat_geo.js 約2.1MB。

**衛星で分かること・分からないこと**: 衛星（WorldCover）は樹木の有無・広がりまで。樹種（スギか）・林齢・人工林か天然林かは判別できないため、スギの量・林齢は森林簿由来（衛星ではない）。衛星は「森林簿のスギ人工林が衛星の樹木被覆の何%か」の答え合わせと塗り分けに使う。JAXA の土地被覆図（常緑針葉樹）は登録・規約確認が要り、スギ判別不可のため使っていない。Sentinel-2 の冬のNDVIによる確認は関東版のみ。

**仮置き・限界**: 半径は国の目安50 kmのみが根拠（花粉の到達式ではない。風向なし）。被害側の指標は人口だけ（飛散・有病率・損失の市町村別の公的データは未確認）。人口の市町村集計は1kmメッシュによる概数。連携事例（世田谷区×川場村、港区みなとモデル）は画面の説明に出典付きで載せたが、検索要旨のみ確認で本文未読。

## 関東版: スギ花粉の発生源対策マップ（関東1都6県）

衛星データ活用アワード2026–2027 向けの比較用の案（既存の proposal-a / b / alpha とは別。入れ替えず並べる）。総司令官の指示（2026-11-21）で、青梅周辺の試作を**関東1都6県の地図**にし、**公的資料・論文に基づいて場所ごとに「どの対策を優先するか」を塗り分ける**形に作り直した。調査は reports/intel/satellite-2026-sugi-countermeasures-20261121.md。

## 画面（kanto.html）
区分1の中は「人に届きやすい発生源の順位」（下の節）で濃淡と斜線の太さを変え、パネルに順位表・感度表を出す。
地図が画面の約66%（スマホは高さの62%）。色=対策の区分、濃さ=500mメッシュのスギ人工林の多さ、模様でも区別（斜線・点・交差斜線・横線）。太い黒の輪郭=林野庁の伐採重点区域がある市町村、黒の破線=50km圏の外縁、●=起点の都市。凡例に「何をするか」と根拠。地図クリックでその場所の区分と理由、市町村・都県の一覧、仮の基準（傾斜・まとまり・林齢26/21年）のスライダー、東京都12地点・雄花花芽調査との照合（参考）。

## 区分1の中の順位（人に届きやすい発生源の順位。作成者の式。2026-11-21 追加）
区分1（253,614 ha）が関東の大半を占め、色だけでは着手の差が見えないため、区分1の**中**に順位を付けた。総司令官の指示（「花粉症の論文を参照して順位を付けて」）。要因と根拠の整理は reports/intel/satellite-2026-sugi-ranking-factors-20261121.md。

**式**: `S_i = a_i × Σ_j Pop_j × K(d_ij)`。a_i＝そのメッシュの26年生以上（切替で21年生以上）のスギ人工林の面積（ha）、Pop_j＝人口、K(d)＝半径 R km 以内なら1、外は0。R は画面で10・20・30 kmから選び、**初期値20 km（仮）**。区分1の中を、面積で数えた百分位で 上位10%・10〜30%・30〜60%・残り の4つの帯にする。地図は帯ごとに茶→橙→薄橙の濃淡と斜線の太さ・間隔で塗り（色だけに頼らない）、パネルに都県別の面積と市町村の順位表（上位10%の面積順）を出す。「花粉の量」「対策の成果」は示さない。

| 根拠の強さ | 内容 |
|---|---|
| 根拠あり | 26年生以上のスギ人工林を発生源とする（金指・篠原 2009）。「発生源の量×そこに住む人口」の形（森林総研は人口を考慮して首都圏の居住者の曝露を発生源別に集計）。 |
| 方向のみ | 近い地点ほど影響が大きい（東京都12地点の回帰係数は青梅2.91〜大田0.39。横山 2017）。 |
| 仮置き | 距離の減り方（半径内=1、外=0）と R の値。距離減衰の式を示した公的資料・論文は見つかっていない。 |
| 点数に入れない | 林齢の連続的な重み（雄花量は26年生以上で頭打ち。齋藤 1991、金指 2009、宇都木。区分1の97%が26年生以上で順位を分けない）、風（根拠になる数値がなく、単一地点・数年の最多風向は限界が既知）、傾斜（区分3の判定に使う別の軸）、まとまり、県別の雄花調査値（県平均で年によって2〜3倍動く）、ヒノキ。 |

**人口**: e-Stat 地域メッシュ統計 令和2年国勢調査 250mメッシュ（統計表ID T001102、人口総数、1次メッシュ19面。合計 52,188,842 人、`https://www.e-stat.go.jp/gis/statmap-search/data?statsId=T001102&code=<1次メッシュ>&downloadType=2` を GET）。出典は総務省統計局（e-Stat）で、500mメッシュごとの半径内人口への集計は当方の加工。`tools/kanto_pop.py` が `data/pop.js`（約0.7MB、100人単位）を作る。距離は緯度36度で補正した平面近似。人口を読み込めない場合のみ、`max(0, 1−最寄りの起点までの距離/50)` を代替にし、画面に「人口は使っていない」と出す（今回は人口を使えたので通常は出ない）。

**検証と感度（東京都12地点・2009〜2017年の9年分。参考であり順位の正しさの証明ではない）**: 地点の周囲（半径 R km）にある区分1のメッシュの点数の合計と、飛散花粉数（スギ・ヒノキ亜科の合計、ダーラム法）とのスピアマンの ρ（n=12）。観測は東京都 花粉症対策検討委員会 平成29年度第2回 資料3 の表2・表3（`tools/kanto_verify9.py` が原表を機械で読み直す。情報部報告の暗算の平均値と一致）。

**読み方と限界**: n=12・東京都だけで、関東の他の場所では確かめていない。地点は区市の代表点（観測地点そのものではない）。年によって ρ は−0.7〜0.85 と大きく動き、単年では順位の根拠にならない（低飛散年は負になる）。9年平均では R が小さいほど高いが、**R は観測に合わせて選び直していない**（初期値20 kmは先に決めた仮の値で固定。地点の違いを表す回帰係数では20 kmが最大だが差は小さい）。人口を掛けても掛けなくても ρ はほぼ同じで、この照合は人口の効き方を確かめていない（地点がすべて人口の多い東京都内）。風向・ヒノキ・距離減衰の形は入っていない。この感度表は画面の折りたたみにも載せた。

## 衛星で確かめる（Sentinel-2 の冬の NDVI。2026-11-21 追加）
審査の「衛星データ活用の妥当性」に応えるため、森林簿ベースの区分に衛星を重ねた。**衛星は樹種・林齢・雄花の量を判別できない**ので、使うのは次の2点だけ。順位の点数には混ぜていない（混ぜる根拠がなく、冬の緑の強弱は面積×人口の順位と別の問いのため）。

## 目的
政府の花粉症対策（スギ人工林の伐採・植え替え）で、**どの林から手を付けると、花粉を浴びる人が多い所を先に減らせそうか**を、都道府県・市町村の林務担当が公開データで当たりを付けるための流れを体験できるようにする。

流れ: 1 把握（スギ林を地図で見る）→ 2 順位（風下の人口で順位付け）→ 3 根拠（区画の根拠を確認）→ 4 出力（植え替え候補のCSV）

対象地域: 東京都 青梅市を中心に、日の出町・あきる野市・瑞穂町・羽村市・奥多摩町の一部と埼玉県 飯能市・入間市・日高市の一部（経度 139.17–139.35、緯度 35.76–35.88）。山地の人工林と、風下側の住宅地が近い。

## 実データか架空か
**このデモに架空のデータはありません。** 画面の植林・人口・風向・衛星値はすべて公開データの加工です（画面右上のバッジと左パネルの帯で常に明示）。ただし次は**説明用の仮置き**で、根拠のある値ではありません: 優先度指数の式（風下人口指数 × 面積）、人口を数える半径（1/2/3/5 km から選択、初期3km）、冬NDVIのしきい値 0.5。花粉の量・健康への影響・植え替えの効果は示しません。

## 計算方法
- **区画**: 500mメッシュ（地域メッシュ4次、9桁コード）のうち、植林を含み、植林面積が 0.5 ha 以上のもの（643区画、植林面積の合計は約 9,500 ha）。植生図のポリゴンは山地で非常に大きく連なるので、メッシュで区切って順位付けの単位にした。
- **風下人口指数**: 区画の中心から半径内にある250m人口メッシュの人口 × 重み、の合計。重み = その人口のいる方角が風下になる日の割合（最多風向の16方位の日数割合）×16。風向を使わない設定では重みはすべて1。方位は「風が吹いてくる方向」で、区画から方角 b にいる人は、風向が b+180° のとき風下。
- **優先度指数** = 風下人口指数 × 植林面積（ha）。花粉の発生源が大きいほど、浴びる人が多いほど上位、という説明用の単純な式。
- **衛星での確認**: 区画内の植林部分の NDVI 平均（SCL で雲・影・雪などの画素を除く）。冬の NDVI が 0.5 未満の区画は「要確認（冬の緑が弱い）」。落葉樹は冬に緑が落ちるが、常緑針葉樹は保たれるという性質を使い、植生図が古い調査に基づくため、いま常緑の林が残っているかの目安にする。伐採跡や植生図とのずれの可能性があるが、原因までは判別しない。
- CSV の列: 順位、区画コード、中心の緯度経度、植林面積、半径内人口、風下人口指数、優先度指数、冬／夏NDVI、衛星での確認状態、備考（実データの加工値・指数は説明用の旨）。末尾に条件の行。文字コードは UTF-8（BOM付き、Excel 対応）。`=` などで始まる文字列は式として解釈されないよう無効化している。

## 既知の限界
- 植生図は現地調査ベースで、調査年度が古い場所がある。すでに伐採・植え替えされた林が残っていることがある。凡例は「スギ・ヒノキ・サワラ植林」で、スギ単独ではない（ヒノキ花粉も含む区分）。
- 風向は1地点（青梅）・3年・日ごとの最多風向のみ。風速、地形による風の変化、花粉の飛散量・飛距離は入っていない。人口を数える半径も仮置き。
- 人口は常住人口で、昼間人口・学校・病院などは入っていない。人口メッシュの統計表IDと調査年は、取得したファイルの見出し（「人口（総数）」）とファイルの日付（2022-07-26）から令和2年国勢調査と判断した。e-Stat のページ上の表題までは確認できていない。
- 区画は市町村・林班・所有・補助要件の境界と対応しない。市町村名の表示はない。実際の施業は森林簿・所有者・現地の確認が必要。
- 衛星は光学（Sentinel-2）の単一時期ずつで、樹種・林齢は判別しない。しきい値 0.5 は仮置き。
- 「花粉が○%減る」などの効果の数値は、このデモでは出さない。
- 候補の選択は画面内のみ（ページを閉じると消える）。

順位表と根拠に「最も近い役所からの方角と直線距離」を出し、「場所で絞る」で役所ごとに区画を絞れるようにした。役所の位置は国土地理院の地名検索API（https://msearch.gsi.go.jp/address-search/AddressSearch 、GET）で 2026-11-16 に取得した値を `app.js` の `OFFICES` に書いている。市町村の境界ではなく、最も近い役所で分けた目安である。

## 区画の市町村（2026-11-16 追加）
区画の中心点の市区町村と大字（町名）を、国土地理院の逆ジオコーディングAPI（GET）で調べて `data/muni.js` に入れた（`python3 tools/fetch_muni.py`）。区画数は 青梅市 309・飯能市 231・日の出町 53・入間市 14・日高市 11・あきる野市 10・奥多摩町 9・瑞穂町 4・羽村市 2。対象範囲（緯度35.76〜35.88）は青梅市が中心で、あきる野市・羽村市の区画は少ない（初版の「対象地域」の書き方を、この結果に合わせて直した）。順位表・根拠に市町村と大字を出し、「市町村で絞る」で絞れる。前の節「区画の場所の目安」（役所からの方角）は、この市町村表示に置き換えたため、画面からは外した。
