# 提案A

## 応募テーマ
協賛企業テーマ, 共通テーマ1

## 提案名称
衛星で絞り、地中レーダで確かめる 路面下リスクの二段階調査

## 1. 提案の概要
[図] 衛星の変位と台帳で区画を点数化（Sentinel-1） → 未調査の生活道路からGMS3の投入先を選ぶ → GMS3で路面下を確認 → 結果を点数に戻して較正
下水道管路に起因する道路陥没は令和4年度に2,625件ある。一方、自治体の路面下空洞調査は緊急輸送道路や幹線道路が中心で、生活道路やその下の中小口径管には手が回っていない。本提案は、協賛企業カナン・ジオリサーチ社と組み、この領域に路面下調査の需要を広げる事業である。第1段階では、無料公開のSentinel-1のSAR干渉解析（InSAR）で得た地表変位の傾向を下水道台帳の属性に重ねて区画ごとに点数を付け、GMS3（地中レーダと360度カメラ）をどこへ投入すべきかを選ぶ。第2段階では、選んだ区画の道路をGMS3で走査して路面下の空洞を確かめ、管内の破損が疑われる箇所は管内カメラ調査につなぐ。確認結果は点数の較正に戻し、使うほど投入先の選び方が良くなる閉ループにする。衛星は空洞を直接見つけるものではなく、地上調査の投入先を選ぶ役割に限る。顧客は自治体の下水道・道路部局で、カナン社の路面下空洞調査に衛星による投入先の選定を組み込んだ調査パッケージとして提供し、選定料と調査の受注で収益を得る。まず一次通過後にGMS3の提供エリアで衛星指標と地上の確認結果を比べ、次に自治体での実証へ進める。

## 2. 募集テーマ合致性
協賛企業テーマの趣旨は、衛星と地中のデータでインフラのリスクを可視化し、災害に備えることである。本提案では、GMS3が取得する路面下のデータを判断の正解として中心に置き、衛星はGMS3を最も必要な場所へ導く入口として掛け合わせる。応募例にある「衛星データによる一次スクリーニングでの地中リスク箇所抽出」を中核に据え、さらにGMS3の確認結果で衛星指標を較正するところまで踏み込む。災害に備えるとは、陥没が起きてから復旧するのではなく、予兆の段階で路面下の空洞を見つけて手を打つことと解釈した。共通テーマ1（インフラマネジメント・都市活動）には、限られた予算と人員のまま、これまで調査が届かなかった生活道路まで維持管理の対象を広げる点で合致する。背景として、下水道管路に起因する道路陥没は令和4年度に全国で2,625件発生し、標準耐用年数50年を超える管きょは約4万km（総延長約50万kmの約7%）、10年後には約10万kmに増える見通しである（国総研）。調べる場所を選ぶ需要は、今後さらに高まる。陥没の予防は、生活道路を使う通学や物流などの都市活動の継続に直結する。

## 3. 事業スコープ・衛星データ活用の妥当性
衛星は、下水道台帳だけの優先順位付けに三つの情報を足す。第一に、実際に地表が動いているかという観測事実である。自治体は布設年度や管種などの台帳で順位を付けているが、台帳は管の属性であり、現在の地盤の状態は示さない。第二に、台帳に載らない変化の検出で、布設後の周辺工事や地盤沈下などの動きを拾える。第三に広域の継続監視で、数年おきの地上調査の合間も、Sentinel-1（観測幅250km、商用を含め無料、Sentinel-1Cで2機・6日回帰に戻る計画、ESA）で定期的に見直せる。一方で限界も認める。画素は生活道路の幅と同程度以上に粗く、安定した反射点は建物に多いため、点数は路線単位ではなく区画（メッシュ）単位で付ける。また、地中で進む空洞は地表に現れにくく、衛星だけでは見逃しうる（NTTも同旨を指摘）。そこで衛星は検出ではなくスクリーニングに限り、GMS3の確認結果で区画の点数を較正し続ける。効果は、台帳だけの順位と衛星を加えた順位を同じ地上結果に照らして測る。空洞の陽性は少ないため、異常なしとした区画が本当に異常なしかという除外の精度から検証する。ALOS-4（Lバンド）は商用条件の確認後に比較検証に使う。

## 4. 事業の実現性・収益性
顧客は自治体の下水道・道路部局で、カナン社の路面下空洞調査に衛星による投入先の選定を組み込んだ調査パッケージとして提供し、選定料と地上調査の分配で収益を得る。自治体は幹線に限っていた調査を生活道路の危険な区画へ広げられ、カナン社には未開拓の生活道路・中小口径管の調査市場が開ける。地上調査の単価は、仙台市・札幌市・神戸市の公開入札結果で1kmあたり約19万〜38万円（二次調査等を含む契約額÷延長）で、管きょ約50万kmを一巡すれば約950億〜1,900億円かかる。この全数はできないという差が市場の母数で、規模は「選定延長×選定単価＋新規の地上調査延長×上記単価」と置き、両者を実証で検証する。NTTは衛星による地中レーダの代替を掲げるが（2025年11月）、本提案は衛星で投入先を選び地中レーダで確かめる。GMS3データの商用利用は別途契約する。

## 5. 実用化による社会発展性
事業化の区切りは、衛星指標とGMS3結果の対応データがどれだけ貯まったかで決める。一次通過後（2026年12月〜）はGMS3の提供エリアで対応データを作り、2027年前半は自治体の協力を得て比較エリアを広げ、最終選考向けに地図上のリスク表示を試作する。対応が複数エリアで確かめられた時点で有償提供に移り、その後に水道管・橋梁へ広げる。【本人加筆（約70字）: 比較・実証の協力を打診する自治体の候補（合意がなければ「打診予定」と書く）と、有償提供を始める時期の見込み】。想定ユーザーは自治体の下水道・道路部局で、調査はカナン社と協業して担う。国の全国特別重点調査（管径2m以上の大口径管が対象）では、対策が必要な延長748km、地盤中の空洞96箇所が確認された（令和8年4月公表）。本提案は、対象外の中小口径管や路面下で、調べる順序を低コストで付ける。技術職員が少ない小規模自治体でも、全数ではなく危険な路線から調べられるようになり、陥没事故の抑制と点検費用の平準化に寄与する。発生率は管路延長1,000kmあたり5.3件（令和4年度）で、順位付けにより事前に対処できる箇所が増えれば件数の低減につながる（効果は実証で確認する）。
