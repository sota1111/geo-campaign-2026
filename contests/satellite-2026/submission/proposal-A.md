# 提案A

## 応募テーマ
協賛企業テーマ, 共通テーマ1

## 提案名称
衛星で絞り、地中レーダで確かめる 路面下リスクの二段階調査

## 申請者
【総司令官記入】所属先／代表者氏名／ふりがな／部署名・役職／所在地（個人は居住地）／電話／E-mail

## 1. 提案の概要
[図] 衛星で路線を点数化（Sentinel-1・降雨） → 上位路線だけGMS3で確認 → 結果を点数に戻して較正 → 次回の優先順位に反映
下水道管路に起因する道路陥没は令和4年度に2,625件あるが、全路線を調べる予算と人員はない。そこで下水道・道路の管理者と調査会社に向け、路面下リスクの調査を衛星と地中レーダの二段階に分けるサービスを提案する。第1段階では、無料公開のSentinel-1のSAR干渉解析（InSAR）で得た地表変位の傾向に降雨などを重ね、路線ごとにリスク点数を付ける。第2段階では、点数上位の路線にだけ、協賛企業カナン・ジオリサーチ社のGMS3（地中レーダと360度カメラ）を走らせ、空洞や管の異常を確認する。確認結果は点数の較正に戻し、使うほど順位付けの精度が上がる閉ループにする。衛星は空洞を直接見つけるものではなく、調査の順番を決める役割に限る。提供物は路線別のリスクマップ（点数と根拠指標）と調査計画案である。顧客は自治体の下水道・道路部局と調査会社で、リスクマップの年額提供と、GMS3調査への送客で収益を得る。まず一次通過後に1エリアで衛星指標とGMS3結果を比較し、次に自治体の実証へ進める。衛星の更新は追加費用が小さく、定期的に点数を見直せる。

## 2. 募集テーマ合致性
協賛企業テーマの趣旨は、衛星と地中のデータでインフラのリスクを可視化し、災害に備えることである。本提案は、広域の衛星データと路面下のGMS3データを一つのリスク点数に統合し、道路陥没を未然に防ぐ。災害に備えるとは、被災後の復旧ではなく、予兆の段階で手を打つことと解釈した。協賛企業の応募例にある「衛星データによる一次スクリーニングでの地中リスク箇所抽出」を中核に置き、さらにGMS3の確認データで衛星指標を較正するところまで踏み込む。共通テーマ1（インフラマネジメント・都市活動）には、維持管理を全数調査から優先順位付きの調査へ変え、限られた予算と人員で道路機能を保つ点で合致する。背景として、下水道管路に起因する道路陥没は令和4年度に全国で2,625件発生し、標準耐用年数50年を超える管きょは約4万km（総延長約50万kmの約7%）、10年後には約10万kmに増える見通しである（国総研）。調べる順番を決める需要は、今後さらに高まる。衛星で絞ることは、協賛企業にとっても調査営業の入口になる。陥没の予防は、道路を使う都市活動の継続にも直結する。

## 3. 事業スコープ・衛星データ活用の妥当性
衛星データは第1段階の中核である。Sentinel-1は幅250kmを一度に観測し、繰返しは12日（1機体制時）、商用利用を含め無料で使える（ESA）。数十万km規模の管路を現地調査だけで定期的に見ることはできず、広域・定期・低コストという衛星の特性が不可欠になる。処理は公開ツールで自動化し、新しい観測が入るたびに更新して、路線ごとの点数と根拠指標を地図で示す。使う指標は、InSARによる地表変位の時系列、降雨、SARの変化から見た水分状態である。これらと空洞との関係は未確立のため、GMS3の確認結果で検証し較正する。先行技術として、NTTが2025年11月にSAR衛星から道路陥没の予兆を捉える実証を発表している（探査深度は現時点で50〜100cm程度）。本提案は衛星で空洞を直接検出すると主張せず、こうした手法の出力も含めて路線の優先度に統合し、地上調査で較正する運用層を担う補完関係にある。NTTの実証の指標は、本提案の点数に取り込める。ALOS-4（観測幅200km）は商用条件と価格の確認後に追加する。

## 4. 事業の実現性・収益性
価格は管理延長に応じた定額とし、予算は調査委託費の枠を想定する（推測）。顧客は、維持管理予算を持つ自治体の下水道・道路部局と、調査の効率化を求める調査会社である。収益は、①リスクマップの年額提供、②GMS3調査への送客の二つ。市場規模は「対象延長×調査頻度×単価」で推定する。対象は標準耐用年数を超えた管きょ約4万km、頻度は年1回、単価を仮に1kmあたり年1万円（仮説。自治体・調査会社へのヒアリングで検証する）と置くと約4億円、10年後の約10万kmでは約10億円になる。道路・水道・橋梁への展開は別途見込む。協賛企業とのシナジーは、優先路線への集中走行によるGMS3の稼働率向上、自治体への営業リード、確認データの蓄積である。差別化は、衛星単独や地上調査単独ではなく、確認データで較正する閉ループにある。残る課題への対応として、衛星指標と空洞の対応は未確立なのでGMS3との比較で検証し、GMS3データは本プログラム内の利用に限られるため商用化の際は別途契約し、実績を重視する自治体には実証を入口にする。体制は【本人加筆: 協力者・専門家・法人化の予定】。

## 5. 実用化による社会発展性
事業化の区切りは、衛星指標とGMS3結果の対応データがどれだけ貯まったかで決める。一次通過後（2026年12月〜）はGMS3の提供エリアで対応データを作り、2027年前半は自治体の協力を得て比較エリアを広げ、最終選考向けに地図上のリスク表示を試作する。対応が複数エリアで確かめられた時点で有償提供に移り、その後に水道管・橋梁へ広げる。【本人加筆: 実証先候補・法人化時期】。想定ユーザーは自治体の下水道・道路部局と調査会社で、保険など民間への拡張も考えられる（推測）。国の全国特別重点調査（管径2m以上の大口径管が対象）では、対策が必要な延長748km、地盤中の空洞96箇所が確認された（令和8年4月公表）。本提案は、対象外の中小口径管や路面下で、調べる順序を低コストで付ける。技術職員が少ない小規模自治体でも、全数ではなく危険な路線から調べられるようになり、陥没事故の抑制と点検費用の平準化に寄与する。発生率は管路延長1,000kmあたり5.3件（令和4年度）で、順位付けにより事前に対処できる箇所が増えれば件数の低減につながる（効果は実証で確認する）。
