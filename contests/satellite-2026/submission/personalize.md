# 総司令官が本人にしか書けない箇所（提出前に必ず記入）

docx内で検索できる印は「【総司令官記入】」と「【本人加筆】」。A・Bとも同じ箇所があるため、両方を直すこと。

## 申請者欄（A・B共通。【総司令官記入】）
- 所属先（個人の場合の書き方は様式の指示に従う）、代表者氏名、ふりがな、部署名・役職、所在地（個人は居住地）、電話番号、E-mail
- 参加者欄（グループ用の3表）は個人応募なので空欄のまま。グループで出す場合のみ記入。

## 本文中の【本人加筆】
| 提案 | 項目 | 書く内容（置き換え後も450〜550字に収めること） |
|---|---|---|
| A | 4. 実現性・収益性 末尾 | 体制: 協力者・専門家・法人化の予定。「事業化の意思」を示す一文として最も重要 |
| A | 5. 社会発展性 段階計画の末尾 | 実証先の候補（自治体名・調査会社名など。実在の合意がなければ「候補として打診予定」）、法人化の時期 |
| B | 4. 実現性・収益性 末尾 | 同上（体制） |
| B | 5. 社会発展性 段階計画の末尾 | 実証先の候補、法人化の時期 |

## 提出前に総司令官が判断すること
1. 重複応募: FAQの「代表者が重複する場合は提案を1つにまとめる」が本アワードに当たるか、事務局に問い合わせるか（偵察隊レポート §7-1）。回答が得られない場合はA単独にする選択肢がある。
2. 事業化の意思: 本文は「事業化する」前提（段階計画あり）で書いている。意思がなければ選考対象外（要項p4）なので、本人の意思と合っているか確認すること。段階計画の時期（2026年12月〜、2027年前半、2027年度）も本人の計画に合わせて直す。
3. 時間: 一次通過後のワークショップ初回は12/9。2案とも通過した場合の稼働を確認。
4. 他コンペ（イチBiz等）で路面下・盛土の題材を使わないこと。
5. 提出前に Word で開き、体裁（図の表・チェックボックス・改ページ）を目視確認すること（作成環境にWord/LibreOfficeがなく、描画は未確認）。
