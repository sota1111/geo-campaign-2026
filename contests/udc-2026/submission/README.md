## 1. 送信前に決めること（総司令官）
1. 応募主体: 個人を想定。①と②で同じ氏名・連絡先にする（主体を変えると「同一主体の類似作品」の判断がかえって分かりにくくなる）。
2. 作品名: 各ファイルの「20字以内（推奨）」を既定とする。別案に替えてもよい。
3. 作品②を登録するか: 登録だけなら罰則なし。①の開発を優先するため、本応募は後で判断できる。

## 3. 字数の選び方
- 上限が明示されている → その上限以下で最も長い版を貼る（例: 300字上限なら200字版）。
- 上限がない自由記述 → 400字版。
- 1行の短い欄（「一言で」「キャッチコピー」等） → 40字以内の作品名か、100字版の第1文。
- どの版も上限を超える／中間の長さが欲しい → **データ名・機能・出典に当たる部分と、①の「鉄道駅が近い（未評価）」の区別・「5地域に限る」、②の「国の地図を土台に」の句は削らず**、修飾語と背景（冒頭の社会背景の文）から削る。数値や効果を書き足して膨らませない。
- 字数は改行を除く全文字（空白・句読点を含む）で数えてある。フォームが空白を数えない場合も上限内に収まる。

## 4. 想定と違った時の対応
| 状況 | 対応 |
|---|---|
| フォームが Google ログインを要求する | 総司令官のアカウントで進める。部隊はログインしない |
| 想定にない必須項目がある（例: 動機、チーム構成、想定利用者、使用技術） | 各ファイルの該当節（地域課題・本応募までの予定・使用予定データ）から抜粋する。合う材料がなければ「本応募時に詳述します」と書き、創作しない。判断に迷う項目は送信前に参謀長へ戻す |
| 他コンテストへの応募状況を聞かれる | ①:「公共交通オープンデータチャレンジ2026にも同じアプリで応募予定」と正直に書く（UDCは他コンテスト発表作品も応募可）。②: 衛星アワードの提出方針とは独立に扱う。衛星アワードへの言及はしない（設問が他コンテストへの応募の有無を必須で問う場合は、虚偽にならないよう総司令官が判断して記入する） |
| 作品タイプ・テーマの選択肢が想定と違う | ①は交通に最も近いもの、②は防災に最も近いものを1つ選ぶ。①と②が同じタイプ・同じテーマにならないこと |
| 特別賞の欄に「該当なし」がない（②） | 空欄のまま。必須の場合は「その他」等の最も中立な選択肢を選び、自由記述があれば「該当なし」と書く |
| 「重点分野」を聞かれる | 2026の重点分野は未確認（情報部）。公式ページで赤字の分野を確認し、①②のテーマと一致する場合のみ該当と答える |
| 送信後に修正したくなった | フォームの「回答を編集」リンクが出る設定なら編集。出ない場合は事務局（udc-office@aigid.jp）への連絡が必要。総司令官名義で行う |
| 1人1回しか送信できない設定 | 2作品を1回で書ける欄があるか確認。なければ事務局に問い合わせ（総司令官名義）。締切直前なら①を優先して登録する |
| 送信後の控え | 確認画面・確認メールを保存。入力した作品名・タイプ・テーマを reports/ops/ 等に後で記録できるよう手元に残す（本応募フォームで同じ内容が問われる可能性がある） |
