# 夜も使えるAED診断マップ（UDC2026 新案A 動くプロトタイプ）

自治体が公開したAEDのオープンデータ（利用可能曜日・開始/終了時間・緯度経度）と国勢調査の地域メッシュ人口から、選んだ曜日・時刻に徒歩圏（直線300/500/800m）で使えるAEDがない地区を地図に出す静的Webアプリです。地区別一覧、「ここに24時間使えるAEDを1台置くと徒歩圏に入る人」の試算、設置先候補（上位10件）とCSV出力を備えます。サーバー・APIキー不要。外部への送信はしません。

状態: 下書き（提出前）。現行の作品①②とは別の追加作品の候補です。公開・提出は総司令官が行います。

## 起動方法
```
cd contests/udc-2026/app/aed-night
python3 -m http.server 8831 --bind 127.0.0.1
# http://127.0.0.1:8831/ を開く（地図タイルと MapLibre はCDN・地理院タイルをブラウザが取得するためネット接続が必要）
```

## 対象自治体とデータ（実データ。サンプルは使っていません）
| 自治体 | データ | 登録数 | 地図に載る | 24時間 | 時間指定 | 不明 | 利用条件 |
|---|---|---|---|---|---|---|---|
| 町田市 | 町田市「AED設置箇所一覧」（標準形式） https://opendata.city.machida.tokyo.jp/en/dataset/shisetsu_aed | 337 | 288 | 14 | 274 | 0 | CC BY |
| 福岡市 | 福岡市「AED」（BODIK ODM、利用可能時間は自由記述） https://odm.bodik.jp/dataset/401307_aed | 1,139 | 1,139 | 114 | 544 | 481 | CC BY（BODIKの表示は Creative Commons Attribution） |
| 井原市 | 井原市「AED設置施設」（標準形式） https://odm.bodik.jp/dataset/332071_649_pdl | 75 | 75 | 12 | 53 | 10 | 公共データ利用規約 PDL1.0（BODIKの表示は pdl。CC BY 4.0 と互換とされる） |
| 倉敷市 | 倉敷市「AED設置施設」（標準形式） https://odm.bodik.jp/dataset/332020_496_pdl | 273 | 273 | 114 | 0 | 159 | 同上（PDL1.0） |

- 取得: 2026-11-13（町田市は 2026-11-09 更新の版）。件数は `data/aed.json` の `munis` に記録。
- 「地図に載る」は緯度経度のある台数。町田市は緯度経度の無い49台を載せられません。
- **時間表記を読めた割合**（24時間＋時間指定。分母は地図に載る台数）: 町田市 100%（288/288）、福岡市 57.8%（658/1,139）、井原市 86.7%（65/75）、倉敷市 41.8%（114/273）。解釈できない値は「不明」として数え、推測で埋めません。不明の理由別の内訳は画面の「4 データ」タブに出ます。
- 曜日が空欄で時刻だけの記載は、既定では不明です（自治体標準オープンデータセットの定義書は、曜日が定まっていない場合は空欄にして特記事項に理由を書くとしており、空欄を毎日と読む根拠がないため）。毎日と仮定すれば不明は福岡市332台、井原市3台に減りますが、画面の「不明も使える（最大見積）」側でのみ使います。
- **座標が市の範囲外のAED**: 元データの座標誤りと疑われるものが2台あり、除外せず印（`aed.json` の9番目の値、`munis[].out_of_range`）を付けて件数に数えています。町田市「高ヶ坂学童保育クラブ」（35.6904, 139.76613。東京都台東区付近）と倉敷市「玉島消防署 西出張所」（34.54202, 133.62704。市境から約1km超）。地図と判定には使いません。市の担当部署への確認はしていません。
- 倉敷市は24時間（00:00〜24:00・毎日）と読めた114台以外の156台が曜日・時間とも未記入で、時間帯による差が出ません。

クレジットは画面の「出典」欄とこの README に表示しています。再生成:
```
python3 -I tools/fetch_raw.py raw        # GETのみ。AED CSV・境界・メッシュ統計
python3 -I tools/build_data.py raw data  # 要 shapely。時間表記を正規化し data/ を作る
```
自治体の追加は `tools/sources.json` への追記（標準形式のCSVで緯度経度があること）。BODIK ODM での探索は `tools/discover_bodik.py`。標準形式でも緯度経度が空の自治体（例: 大網白里市）、利用可能曜日・時間がほぼ空の自治体（例: 松原市、那須塩原市）は対象外にしました。

## 限界（正直に）
- 「圏外」は**公開データ上の話**です。民間の24時間AED（コンビニ等）は載っていないことがあり、圏外＝AEDが無い、ではありません。画面に常時表示しています。
- 判定は250mメッシュ中心から使えるAEDまでの**直線距離**です。道路網・川・線路・坂は考慮せず、AEDを取って戻る往復も含みません。
- 祝日・年末年始・特記事項（「第2日曜は休み」等）は反映していません。
- 人口は夜間にその場にいる人数ではありません。メッシュ人口の合計は国勢調査の市人口よりやや少なくなります（町田市430,913人、福岡市1,607,363人。秘匿の影響）。
- 市の境界から800m以内のメッシュは、隣の自治体のAEDを読み込んでいないため圏外が多めに出ます（画面で破線表示）。
- 「地区」は500mメッシュ中心の住所（町丁目名）で付けた目安で、町丁目の境界とは一致しません。
- 設置先候補は「新たに徒歩圏に入る人」が多い順の貪欲法で、敷地・管理者・電源・見守りなどの設置可否は含みません。
- 時間帯別の使えるAED数は取得時点のデータで、更新・撤去は反映されません。
- 収益モデル・自治体が払う根拠は仮説で、このアプリでは扱いません。
