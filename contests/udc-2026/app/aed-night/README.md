# 夜も使えるAED診断マップ（UDC2026 新案A 動くプロトタイプ）

自治体が公開したAEDのオープンデータ（利用可能曜日・開始/終了時間・緯度経度）と国勢調査の地域メッシュ人口から、選んだ曜日・時刻に徒歩圏（直線300/500/800m）で使えるAEDがない地区を地図に出す静的Webアプリです。地区別一覧、「ここに24時間使えるAEDを1台置くと徒歩圏に入る人」の試算、設置先候補（上位10件）とCSV出力を備えます。サーバー・APIキー不要。外部への送信はしません。

状態: 下書き（提出前）。現行の作品①②とは別の追加作品の候補です。公開・提出は総司令官が行います。

## 起動方法
```
cd contests/udc-2026/app/aed-night
python3 -m http.server 8831 --bind 127.0.0.1
# http://127.0.0.1:8831/ を開く（地図タイルと MapLibre はCDN・地理院タイルをブラウザが取得するためネット接続が必要）
```

## 数字の決め方（2026-11-13 の修正で変えた点）
アグレッサーの攻撃（reports/aggressor/udc-2026-aed-20261113.md）で、元データの読み方に誤りが見つかったため、次のように直しました。

1. **自由記述の読み取り**（`tools/aed_time.py`）: 「開館日」の「日」を日曜、「4月～9月」の「月」を月曜と読んでいた誤りを直した。曜日は「月曜」「土日」「月～金」「平日」など曜日として書かれた形だけを読む。「土日休」「月曜休館」は休みの曜日を除いた曜日、「休館日：毎週月曜日」は月曜以外、「24時間（土日除く）」は平日。「午後1時～5時」は13〜17時（午後が両端に掛かる）。「終日」だけの記載は、開館中の意味でも使われるので24時間とは読まず「不明」にした（「24時間」「常時」などと書かれたものだけ24時間）。夜間は施錠・インターホンとあるもの、季節や月で時間が変わるもの、設置箇所ごとの条件が混ざったもの（①②…）、休館日以外とだけあって曜日がないものは「不明」。読み取れないものは「読めた」に数えない。分が60以上の時刻は不正とする。
2. **町田市の特記事項**: 288台中287台に特記事項があります。曜日と時間が書かれたものだけ反映しました（105台）。例: 学校の体育館など52台は、曜日欄が「毎日 17:00–21:00」で、特記に「土曜日、日曜日、祝休日の利用可能時間は8:00～21:00」とあるため、土日は8–21時。「日曜日…は終日利用不可」はその曜日を使えないとする。「施設の貸出がある場合のみ」「グラウンド使用時のみ」「カフェ営業時間中のみ」「有料開園期間…土日祝のみ」など条件付きの5台は不明にした。**反映していないもの**: 祝日・年末年始、「第1・第3月曜日」など週が限られるもの、「8月の」「5月中旬から8月中旬の」「夏季期間の平日」など季節や月が限られるもの、「土曜授業日」「学校閉庁期間」。これらを含め反映できなかったもの177台は、曜日欄・時間欄のままです（画面の地点表示に「特記あり・未反映」と出ます）。
3. **市境の扱い**: 隣の市のAEDを読み込めないため、市の境界から800m以内（最大の徒歩圏の半径）のメッシュは、画面では**見出しの数字から外し**、含めた全体の数字は「上限」として別の行に出します（地図では破線のまま）。外す方を選んだ理由: 市境の近くの人は隣の市のAEDを使える可能性があり、読み込んでいないものを「圏外」と数えると過大になる。隣の市のデータを足す案は、自治体の追加が増えて期限内に確認しきれないため採らなかった。町田市はメッシュ人口430,913人のうち255,695人（59.3%）が市境付近で、内側は175,218人です。福岡市は452,404人（28.1%）、井原市は5,713人（16.4%）、倉敷市は79,841人（16.9%）が市境付近。市境付近は地区別一覧でも「境界付近を含む」と表示し、チェックで除外できます。
4. **登録台数**: 町田市は288台（上の表のとおり）。
5. **「使える台数」と一般の人が使えない設置位置**: 画面と提出文は台数に加えて**設置か所数**（同じ座標を1か所と数える）を出す。町田市の午前3時は11台・2か所（町田市民病院の10台＋薬師池公園警備室の1台）で、以前の「14台」は病院の13台のうち、救急車内・南棟10階病棟内廊下・東棟1階口腔外科外来の3台を含んでいた。**一般の人が使えない設置位置**は、救急車の中、病室・病棟内の廊下、診察室・診療室・医務室・処置室・手術室、外来診療の部屋（設置位置の文字に「救急車」「車内」「病棟内」「病室」「診察室」「診療室」「医務室」「処置室」「手術室」「調剤」「外来」がある。「外来及び病棟各階ロビー」のような共用部は除く）として、**台数・圏内の判定に入れず**、地図に灰色で示す（町田市4台・福岡市10台・井原市2台・倉敷市3台）。ロビー・コンコース・玄関などの共用部は数える。ただし病院・施設の共用部に**夜間に一般の人が入れるか**は元データから確認できないため、町田市の午前3時の「2か所」は、うち1か所（町田市民病院）が夜間に入れない場合は1か所になる。事務所・事務室・職員室の「中」にあり24時間とされたものは、施錠される部屋の可能性が高いため不明にした（外壁の収納ボックスや入口付近は除く）。
6. **「平日」**: 以前のプリセットは月曜（祝日と月曜休館が多い曜日）で「平日」を代表させていた。プリセットを水曜に変え、見出しに「同じ時刻で月〜金を比べると X%（月曜）〜Y%（○曜）」を出す。祝日は反映していない。
7. **最大見積の幅**: 「不明も使える」は、夜間（22時〜翌6時）には、理由が「施設の開館時間」「条件付き（学校使用時のみ・施錠など）」「季節別」「終日の意味が不明」「休館日の曜日なし」「複数箇所の混在」の不明を使えるとみなさない。未記入・曜日なし・曜日だけ等は、夜に使えないとも言えないので、使えるとみなす。
8. **ライセンス表記**: Geoshape は公式表記（CC BY 4.0）に合わせた。井原市・倉敷市は岡山県の規約の出典表記（上の表）。
9. 軽微: 途中で切れた共有URL（`#m=%E0` など）でも既定値で起動する。人口の注記は、国勢調査が常住人口なので深夜の在宅に近く、昼（14時など）は実際の人の分布とずれる、に直した。

## 限界（正直に）
- 「圏外」は**公開データ上の話**です。民間の24時間AED（コンビニ等）は載っていないことがあり、圏外＝AEDが無い、ではありません。画面に常時表示しています。
- 判定は250mメッシュ中心から使えるAEDまでの**直線距離**です。道路網・川・線路・坂は考慮せず、AEDを取って戻る往復も含みません。メッシュの角では中心から最大約177m（125m×√2）ずれるため、300mの設定では誤差が半径の半分以上になります。既定の500mが、救急医療の「何分以内」の基準とどう対応するかは確認していません（ガイドラインは未確認）。
- 祝日・年末年始、週や季節が限られる特記事項（「第2日曜は休み」「夏季は…」等）は反映していません。町田市は、曜日と時間が書かれた特記事項だけ反映しました。
- 人口は令和2年国勢調査の常住人口で、深夜の在宅人口に近く、昼間の人の動き（通勤・通学）は含みません。メッシュ人口の合計は国勢調査の市人口よりやや少なくなります（町田市430,913人、福岡市1,607,363人。秘匿の影響）。
- 市の境界から800m以内のメッシュは、隣の自治体のAEDを読み込んでいないため圏外が多めに出ます。見出しの数字は、これを外した人口で数えます（上記3）。
- 「地区」は500mメッシュ中心の住所（町丁目名）で付けた目安で、町丁目の境界とは一致しません。
- 設置先候補は「新たに徒歩圏に入る人」が多い順の貪欲法で、敷地・管理者・電源・見守りなどの設置可否は含みません。
- 時間帯別の使えるAED数は取得時点のデータで、更新・撤去は反映されません。
- 作品①（GTFS診断マップ）と同じ型（メッシュ×時間帯×「1つ変えると何人」）です。違いは題材・データ・受け手で、entry-3 の「差別化」に書きました。
- 収益モデル・自治体が払う根拠は仮説で、このアプリでは扱いません。
