# みんなの盛土ウォッチ（UDC2026 作品② 動くプロトタイプ）

住民が身近な盛土造成地を地図で確かめ、昔の空中写真と見比べ、現地で気づいた変化（亀裂・湧水・崩れ等）をこの端末に記録し、自治体の窓口に伝える通報文のたたき台と GeoJSON/CSV にするための静的Webアプリです。サーバー・APIキー不要。記録は端末の localStorage だけに保存し、外部へ送信しません。

状態: 下書き（提出前）。公開・提出は総司令官が行います。

## 起動方法

```
cd contests/udc-2026/app/moritsuchi-watch
python3 -m http.server 8821 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8821/ を開く
```

`data/fills.geojson` を fetch するため、file:// ではなく上記のようにサーバー経由で開きます。地図タイルと MapLibre は CDN（unpkg、版固定・SRI付き）と地理院タイルをブラウザが GET します（インターネット接続が必要）。

## 体験の流れ
1. 確かめる: 熱海市・伊東市の大規模盛土造成地（色付き）を地図で見る。背景を切り替え、「昔の写真」（1961〜69年／1974〜78年）と現在の背景をスライダーで見比べる。表示状態は URL のハッシュに入り、URLのコピーで共有できる。
2. 記録する: 地図をタップ（または現在地）で位置を決め、気づいたこと・日時・メモを保存。最寄りの盛土造成地との位置関係を自動で付ける。位置を約100mにぼかす選択肢あり。
3. 届ける: 記録ごとに通報文のたたき台を生成してコピー。GeoJSON/CSV の書き出し、GeoJSON の読み込み（仲間の記録の取り込み）。

## データ（実データ）
| データ | 出典 | ライセンス | 加工 |
|---|---|---|---|
| 大規模盛土造成地 A54（2023年版、データ基準日 2023-03-31、静岡県分） https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A54-2023.html | 国土交通省 国土数値情報 | CC BY 4.0 | 熱海市14か所・伊東市13か所を抽出、座標を小数5桁に丸め、GeoJSON化（`tools/build_data.py`）。2026-11-11 取得 |
| 地理院タイル（標準・淡色・シームレス空中写真・年代別の写真 1961〜1969年 `ort_old10`／1974〜1978年 `gazo1`） https://maps.gsi.go.jp/development/ichiran.html | 国土地理院 | 国土地理院コンテンツ利用規約 | 無加工（ブラウザが直接取得） |
| MapLibre GL JS 4.7.1 | MapLibre | BSD-3-Clause | CDN |

サンプル（架空）データは使っていません。A54 の注意事項（画面にも表示）: 安全性の確認が必要な盛土造成地であり、直ちに危険な盛土造成地ではない。すべての盛土造成地が抽出されているわけではない。重要事項説明等の根拠には使えない。

再生成: `python3 -I tools/fetch_raw.py <作業ディレクトリ>`（GETのみ）で国土数値情報から取得し、`python3 -I tools/build_data.py <作業ディレクトリ>/A54-23_22_GML/A54-23_22.xml data/fills.geojson`。

## 限界（正直に）
- 対象は熱海市・伊東市のみ。範囲外では盛土造成地は出ず、範囲外の記録には注記が付く。
- 盛土造成地の範囲は「概ね」の位置。危険かどうかの判定、変化の自動検出はしない。昔の写真との見比べは目視で、地理院タイルの撮影年・提供範囲に依存する（提供範囲外は空白）。
- 土砂災害警戒区域・盛土規制法の規制区域は表示しない（国の重ねるハザードマップを案内するのみ）。
- 写真は保存しない（容量と個人情報の観点）。通報の送信もしない。通報先は自治体ごとに異なるため案内にとどめる。
- 記録はブラウザのデータ削除で消える。端末間の同期はなく、共有は書き出したファイルで行う。
- 位置のぼかしは小数3桁への丸め（約100m）であり、匿名性を保証するものではない。
- 地図タイルの取得には地理院サーバーへの通信が発生する（閲覧位置はタイル要求から分かる）。記録の内容は送信されない。
