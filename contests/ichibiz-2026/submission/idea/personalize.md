# アイデア部門 本人加筆ガイド（I2 地名に残る災害記憶マップ）

目的: 生成AIの出力そのままと見なされないよう、本人の経験・判断を入れる。
【本人加筆: …】の括弧書き全体（【】含む）を、本人の文に置き換える。括弧書きの長さ程度に収めると上限内に収まる。置換後に必ず `python3 contests/ichibiz-2026/check_limits_divisions.py` を実行する。
地名と災害の因果を断定する文は足さない（足すなら出典を sources.md に書き、「諸説」と添える）。

| 場所 | 問いかけ | 書き方のヒント |
|---|---|---|
| problem.md 1段落目末 | 自分の地域の災害の話を、誰かから聞いたことはあるか。調べて初めて知った過去は | 「誰から・いつ・何を」。知らなかったという驚きがあればそれも |
| service.md 末尾 | 自分の地域でまず誰と何を試したいか（学校、自治会、家族、友人） | 1文。現実に頼める人がいればその属性 |
| background.md 冒頭 | 出身地や住んでいる地域の地名で、由来が気になったものは。災害にまつわる見聞は | 地名そのものを出すかは本人判断（地名への偏見を生まない配慮が必要） |
| background.md 2か所目 | 「散らばった資料を地図で見たい」と感じたのは実際にはどんな場面か | 実際のきっかけに書き換える。違うなら削除 |
| background.md 3か所目 | 「災害の備えは自分の場所の話として聞いた記憶が行動につながる」に同意できるか。自分の言葉なら | 同意できなければ削除して、自分の考えを書く |

提出前の確認
- 国土地理院の自然災害伝承碑・旧版地図の公開形式と利用条件を確認（sources.md参照）。使えないデータは本文から外す。
- 衛星データアワードに出す案（災害リスクの可視化）と、題材が近いと見えないか。本案は危険度を判定しない点を本人の言葉で強調してよい。
- 地名を実名で挙げる場合は、その地名への偏見につながらないか確認する。
