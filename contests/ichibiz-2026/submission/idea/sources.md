# アイデア部門 出典・確認状況（応募フォームには貼らない。内部用）

本文に数値は書いていない。書いた事実と根拠は次のとおり。

| 本文の記述 | 根拠 | 状況 |
|---|---|---|
| 国土地理院が自然災害伝承碑を公開している | 国土地理院「自然災害伝承碑」（地理院地図・ハザードマップポータルサイトで公開） | 未確認。提出前に公式ページで公開形式（地図表示のみか、データ取得可か）とライセンス（測量法・利用規約）を確認 |
| 旧版地図が利用できる | 国土地理院の旧版地図（古い地図の閲覧・入手サービス） | 未確認。利用条件を確認 |
| 現代のハザード情報（洪水浸水想定など）に切り替えられる | ハザードマップポータルサイト（国土交通省・国土地理院）の重ねるハザードマップ | 未確認。「構想では」の位置づけ。実装不要部門 |
| 地名（小字・旧地名）のデータ | 全国一括の公式データがあるとは確認していない。自治体史、地名辞典、図書館資料、住民の聞き取りで補う前提 | 未確認（偵察レポートでも要確認） |

注意
- 地名と災害の因果は断定しない。本文は「関係が語られている」「諸説」という表現にそろえている。因果を示す文を足さないこと。
- 地名由来の説を例として挙げる場合は、必ず出典（文献名・自治体史）を付ける。出典を付けられない例は書かない。
- 衛星データアワードの案（災害・インフラリスクの可視化）と近接して見える可能性がある。本案は危険度の判定をせず、語り継ぎ・住民参加を軸にしている。本文でもその違いを明記した。
