# 相談前の1枚シート（イチBizアワード2026 不動産情報活用部門・動くデモ）

相続した土地を地図で指すと、公開データから判断材料を集め、「売る・貸す・活かす・手放す」の4つの出口ごとに「専門家に聞くこと」を並べた1枚シートを出す。印刷（PDF保存）できる。静的ファイルのみ。この単体版の画面はサーバー・APIキー不要（APIキーは、ダッシュボード版が使う不動産情報ライブラリのデータを取り直すときだけ使う。下記）。

**提出する試作の正本はダッシュボード版**（`contests/dashboard/src/apps/biz-realestate/`）。不動産情報ライブラリの取得結果（区域区分・地価公示/地価調査・取引価格）を表示するのはダッシュボード版だけで、この単体版は表示しない。提出文（`contests/ichibiz-2026/submission/realestate/`）の「試作」はダッシュボード版を指す。

## 起動
```
cd contests/ichibiz-2026/app/realestate/web
python3 -m http.server 8826 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8826/ （地理院のサーバーへ画像を取りにいくためネット接続が必要）
```

## 使い方
1. 地図をクリック（タップ）して土地の位置を指す（住所検索も可）。
2. 地図で分からないこと（建物・地目・接道・相続登記）を選ぶ（任意）。
3. 「印刷・PDFで保存する」。印刷用CSSでA4・1枚に収まる。
「サンプル（架空）の土地」ボタンで、地図を指さずに見本シートを見られる。

## 不動産情報ライブラリのデータ（reinfolib.json）
- 中身: 徳島市（36201）の区域区分175件（XKT001）、地価公示・地価調査の標準地150点（XPT002、2025年）、取引価格（XIT001、取引価格のみ）の「宅地(土地)」440件を町名別（3件以上の町名43件）と市全体で集計した1平方メートル単価の中央値（取引時期 2024年第1四半期〜2025年第4四半期）。個別の取引・APIキーは含まない。
- 作り方: ダッシュボード版の `fetch-reinfolib.ts` が API から取得・整形してここに書き、ダッシュボードのビルド時に `scripts/copy-data.mjs` が `public/data/biz-realestate/` へ複写する（手順は `contests/dashboard/src/apps/biz-realestate/README.md`）。ここに置いているのは、ダッシュボード版のデータの置き場所がこのフォルダのため。
- 使う場所: ダッシュボード版だけ。この単体版の `app.js`・`lib.js`・`index.html` は読み込まず、画面には出さない。
- 表示している出典・クレジット（ダッシュボード版の画面・シート・印刷。文言は `contests/dashboard/src/apps/biz-realestate/reinfolib.ts` の定数どおり）:
  - 出典（利用規約「コンテンツの利用に係るPDL1.0に関する重要情報」(1)の記載例どおり）: 出典：国土交通省　不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）
  - API利用規約 第7条のクレジット（規約の文言のまま）: このサービスは、国土交通省の不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません
  - 加工の旨: 「不動産価格（取引価格）情報」「地価公示・地価調査」「都市計画決定GISデータ（区域区分）」（国土交通省）をもとに作成者が集計・照合して作成
- 取引価格の行は、住所（町名）が取れた地点でだけ出る（国土地理院の逆ジオコーダが返す町名が町名別集計に一致すれば町名単位、徳島市内で集計の無い町名なら市全体の中央値）。
- 注意: この単体版の `web/` をそのまま公開すると、上のクレジットを表示しないまま `reinfolib.json` も配布される。単体版を公開する場合は、`web/data/reinfolib.json` を公開物から外すこと（外しても単体版の画面は変わらない）。

## 守っていること
- 金額・査定・収益の数値は一切出さない。「売るべき」等の結論を出さない。すべて「〜を〇〇に聞く」の形（テストで検査）。
- 入力と指した位置は端末内のみ。保存・送信しない。外部へのPOSTなし。外部へのリクエストはGETのみ（地理院のタイル・住所検索）。
- 通信に失敗した災害データは「該当なし」と書かず「取得できなかった」と出す。

## 限界
- 地図データ（用途地域・公共交通）は徳島市のみ。範囲外は出せない旨をシートに出す。災害・標高は全国で動く。
- 用途地域は2019年度版で、最新の都市計画とは異なりうる。「用途地域の指定なし」は、市街化調整区域・都市計画区域外・データの古さのどれかの可能性としか言えない（区域区分は不動産情報ライブラリのXKT001で取得済みで、ダッシュボード版では表示するが、この単体版の画面では表示しない）。
- 災害リスクは1画素の色の判定。区域境界付近の誤差がある。洪水の深さは凡例色（目安）。
- 公共交通は便数・運行日を含まない。
- 接道・地目・建物の状態・境界は公開データにないため、「データにない項目」として相談先で確かめる形にしている。
- 法務・税務の助言ではない。相談先の指定（司法書士・法務局・農業委員会など）は一般的な目安。
