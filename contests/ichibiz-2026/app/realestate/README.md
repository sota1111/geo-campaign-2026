# 相談前の1枚シート（イチBizアワード2026 不動産情報活用部門・動くデモ）

相続した土地を地図で指すと、公開データから判断材料を集め、「売る・貸す・活かす・手放す」の4つの出口ごとに「専門家に聞くこと」を並べた1枚シートを出す。印刷（PDF保存）できる。静的ファイルのみ。サーバー・APIキー不要。

## 起動
```
cd contests/ichibiz-2026/app/realestate/web
python3 -m http.server 8826 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8826/ （地理院のサーバーへ画像を取りにいくためネット接続が必要）
```

## 使い方
1. 地図をクリック（タップ）して土地の位置を指す（住所検索も可）。
2. 地図で分からないこと（建物・地目・接道・相続登記）を選ぶ（任意）。
3. 「印刷・PDFで保存する」。印刷用CSSでA4・1枚に収まる。
「サンプル（架空）の土地」ボタンで、地図を指さずに見本シートを見られる。

## データと出典（実データかサンプルか）
| 項目 | 種別 | 出典・ライセンス |
|---|---|---|
| 背景地図 | 実データ（実行時に取得） | 国土地理院タイル（標準地図）。出典表示あり |
| 洪水・高潮・津波・土砂災害の区域 | 実データ（実行時にタイル1枚をGETし、指した1画素の色を読む） | ハザードマップポータルサイト（国土地理院）の公開タイル `disaportaldata.gsi.go.jp/raster/...`。キー不要。404=区域外として扱う |
| 標高 | 実データ（参考値） | 地理院標高タイル dem_png（z14） |
| 用途地域・建ぺい率・容積率 | 実データ（`web/data/tokushima.json` に同梱。徳島市のみ） | 国土数値情報 用途地域データ A29-19（令和元年度版・徳島県、国土交通省）を加工。CC BY 4.0（一部制限）。**各市区町村の利用条件あり。徳島市分の条件は未確認（公開・提出前に要確認）** |
| バス停・鉄道駅 | 実データ（同梱。直線距離のみ） | GTFSデータリポジトリ掲載の徳島市営バス・徳島バス・上八万コミュニティバス・松茂町・北島町・鳴門市の各GTFS（CC BY 4.0）。`contests/odpt-2026/app/web/data/tokushima.json` から抜粋 |
| 住所検索 | 実データ | 国土地理院 住所検索API（キー不要のGET） |
| 見本シート | **サンプル（架空）** | 実在の土地ではない。市街化調整区域・浸水想定区域内・建物付きという提案書の見本の前提を再現 |
| 取引価格・地価公示・将来人口・医療機関・小学校区 | **取得していない** | 国土交通省「不動産情報ライブラリ」で確認する項目として、シートに文字で示すだけ（APIキー未申請のため） |

サービス名に「不動産情報ライブラリ」は含めていない（出典表記としてのみ登場）。

## 守っていること
- 金額・査定・収益の数値は一切出さない。「売るべき」等の結論を出さない。すべて「〜を〇〇に聞く」の形（テストで検査）。
- 入力と指した位置は端末内のみ。保存・送信しない。外部へのPOSTなし。外部へのリクエストはGETのみ（地理院のタイル・住所検索）。
- 通信に失敗した災害データは「該当なし」と書かず「取得できなかった」と出す。

## 限界
- 地図データ（用途地域・公共交通）は徳島市のみ。範囲外は出せない旨をシートに出す。災害・標高は全国で動く。
- 用途地域は2019年度版で、最新の都市計画とは異なりうる。「用途地域の指定なし」は、市街化調整区域・都市計画区域外・データの古さのどれかの可能性としか言えない（区域区分は不動産情報ライブラリのXKT001相当の項目で、この画面では取得していない）。
- 災害リスクは1画素の色の判定。区域境界付近の誤差がある。洪水の深さは凡例色（目安）。
- 公共交通は便数・運行日を含まない。
- 接道・地目・建物の状態・境界は公開データにないため、「データにない項目」として相談先で確かめる形にしている。
- 法務・税務の助言ではない。相談先の指定（司法書士・法務局・農業委員会など）は一般的な目安。

## テスト
```
node --test contests/ichibiz-2026/app/realestate/tests/lib_test.js     # ロジック16件
node contests/ichibiz-2026/app/realestate/tests/ui_shot.mjs http://127.0.0.1:8826/ <出力先>   # 手動確認: 実クリック→シート→スクリーンショット
```
スクリーンショットは `screenshots/` （デスクトップ1280px・スマホ390px・印刷プレビュー・PDF）。
ブラウザのコンソールには、土砂災害タイルが「区域外」で 404 を返すログ（想定どおりの動作）が出る。
