# 地名の記憶マップ（デモ）— イチBizアワード2026 アイデア部門

提案「地名の記憶マップ　語り手がいるうちに、土地の災害の話を確かめて地図に残す」の考え方を、触って確かめるための最小限の静的Webアプリ。アイデア部門は実装不要なので、審査用の補助資料（独創性・実現可能性の説明）という位置づけ。

## 画面で体験できる流れ
1. **地名を選ぶ**: 地図上のオレンジのピン、または一覧から選ぶ（地図の何もない所をタップして新しい位置を指定することもできる）。
2. **公開データで確かめる**: 選んだ地名の位置から半径内の「自然災害伝承碑」（実データ）を探し、語られている災害の種類（洪水・土砂災害など）と碑の種類を突き合わせる。結果は「手がかりあり」か「公開データでは見つからず」の2通りで、**危険度は判定しない**。国土地理院の空中写真（1945〜50年・1961〜69年）、明治期の低湿地、治水地形分類図、色別標高図を重ねて、人が目で確かめた内容をチェックで記録できる。
3. **聞き取りを記録して地図に残す**: 語り手・出典・確からしさ（定説／諸説／不明）・公開範囲・利用条件を入力して保存。新規は必ず「未確認」。「確認役として確認済みにする（デモ）」で確認済みになり、「本人・家族の求めで非公開」「削除」もできる。**公開分**（確認済み・公開・利用条件あり）と、非公開以外すべてを GeoJSON で書き出せる。

## 起動方法
```
cd contests/ichibiz-2026/app/idea
python3 -m http.server 8825 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8825/ を開く
```
サーバー側の処理・APIキーは不要（静的ファイルのみ）。地図部品（MapLibre GL JS 4.7.1）を unpkg.com から、地図タイルを国土地理院から読み込むため、ネットワーク接続が必要。記録の保存は localStorage、書き出しはブラウザ内で作ったファイルのダウンロードのみ（外部へのPOSTなし）。

## テスト
```
node --test tests/lib.test.js          # ロジックの単体テスト（11件。node 22）
node tests/ui_flow.mjs http://127.0.0.1:8825/ shots   # ヘッドレスChromeでの通し確認（サーバー起動後）
```
`ui_flow.mjs` は デスクトップ1280×800 とスマホ390×844 で、選択→突き合わせ→記録→確認→書き出し→非公開→出典表示までを通し、コンソールエラーなし・横スクロールなしを検査し、`shots/` にスクリーンショットを保存する。

## 限界（正直に）
- 突き合わせは「語られた災害の種類」と「近くの伝承碑の種類」を比べるだけの簡易なもの。碑がないことは災害がなかったことを意味せず、碑があることは地名との因果を示さない。危険度は判定しない（提案の方針どおり）。
- 空中写真・低湿地・治水地形分類図の重ね合わせは、人が見て判断する。自動判定はしない。
- 「確認役」はボタンによる模擬で、本人確認・権限管理・複数人での共有はない（localStorage は端末内のみ）。
- 対象は1地域（広島市安佐南区周辺）、収録の伝承碑は15件のみ。全国展開・運営体制・個人情報や肖像・著作物の扱いの規約は未実装・未検討。
- 位置は地図上の仮置きで、小字の境界などの精度は持たない。
- 効果・利用者数・費用などの数値は一切示していない。
