# 23区、値段の年表（イチBizアワード2026 不動産情報活用部門・新案「時間地図」）

東京23区を、区より小さい**地区（町名）**ごとに、中古マンションの㎡単価（中央値）で塗る。**間取り**（5区分）を選び、時間（**年**）のスライダーと再生ボタンで推移を動かして見る。地区を押すと、その間取りの折れ線（区全体との比較つき）・半数の取引の幅・件数・築年数と面積の中央値を出す。件数が10件未満の地区・年は「件数が少ない」と明示し、斜線と薄い色にする。件数が3件未満（0件を含む）は中央値を出さず「データなし」にする。借家の家賃は**区ごと**にしか公表されていないため、区別の表示として残し、間取り・地区には対応しないと画面に明記する。静的ファイルのみ（実行時にサーバー・APIキー不要）。

現行案（`../realestate/`）・RN1・A4 は変更していない。**追加の候補**で、どれを出すかは総司令官が決める。提出文の下書きは `../../submission/realestate-timeline/`（検査: `python3 contests/ichibiz-2026/check_limits_timeline.py`。本人欄が未記入のうちは終了コード1）。

- **不動産情報ライブラリに家賃のデータはない**（API一覧に賃料の項目なし）。家賃は公的統計から取り、区ごとのまま出す。**地区（町名）×間取り別の公的な家賃データは見つからなかった**ので、無理に作っていない（賃貸の取引件数も無い）。
- 家賃は「その年（その年の10月1日の調査を含む）までの最新の調査」の値を、次の調査まで同じ値で出す（画面に明記）。2009年以降のスライダーなので2008年の調査点はグラフに出ない。
- 最後の年（2026）は2026年6月までの取引。登録が途中の取引は含まれない（画面に注意）。
- 築年数は取引時点との差（和暦を西暦に直し、読めないものは除外）。㎡単価は TradePrice÷Area で作成者が計算（UnitPrice は使わない）。

## 範囲の単位と突き合わせ率
- XIT001 の「地区名」（DistrictName）を、同じ区コードの小地域の町名（「◯丁目」を外したもの）と**名前で突き合わせた**。
- **860地区名のうち 860件（100.0%）が一致**。直近5年の取引件数ベースでも 62,918件中 62,918件（100.0%）。合わなかった件数は 0。
  - 最初は 856/860（99.5%）。残る4件のうち2件は異体字（松濤→松涛、鶯谷町→鴬谷町）で、表記ゆれとして吸収。2件は「神田猿楽町→猿楽町」「神田三崎町→三崎町」（千代田区に同名の町が他に無いことを確認）で、`tools/build-districts.py` の `ALIAS` に明記。
- 境界だけがあり取引のない町名が **75地区**（灰色。「データなし」）。
- **名前の一致であって、範囲が完全に同じとは限らない**（XIT001 の地区名の範囲と、2020年国勢調査の小地域の範囲が一致する保証はない）。地区名が空欄の取引 109件は地区別に入らない。
- 画面の地図は簡略図（測量・権利の根拠ではない）。

## 間取りの分け方（理由）
取引の FloorPlan（全角）の件数: 1K 80.5千・3LDK 56.4千・2LDK 43.3千・1LDK 23.8千・1DK 13.8千・空 11.2千・2DK 9.9千・1R 4.8千・4LDK 4.4千・3DK 2.4千 ほか。部屋数の順に、件数がなるべく近くなる4つに分けた。

| 区分 | 含む間取り | 件数（全期間） |
|---|---|---|
| 1R〜1K | ワンルーム・スタジオ・1R・1K（+S） | 約85千 |
| 1DK〜2DK | 1DK・1LDK・2K・2DK（+S） | 約49千 |
| 2LDK〜3DK | 2LDK・3K・3DK（+S） | 約47千 |
| 3LDK以上 | 3LDK・4部屋以上（+S） | 約61千 |
| すべて | 上記＋間取り欄が空・オープンフロア・メゾネット | 256,042 |

最初の案「1R〜1DK／1LDK〜2DK／…」は、1R〜1DK が約99千件・1LDK〜2DK が約35千件と偏り、後者で「件数が少ない」が増えるため、1DK を 1LDK・2DK の側に入れた。

## 時間の単位と「件数が少ない」の基準（作成者の基準）
- 地区×間取り×**四半期**は件数が足りない（860地区に25.6万件。1年でも多くの地区×間取りで0〜数件）。時間は**年**にし、各年の値は**その年を末尾とする直近5年（年の窓）**の取引の中央値とした。窓の長さ・基準を変えたときの「件数が少ない」の割合を `--survey` で測って決めた（基準10件で、値のあるセルのうち「少」の割合は、窓1年が51〜94%、窓3年が23〜76%、窓5年が18〜63%。「すべて」と、最初の案の間取り4区分での測定。最終の区分での実測は下の表）。
- **件数が10件未満は「件数が少ない」**（斜線・薄い色・※）、**3件未満は中央値を出さず「データなし（n件のみ）」**、0件は「データなし（0件）」。**この基準（10件・3件・5年）は作成者の基準で、統計上の根拠となる出典はない**。
- 最初の窓（2009）は 2005年第3四半期〜2009年（取引価格の公開開始から）。最後の窓（2026）は 2022年〜2026年6月。

## 件数不足セルの割合（実測。935地区 × 18年）
4つの間取り区分 × 935地区 × 18年 = 67,320セルのうち（「すべて」を除く）:

| 状態 | セル数 | 割合 |
|---|---|---|
| 件数が十分（10件以上） | 29,676 | 44.1% |
| 件数が少ない（3〜9件。斜線） | 17,085 | 25.4% |
| 3件未満（データなし） | 7,163 | 10.6% |
| 0件（データなし） | 13,396 | 19.9% |

値を出せるセル（46,761）のうち 36.5% が「件数が少ない」。「すべて」（5区分目）は、935地区×18年 = 16,830セルのうち 十分 79.1%・少 9.0%・3件未満 2.4%・0件 9.5%。間取り別（1R〜1K / 1DK〜2DK / 2LDK〜3DK / 3LDK以上）で値を出せるセル中の「少」は 26.6 / 40.7 / 42.6 / 36.4%。最新の年（2026）・すべてでは、935地区のうち値を出せるのは 826、その9%（73）が少、データなしは 109。画面の凡例に、いまの間取り・年の割合を常に出す。

## 画面の構成
広い画面は左に地図（画面の約66〜70%）・間取りの切り替え・時間の操作、右に凡例と「地区の推移」。狭い画面（900px以下）は縦に積む。
- 切り替え: 「マンション価格（地区）／家賃（区）」と、間取り5つ（押している方に ✓。家賃のときは間取りを選べず薄く表示し、地図に理由を出す）。
- 地図: 地区を塗り、**区の境界は太線**、地区の境界は細線。地区名と値は拡大して地区が十分大きいときだけ出す（小さい縮尺では区名だけ）。凡例の階級は固定。灰色は「データなし」。選んだ地区は太い縁。
- 時間: スライダー（年。キーボード可）と ▶再生／■停止（650ms/年）。
- 地区を押す（または「地区名で探す」・順位表）: 折れ線（地区の中央値・半数の取引の帯・件数が少ない年の白丸・区全体の灰色の線・今の年の点線）、数値の表。グラフを押すとその年へ移る。詳細は区ごとのファイルを遅延読み込み。
- 色だけに頼らない: 値の数字、斜線、「件数が少ない」の文字、太い縁、順位表、地区名の検索。390px で横スクロールなし。

## 限界・次にやること
- 中央値は地区内の築年・広さ・駅距離の構成の違いに左右される（詳細に築年数・面積の中央値を併記）。小さな地区は1件の入れ替わりで動く。
- 「直近5年の窓」は変化をなだらかにし、急な変化の時期を後ろにずらす。単年の値ではない。
- 件数の基準（10件・3件）・窓の長さ（5年）は作成者の基準（根拠となる出典なし）。
- 家賃は区別・5年ごと・借家全体。間取り・地区の家賃は出せない。
- 地区名と小地域の突き合わせは名前の一致。範囲の同一は保証しない。
- 家賃と価格の関係の評価（利回り等）は出していない（根拠データがないため）。
