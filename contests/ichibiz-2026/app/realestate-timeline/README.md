# 23区、値段の年表（イチBizアワード2026 不動産情報活用部門・新案「時間地図」）

東京23区を、中古マンションの㎡単価（四半期ごとの中央値）または借家の1畳当たり家賃で塗り、時間のスライダーと再生ボタンで推移を動かして見る。区を押すと折れ線・半数の取引の幅・件数・築年数と面積の中央値を出す。件数が30件未満の区・期は「件数が少ない」と明示し、斜線と薄い色にする。静的ファイルのみ（実行時にサーバー・APIキー不要）。

現行案（`../realestate/`）・RN1・A4 は変更していない。**追加の候補**で、どれを出すかは総司令官が決める。提出文の下書きは `../../submission/realestate-timeline/`（検査: `python3 contests/ichibiz-2026/check_limits_timeline.py`）。

## 使ったデータ（2026-11-21 時点）
| 項目 | 出典・粒度 | 期間・件数 | 条件 |
|---|---|---|---|
| マンション価格 | 不動産情報ライブラリ XIT001（取引価格のみ・priceClassification=01）、Type=「中古マンション等」、23区、面積10〜300㎡ | 2005Q3〜2026Q2（84四半期。マニュアルの記載どおり取引価格は2005年第3四半期から）。使えた取引 256,042件。区×四半期 1,932セル。件数の最小16、中央値約123 | 出典・加工・クレジット・責任を画面に表示（a4 と同じ文言）。生データは保存せず集計だけ同梱 |
| 家賃 | 総務省統計局「社会・人口統計体系」の指標「専用住宅の1畳当たり家賃」（元は住宅・土地統計調査）、市区町村別、e-Stat 統計ダッシュボードAPI（登録・キー不要） | 2008・2013・2018・2023年（5年ごと、各10月1日）の4時点×23区 | 統計ダッシュボードAPIのクレジット文言を表示（https://dashboard.e-stat.go.jp/static/api）。借家全体（公営・公社・民営・給与住宅）の平均で、民営賃貸だけではない |
| 区の境界 | 国土数値情報 行政区域データ N03 2025年版 東京都（国土交通省） | 23区、外周のみ約12mで単純化（96KB） | 出典表示。簡略図 |
| 背景地図 | 国土地理院 淡色地図タイル | — | 出典表示 |

- **不動産情報ライブラリに家賃のデータはない**（API一覧 XCT/XGT/XIT/XKT/XNT/XPT/XST に賃料の項目なし）。そのため家賃は公的統計から取った。
- **取れなかったもの**: 家賃の四半期・年ごとの市区町村別データ（住調は5年ごと）。民営賃貸マンションだけの家賃（市区町村別では公表指標にない）。賃貸の取引件数。
- 家賃は「調査年の10月1日時点の値」を、その四半期以降次の調査まで同じ値で出す（画面に「次の調査まで同じ値」と明記）。2008年第3四半期以前は家賃なし。
- 最新の2四半期（2026Q1・Q2）は取得時点で登録が途中（受信件数が前年同期の約8割・約3割）。画面に注意を出す。
- 築年数は取引時点との差。和暦を西暦に直し、読めない（戦前など）ものは除外。㎡単価は TradePrice÷Area で作成者が計算（UnitPrice は使わない）。

## 画面の構成
広い画面は左に地図（画面の約66〜70%）と時間の操作、右に凡例と「区の推移」。狭い画面（900px以下）は縦に積む。
- 切り替え: 「マンション価格」「家賃」（押している方に ✓）。凡例の階級は固定で、時間を動かしても同じ色が同じ値段。区名と値（万円/㎡・円/畳）も地図に出す。
- 時間: スライダー（四半期。キーボード可）と ▶再生／■停止（320ms/四半期）。家賃モードは2008年第4四半期から。
- 区を押す（または順位表の区を押す）: 折れ線（中央値）、半数の取引の帯、件数が少ない期の白丸、家賃の折れ線、今の時点の点線。グラフを押すとその時点へ移る。数値の表（各年）も付く。
- 色だけに頼らない: 値の数字、斜線、「件数が少ない」の文字、選択区の太い縁、順位表。390px で横スクロールなし。

## 限界・次にやること
- 中央値は区内の築年・広さ・駅距離の構成の違いに左右される（画面に築年数・面積の中央値を併記）。最寄駅・地区別の集計はしていない。
- 件数が少ない基準30件は作成者の基準（根拠となる出典なし）。
- 家賃と価格の関係の評価（利回り等）は出していない（根拠データがないため）。
- 区境界は簡略化のため、隣り合う区の間にわずかな隙間・重なりがある。
