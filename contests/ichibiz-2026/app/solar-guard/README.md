# 太陽光発電所の盗難対策マップ（イチBizアワード2026・新案・最小デモ・茨城県）

新案NB（使用済みパネルの回収圏計画、`../business-nb/`）の構成を踏襲した別の案。入れ替えず並べて比べる。提出文は未作成。**出すなら部門はアイデア部門（12/10 20:00）のみ。ビジネス部門（11/30）には出さず、2部門への同時応募もしない**（総司令官補佐の決定 2026-11-14。NB とは骨組みが同じで部門を分けるため）。

銅線ケーブル等の金属盗から太陽光発電所を守る対策の優先順位を、**公開データから作る「目安」**で考える静的Webアプリ。公開するのは約2kmメッシュ（四角）・町字の代表点に置く円（散布図）・市町村の**集計だけ**で、個別設備の順位・一覧は出さない。メッシュ・町字・市町村の色は**4段階（低・中・やや高・高、仮の規則）**で示し、連続のスコアや順位の列は画面・CSV・公開 JSON に出さない（ただし元の集計値〔件数・出力計・50kW未満の件数・人口〕は公開しているので、指標は誰でも再計算でき、同じような並びは作れる。帯は同点の多い表示の工夫であり、順位が作れないことの保証ではない）。事業者が自分の設備の位置と対策を入れる自己診断は、ブラウザ内だけで計算する。サーバー・APIキー不要。

## 実データか架空か
**実データ**。認定情報（茨城県ファイル、2026-10-31時点、取得 2026-11-13）の太陽光 **29,611件**のうち、運転開始報告済み **29,187件**（運転開始前424件を除く）を使用。出力は「発電出力（kW）」。
- 町字名を e-Stat 小地域（国勢調査2020）の名称と突き合わせて代表点を得た: 町字名が一致 **26,575件**、大字名で始まる小地域の代表点の平均 **2,075件**、対応づけられず市町村の集計のみ **537件（1.8%）**。
- 町字の面積は中央値 3.1km²、90%点 7.9km²で、1kmメッシュより粗い。公開の集計メッシュは、前の版は1kmメッシュ×5＝約5km（東西約5.6km×南北約4.6km）だったが、総司令官の指示（2026-11-22「四角が大きい」）で**1kmメッシュ×2＝約2km（東西約2.3km×南北約1.9km、面積約4km²）**にした。町字の広さと同じ程度までで、位置のもとが町字の代表点なので、これより細かくしても精度は上がらない（人口の元データも約1km）。1kmにすると設備のある1,869メッシュのうち889しか出せず（設備3,439件分を隠す）、2kmなら1,068メッシュのうち765を出せて隠す設備は1,333件（全体の4.6%）で済むため、2kmを選んだ。広い大字ではなお別のメッシュに数えられうる。
- 集計メッシュ（約2km）: 設備のあるもの1,068。3件未満の99メッシュに加え、設備10件未満で50kW以上が1件以下の204メッシュ（大きな設備1件の出力が割り出せるため。下の「秘匿のしきい値」）を隠し、計303メッシュ（設備計1,333件）を除いた**765メッシュ**を出力（前の約5kmは224メッシュ）。
- 町字の集計（散布図用、`web/data/towns.json`）: 町字（e-Stat 小地域の名称に一致した単位。一致しない分は大字の平均）2,111のうち、メッシュと同じ規則（3件未満、設備10件未満で50kW以上が1件以下）で1,226（設備計3,964件）を隠し、**885町字**を出力。位置は町字の代表点で、個別設備の位置ではない（`tests/test_app.py` が検査）。
- 人口: e-Stat 地域メッシュ統計（国勢調査2020、基準地域メッシュ約1km、第1次区画 5339 5340 5439 5440 5539 5540）14,257メッシュ。「*」（近隣に合算済み）は0。
- 事業者名・代表者名・事業者住所・電話・設備IDは取り込まない。ビルド時に集計して捨て、公開物に個別設備の位置は残らない（`tests/test_app.py` が原データ全件の設備ID・名称・電話が公開物に無いことを検査）。

## 起動

```
cd contests/ichibiz-2026/app/solar-guard
python3 -m http.server 8835 --bind 127.0.0.1 --directory web   # http://127.0.0.1:8835/
```
`web/` をそのまま静的ホスティングできる。地図タイル（地理院）と MapLibre（unpkg、SRI付き）はブラウザが取得する。取得できなくても表・CSV・座標入力の診断は動く。

## データ生成
```
python3 fetch_raw.py     # 公開サイトから GET で raw/ に取得（認定情報・e-Stat 境界属性表・e-Stat メッシュ人口）
python3 build_data.py    # raw/ だけから web/data/（cells.json・towns.json ほか）を生成（ネットワーク不要、再現可）
```
`raw/`（約31MB）は .gitignore。`web/data/checklist.json`・`reality.json` は出典付きの手書き（茨城県警・JPEA・REASPの資料を取得日 2026-11-13 に読んで転記）。

## リスクの色分け（2026-11-21 に作り直し。すべて仮の規則）

総司令官の指示「どのような場所を盗まれやすいのかの統計を調べ、リスクに応じて色分け」に基づき、情報部の報告（`reports/intel/ichibiz-2026-solar-theft-risk-factors-20261121.md`）を根拠にした。前の版（設備1件あたりの出力・低圧割合・人の少なさを、利用者が重みを変えて5段階の帯にする）は廃止した（下の「前の版」）。

### 公開の地図（約2kmメッシュ・町字・市町村）: 4段階（低・中・やや高・高）
**点数 ＝ 2 × 地区の段階（0〜2） ＋ 人目の少なさ（0か1）**。0＝低、1〜2＝中、3〜4＝やや高、5＝高。

| 要素 | 判定 | 根拠（出典） |
|---|---|---|
| 地区の段階（主な根拠） | 県警の令和7年11月末の太陽光の件数（県西373・県南342・県央152・鹿行93・県北49。合計1,009＝県の太陽光に一致）を、地区の設備数（認定情報、運転開始報告済み・20kW以上）で割った「設備1,000件あたり」。県全体の値（34.6）以上＝2、20以上＝1、未満＝0 | 茨城県警 Metal News 令和7年第12号（情報部が図表を読んだ値）。県西・県南で約7割。**20という切り方は仮** |
| 人目の少なさ | 2020年国勢調査の人口密度（メッシュは約2km、市町村は市町村全体）が、県内の同じ単位の低い方から1/3なら1 | JPEA・REASP p.9「人目につきにくい立地」の近似。**数値の根拠はなく、1/3は仮**。常住人口で夜間・見通しは見ない |

- メッシュの地区＝メッシュ内の設備が最も多い市町村の地区（`build_data.py` が `cells.json` の `region` 列に出力。複数の地区にまたがるメッシュが22ある）。出力は整数の地区番号だけで、設備単位の情報は含まない。
- **使わないもの**: 規模（出力）は、JPEA・REASPのアンケートは高圧・特別高圧で被害が多く1件の額も大きい（p.14、ソーウィーク p.7）、茨城県警は小規模での発生が多いとして向きが食い違うため色に使わず、画面の注記に両論を載せる。「逃げやすさ」（IC・幹線道路）は距離の根拠がなく、国土数値情報 N06 は利用条件が未確認のため使わない（OSM の高速道路の出入口なら ODbL で使えるが、今回は未実装）。防犯設備・ケーブルの種類・巡回は公開データで再現できないので自己診断に置く。
- 件数（令和5年 2,889 → 令和6年 3,628 → 令和7年 1,766、全国の太陽光ケーブル窃盗の関東 91.8%）と、金属盗対策法・茨城県条例の施行を、地図タブの上部と「盗難の実態」に出典付きで載せる。

### 実績との照合（正直に）
- 地区の段階は令和7年11月末の実績から作ったので、地区ごとの色の平均と同じ期間の被害率の順位相関 **+0.90** は**独立の検証ではありません**。
- 別の期間（令和8年9月末の設備1,000件あたり）との順位相関は **+1.00**（順位は県南＞県西＞県北＞県央＞鹿行で一致）。ただし規則（20の切り方・人目の1/3）は両期間の数値を見たうえで決めたので、これも独立の検証ではない。5点だけで、有意とは言えない。
- **人目の少なさは、地区どうしでは被害率と逆向き**（人目が少ないメッシュの割合と被害率の順位相関 **−0.70**。県西は被害率が最大なのに割合が最小）。人目の少なさが実績に裏づけられたとは言えないので、色では1点分の補正にとどめた。
- 同じ地区の中のメッシュ別の被害実績は公開されておらず、メッシュの色の違い（人目）が当たっているかは確かめられない。5地区と市町村の対応は推測（誌面に範囲なし）、県警の件数は20kW未満・認定外を含みうる。「当たる」「予測できる」とは主張しない。

### 自己診断（個々の発電所の色。ブラウザ内だけで計算、送信・保存しない）
公開の地図には個別の発電所を出さない（窃盗に悪用されうる）。個々の発電所の色分けは、事業者が自分の設備を入れる自己診断の中だけで行う。**点数 ＝ 2 × 地区の段階 ＋ 当てはまる条件の数（0〜7）**。0〜3＝低、4〜6＝中、7〜8＝やや高、9以上＝高（仮）。「わからない」が残る間は、下限の色と、すべて当てはまった場合の色の両方を出す。位置は約2kmメッシュの単位でしか使わず（公開メッシュでない位置は、10km以内の最も近い公開メッシュの地区で代用）、規模の区分は点数に使わない。

| 条件（`web/data/risk.json`、出典付き） | 判定 |
|---|---|
| 人目につきにくい立地（JPEA p.9 ①、県警） | 本人の回答。答えなければメッシュの人口密度から自動（1/3の切り方は上と同じ） |
| 外から見えにくい（JPEA ②） | 本人の回答 |
| 保守点検が不十分に見える（JPEA ③、県警） | 対策の回答から（雑草・フェンス管理、巡回・草刈りのどちらかが「実施していない」） |
| 防犯・警備の設備がない（JPEA ④、県警） | 対策の回答から（センサー・機械警備・カメラ・警報のどれも実施せず、1つ以上が「実施していない」） |
| 転がし配管・露出ケーブル（JPEA ⑤、県警） | 対策の回答から（埋設・防護のどちらかが「実施していない」） |
| 逃げやすい（側道。JPEA ⑥） | 本人の回答 |
| 建設中・稼働前で資材を屋外保管（県警） | 本人の回答 |

各条件に「なぜ」と出典を画面に出す。点数の配分・色の切り方に公的な数値の根拠はなく、すべて仮。

### 前の版（廃止）
設備1件あたりの出力・低圧割合・人の少なさを、重み付きで平均して5段階の帯にしていた。県警の5地区別の被害と逆向き（順位相関 −0.60、最初の版は −0.90）で、そのことを開示していた。調べ直した統計では、規模の向きが資料で食い違い、人目・防犯設備などが主な条件とされていたため、規則を作り直し、重みの操作も廃止した（実績に合わせて重みを選ぶことになるため）。

| 切り替え | 内容 |

| 表示: 四角／散布図 | 四角＝約2kmメッシュ（765）。散布図＝町字の代表点に円（885町字）。**円の大きさ＝町字の設備数、円の色＝盗難リスクの目安（四角と同じ4段階・同じ色）、外枠の太さ＝段階（低0.6px〜高3px。色だけに頼らない）**。凡例に大きさの例（10・100・400件）を出す。円を押すと町字名・設備数・出力計・点数の内訳・「この町字の被害ではない」「設備の位置ではない」を出す |
| 背景: 地図／空中写真 | 地図＝地理院タイル淡色地図。空中写真＝**国土地理院シームレス空中写真**（`https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`）。選ぶと凡例に出典「地理院タイル（シームレス空中写真）」を出し、地図右下の帰属表示も切り替わる。拡大の上限は変えていない（縮尺11まで。診断の位置のプライバシー設計のため） |

### 円の色の式（散布図）と重み（すべて仮。被害の予測ではない）
**点数 ＝ 2 × 地区の段階（0〜2） ＋ 人目の少なさ（0か1）**。0＝低、1〜2＝中、3〜4＝やや高、5＝高。四角・市町村と同じ式・同じ重み（`W_REGION=2`、`MAP_LEVEL`）。違いは「人目の少なさ」の単位だけ: 町字の円は、町字の人口密度（e-Stat 小地域の人口÷面積。水面を含みうる面積）が、公開した885町字の中で低い方から1/3なら1。町字の地区は、その町字がある市町村の地区。
- 県警の件数は地区単位なので、**同じ地区の円は人目の少なさで2色に分かれるだけ**（県西・県南は「やや高」と「高」、県央・県北は「中」と「やや高」、鹿行は「低」と「中」）。町字ごとの色の違いは地区の実績の違いではない。画面にも書く。
- 規模（出力）は色に使わない（資料で向きが食い違うため。上の「使わないもの」）。円の大きさは設備数で、リスクの高さではない。
- 町字の円・ポップアップには連続のスコア・順位を出さない。設備数・出力計（10kW単位）・50kW未満の件数・人口密度は集計値として載せる（メッシュと同じ扱い）。

### 実際の盗難データ（県警の公表値の転記）
- 画面の地図タブ上部に、**県内5地区の太陽光発電施設関係の発生件数**を表で出す: 令和7年11月末 県西373・県南342・県央152・鹿行93・県北49（合計1,009）、令和8年9月末 県西109・県南164・県央84・鹿行38・県北39（合計434。暫定値）。出典: 茨城県警察 Metal News 令和7年第12号・令和8年第10号（情報部が図表を読んだ値。取得 2026-11-22）。`web/data/reality.json` に出典URL付きで保存。
- 県計の推移（金属盗の年別・太陽光の年別）は「件数と法令」と「盗難の実態」タブに既出（出典付き）。
- **按分しない**: 市町村・町字・メッシュ別の金属盗の公開データは見つからなかった（情報部。犯罪情報マップは金属盗を含まない）。地区の件数を設備数などで割り振って細かい被害件数のように見せることはしない（`tests/test_app.py` が、町字・メッシュの列に被害件数がないことを検査）。
- 市町村と5地区の対応は、県警の資料で例示されたのみ（古河市・稲敷市・かすみがうら市・茨城町・鹿嶋市・鉾田市・常陸大宮市）で、全体の対応は誌面にない。県の地域区分と同じ範囲という対応は**推測**のまま（対応未確認）。
- 背景に衛星画像を使う場合も、EOX Sentinel-2 cloudless は商用に有償ライセンス（EOX Commercial Attribution-RestrictedUse）が要るため**使わない**。Sentinel-2 の生データ（Copernicus）は商用可だが、タイル配信がなく今回は使っていない。

## 悪用を防ぐ設計（実装）
1. 個別設備の順位・一覧・点の表示なし。地図は約2kmメッシュと町字の代表点の円（設備の位置ではない）、表は市町村のみ。**メッシュの順位の列は出さないが、順位が作れないわけではない**: 画面（ポップアップ）・CSV・公開 JSON にメッシュの連続スコアや各指標の順位の列はなく、目安は4段階の色（765メッシュが4つの色に入る）で示す。一方、cells.json・CSV には件数・出力計・50kW未満の件数・人口の集計値があり、3つの指標（kW÷件数、50kW未満÷件数、人口÷面積）は1行で再計算でき、並べ替えれば内部のスコアとほぼ同じ並びが作れる（ブラウザのコンソールからも計算できる）。これらは元の認定情報から集計できる値で、帯は手がかりを足さないための表示の工夫に過ぎない。公開する集計値の粒度そのものは変えておらず、今の形（5段階の帯＋元の集計値公開）で決定済み。資源エネルギー庁が条件を付ければ従う。
2. **秘匿のしきい値**（`build_data.py` の `K_MIN`・`DOM_N`・`KW_ROUND`）: (a) 設備3件未満のメッシュ・市町村は件数・容量・指標を出力しない（出力ファイルにも存在しない）。(b) 設備10件未満のメッシュは、50kW以上の設備が1件以下なら隠す。件数・出力計・50kW未満の件数から、その1件の出力が数十kWの幅で割り出せるため（アグレッサーの指摘で7メッシュ。約5kmのとき隠す対象は11メッシュ、約2kmでは204メッシュ。町字の円にも同じ規則）。(c) メッシュの出力計は10kW単位に丸める。しきい値は最小限の目安で、統計的な匿名性の保証ではない。市町村合計とメッシュ合計の差から隠した分の合計は推定できる（画面の限界に明記）。
3. 自己診断: 位置（市町村の選択・地図クリック・緯度経度）・設備区分・現場の条件・対策チェックリスト（茨城県警 Metal News 第4・10号、同「金属盗難に注意！」、同チラシ「太陽光発電所の窃盗対策」、JPEA・REASP p.9–10。項目ごとに出典）→ 危険度の目安（仮）とその理由、「まず取る対策」3件（並べ方は ⓪選んだ区分で JPEA・REASP p.10 が重点とする箇所 ①当てはまる条件への対策（対策の回答から決まる条件はその対策、立地の条件は `risk.json` の `counter` に挙げた見張り・検知・威嚇の対策。後者は本アプリの仮の対応づけ） ②県警チラシ「ケーブルへの3つの対策」の対策 ③「わからない」の条件に関わる対策 ④その他。同じ順では未実施を先に。効果の大小は資料に数値がないので比べない。`lib.js` の `priorities`）。市町村で選んだ場合は、位置を使わず、市町村の地区と人口密度（市町村の色と同じ規則）だけで診断する。計算はブラウザ内のみ。送信・保存なし（localStorage・Cookie・POST を使わないことを `tests/` で検査）。
   - **位置の粒度**: 診断が使う位置・人口は約2kmメッシュの単位だけ（同じメッシュ内の2点で結果が同じことを検査）。
   - **「送信しません」の正確な範囲**: 座標を入力しても地図は動かさない。地図は拡大を縮尺11（約16km四方のタイル。MapLibre の拡大率10）までに制限する。ただし地図を動かすと、見ている範囲の地図画像を地理院が受け取るので、**見ている範囲は地理院に伝わる**（画面に明記）。地図を見ずに座標入力だけでも診断できる。`tests/ui_check.mjs` が、座標入力・拡大操作の後に縮尺12以上のタイルを要求しないことを検査する。
   - **県内判定**: 入力の1kmメッシュが、茨城県の区域（e-Stat 小地域境界のポリゴン。水面を含む）に重なるメッシュ（`web/data/land.json`、ビルド時に生成）に入るかで判定し、海上・他県の座標は拒否する（鹿島灘・千葉・栃木・県外を検査）。
   - **座標の入力**: 全角を半角にし、符号付きの10進数だけを受け付ける。「36,34」「36.34abc」は拒否。
4. 盗難の実態は公的な粒度（全国・茨城県の年次、県内5地区）のみ。令和8年は暫定値、「9月末」が累計かは誌面に明記なしと画面に記載。
5. CSV は集計（メッシュ・市町村）のみ。色は4段階だけ。県警の実績との食い違いの注記を含む。
6. 元データの認定情報は地番まで公開されている。本アプリの秘匿は「他人に見つけられなくする」ものではなく、元データ以上の手がかり（手薄さの順位）を足さないためのもの。
