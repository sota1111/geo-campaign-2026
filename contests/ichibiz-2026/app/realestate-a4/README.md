# 同じ土地、四つの値段（イチBizアワード2026 不動産情報活用部門・新案 A4）

地図で場所を指す（住所検索は地図を動かすだけ）と、近くの標準地を距離順に最大5件出し、標準地ごとに公示価格・相続税路線価・取引事例比較法比準価格・収益価格（還元利回り付き）を同じ単位（円/㎡）で並べる。「標準地の価格であり、あなたの土地の価格ではありません」を常に併記する。静的ファイルのみ。実行時にサーバー・APIキーは要らない（取得は事前に済ませ、`web/data/fukuoka.json` に同梱）。

## データ取得（総司令官が実行）
```
cd /home/ubuntu/dev/2026/geo-campaign-2026 && node --env-file=.env contests/ichibiz-2026/app/realestate-a4/tools/fetch.mjs
```
- XCT001（鑑定評価書情報）を、福岡県（40）・2025年・住宅地（00）と商業地（05）の計2回、GET で取得。要求の間隔は 500ms 以上。キーは環境変数 `REINFOLIB_API_KEY` だけから読み、出力・ファイルに書かない。応答の生データは残さず、画面に要る項目（位置・所在・用途・4つの価格・還元利回り・変動率・用途地域・建蔽率・容積率・地積・現況）だけを `web/data/fukuoka.json` に書く（見込み 約1,750件、1MB前後）。
- `--check` で通信せず設定だけ確認。`--year` で価格時点、`--out` で出力先を変える。
- 項目名が想定と違って全件が除外された場合は、値を出さず項目名だけを表示して止まる。
