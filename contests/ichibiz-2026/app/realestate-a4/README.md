# 同じ土地、四つの値段（イチBizアワード2026 不動産情報活用部門・新案 A4）

地図で場所を指す（住所検索は地図を動かすだけ）と、近くの標準地を距離順に最大5件出し、標準地ごとに公示価格・相続税路線価・取引事例比較法比準価格・収益価格（還元利回り付き）を同じ単位（円/㎡）で並べる。「標準地の価格であり、あなたの土地の価格ではありません」を常に併記する。静的ファイルのみ。実行時にサーバー・APIキーは要らない（取得は事前に済ませ、`web/data/fukuoka.json` に同梱）。

現行案（`../realestate/`）・RN1（`../realestate-rn1/`）は変更していない。**追加の候補**で、どれを出すかは総司令官が決める。提出文の下書きは `../../submission/realestate-a4/`。偵察: `reports/recon/ichibiz-2026-reinfolib-newplan-20261121.md`。

## 状態（2026-11-21、2回目）
- 実データを取得済み（総司令官が実行）: 福岡県・2025年・住宅地1,254件＋商業地504件＝1,758件、除外0件、660KB。**`web/data/fukuoka.json` は二次配布の再確認が済むまでコミットしない（未追跡）。**
- 実データで確認したこと: 緯度・経度は10進の度（福岡県の範囲内）。還元利回りは%の値（2.9〜3.8 の範囲。1未満の割合表記は無かった）。
- 値のある件数（1,758件中）: 公示価格1,758、取引事例比較法比準価格1,758、相続税路線価938（住宅地544・商業地394）、収益価格・還元利回り904（住宅地422・商業地482）、4つ全てそろう708（住宅地318・商業地390）。偵察の実打ちの「全件で値あり」とは違うが、空・0・「-」を値なしとして数えたため（取得スクリプトは0・「-」・空を値なしにする）。
- 値が無い行は「データなし」と、「国のデータにこの標準地の値の記載がありません」を出す。理由（路線価でなく倍率で評価する地域、その手法を使っていない等）はデータから確かめていないので断定しない。カードの上に「4つの価格がそろっています」「4つのうち n つはデータなし」を出し、「4つの価格がそろう標準地だけ」の切替で絞れる。
- 同じ所在地に標準地が2件並ぶことがある（例: 天神1丁目96番1外）。地価公示と都道府県地価調査など別の調査の可能性があるが、データの項目からは区別していない。

## データ取得（総司令官が実行）
```
cd /home/ubuntu/dev/2026/geo-campaign-2026 && node --env-file=.env contests/ichibiz-2026/app/realestate-a4/tools/fetch.mjs
```
- XCT001（鑑定評価書情報）を、福岡県（40）・2025年・住宅地（00）と商業地（05）の計2回、GET で取得。要求の間隔は 500ms 以上。キーは環境変数 `REINFOLIB_API_KEY` だけから読み、出力・ファイルに書かない。応答の生データは残さず、画面に要る項目（位置・所在・用途・4つの価格・還元利回り・変動率・用途地域・建蔽率・容積率・地積・現況）だけを `web/data/fukuoka.json` に書く（見込み 約1,750件、1MB前後）。
- `--check` で通信せず設定だけ確認。`--year` で価格時点、`--out` で出力先を変える。
- 項目名が想定と違って全件が除外された場合は、値を出さず項目名だけを表示して止まる。
