# 同じ土地、四つの値段（イチBizアワード2026 不動産情報活用部門・新案 A4）

地図で場所を指す（住所検索は地図を動かすだけ）と、近くの標準地を距離順に最大5地点出し、1地点を1枚のカードにして、公示価格・相続税路線価・取引事例比較法比準価格・収益価格（還元利回り付き）を同じ単位（円/㎡）で並べる。「標準地の価格であり、あなたの土地の価格ではありません」を常に併記する。静的ファイルのみ。実行時にサーバー・APIキーは要らない（取得は事前に済ませ、`web/data/fukuoka.json` に同梱）。

現行案（`../realestate/`）・RN1（`../realestate-rn1/`）は変更していない。**追加の候補**で、どれを出すかは総司令官が決める。提出文の下書きは `../../submission/realestate-a4/`。偵察: `reports/recon/ichibiz-2026-reinfolib-newplan-20261121.md`。

## 4つの価格の出し方（情報部報告 reports/intel/ichibiz-2026-xct001-duplicates-20261121.md による）
- **公示価格**: 地価公示のポイントAPI（XPT002）の**当年価格**だけを出す（公示価格として表示。判定価格に当たるという公式の明記は未確認）。出典の表記は「地価公示（不動産情報ライブラリ XPT002 の当年価格）」。XCT001 の「公示価格」「1㎡当たりの価格」は画面に出さない（同じ標準地の2件で値が違い、公示価格の定義と合わないため）。XPT002 の当年価格が判定価格に当たると明記した公式の文は確認できていない（有力な対応）。標準地と位置（50m以内・用途が同じ）で突き合わせ、できない地点は「公示価格: 照合できませんでした」。
- **鑑定評価書の値**（取引事例比較法比準価格・収益価格・還元利回り・相続税路線価）: XCT001 は同じ標準地番号の記録を2件ずつ返す（実データでは879地点が全て2件）。1地点を1枚のカードにまとめ、2件の値が違えば「7,000,000／7,050,000円/㎡（鑑定評価書の記録2件）」と並べ、同じなら1つ。説明は「地価公示では、1つの標準地を2人の鑑定評価員が評価する制度です（国土交通省）」まで。API の2件がその2人分に当たるとは断定しない（公式資料に明記が無い）。
- **標準地番号**: 突き合わせできた地点は XPT002 の標準地番号をそのまま出す。できなかった地点は、国の形（住宅地「地域名-連番」、商業地「地域名5-連番」。突き合わせできた832地点の全てでこの規則が XPT002 の番号と一致）に組み立て、「（作成者による表記）」を添える。他の用途は規則が未確認なので「地域名 用途 連番」。
- 画面の「4つそろう」は、公示価格が照合でき、路線価・比準価格・収益価格がそれぞれ記録のどれかに値がある地点。

```
# 2段目: 本取得（1段目で「地価公示として抽出できた標準地」が1点以上なら）

```
- ① XCT001（鑑定評価書情報）を、福岡県（40）・2025年・住宅地（00）と商業地（05）の計2回。② XPT002（地価公示・地価調査のポイント）を、①の標準地の位置があるタイルだけ（z13、約154タイル）を、`priceClassification` を付けずに取り、地価公示（`land_price_type` が 0）だけを使う。すべて GET、要求の間隔は 500ms 以上。所要はおよそ2〜3分。
- XPT002 の当年価格（`u_current_years_price_ja`）は「3,100,000(円/㎡)」のように単位つきの文字列で返る（公式マニュアル）。先頭の数を読む。初回の取得で0点だったのは、この文字列を数として読めなかったためと見られる（`--probe` で確かめる）。
- 診断（`--probe` と、0点で止まった時に出る）: features の件数、地価区分ごとの件数、価格を数として読めた件数、1件目の項目名（値は出さない）、想定していて見つからない項目名、HTTP ステータスごとの回数（404 は「標準地なし」として扱うが回数は数える）。
- キーは環境変数 `REINFOLIB_API_KEY` だけから読み、出力・ファイルに書かない。応答の生データは残さず、画面に要る項目だけを `web/data/fukuoka.json`（標準地ごとにまとめた形式）に書く。
- `--check` で通信せず設定・要求回数の見込みだけ確認。`--year` で価格時点、`--out` で出力先を変える。
- 項目名が想定と違って全件が除外された場合や、XPT002 が0点だった場合は、書き出さずに止まる（値は出さず、項目名だけを表示）。
