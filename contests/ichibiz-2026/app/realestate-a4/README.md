# 同じ土地、四つの値段（イチBizアワード2026 不動産情報活用部門・新案 A4）

地図で場所を指す（住所検索は地図を動かすだけ）と、近くの標準地を距離順に最大5地点出し、1地点を1枚のカードにして、公示価格・相続税路線価・取引事例比較法比準価格・収益価格（還元利回り付き）を同じ単位（円/㎡）で並べる。「標準地の価格であり、あなたの土地の価格ではありません」を常に併記する。静的ファイルのみ。実行時にサーバー・APIキーは要らない（取得は事前に済ませ、`web/data/fukuoka.json` に同梱）。

現行案（`../realestate/`）・RN1（`../realestate-rn1/`）は変更していない。**追加の候補**で、どれを出すかは総司令官が決める。提出文の下書きは `../../submission/realestate-a4/`。偵察: `reports/recon/ichibiz-2026-reinfolib-newplan-20261121.md`。

## 4つの価格の出し方（情報部報告 reports/intel/ichibiz-2026-xct001-duplicates-20261121.md による）
- **公示価格**: 地価公示のポイントAPI（XPT002）の**当年価格**だけを出す（1地点に1つ）。出典の表記は「地価公示（不動産情報ライブラリ XPT002 の当年価格）」。XCT001 の「公示価格」「1㎡当たりの価格」は画面に出さない（同じ標準地の2件で値が違い、公示価格の定義と合わないため）。XPT002 の当年価格が判定価格に当たると明記した公式の文は確認できていない（有力な対応）。標準地と位置（50m以内・用途が同じ）で突き合わせ、できない地点は「公示価格: 照合できませんでした」。
- **鑑定評価書の値**（取引事例比較法比準価格・収益価格・還元利回り・相続税路線価）: XCT001 は同じ標準地番号の記録を2件ずつ返す（実データでは879地点が全て2件）。1地点を1枚のカードにまとめ、2件の値が違えば「7,000,000／7,050,000円/㎡（鑑定評価書の記録2件）」と並べ、同じなら1つ。説明は「地価公示では、1つの標準地を2人の鑑定評価員が評価する制度です（国土交通省）」まで。API の2件がその2人分に当たるとは断定しない（公式資料に明記が無い）。
- **標準地番号**: 突き合わせできた地点は XPT002 の標準地番号をそのまま出す。できなかった地点は、作成者による表記（地域名 用途区分 連番）に「（作成者による表記）」を添える。
- 画面の「4つそろう」は、公示価格が照合でき、路線価・比準価格・収益価格がそれぞれ記録のどれかに値がある地点。
