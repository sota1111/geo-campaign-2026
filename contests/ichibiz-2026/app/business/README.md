# 見直し案の比較（イチBizアワード2026 ビジネス部門・最小デモ）

自治体の交通担当が、バス路線の見直し案（路線の廃止）を2〜3案つくり、案ごとに「病院・小中学校へ公共交通で行けなくなる人（65歳以上を含む）」を地区別に並べて比べ、資料用のCSVに書き出す静的Webアプリ。構想（提案書 service.md）の「案を作る→比べる→出す」を、実データで一通り体験できる最小限の形にしたもの。サーバー・APIキー不要、外部への送信なし。

## 起動

```
cd contests/ichibiz-2026/app/business
python3 -m http.server 8824 --bind 127.0.0.1 --directory web   # http://127.0.0.1:8824/
```

`web/` をそのまま静的ホスティングできる（パスは相対）。地図タイル（地理院）とMapLibre（unpkg、SRI付き）はブラウザがインターネットから取得する。取得できなくても表とCSV書き出しは動く。

## 画面の流れ

1. 地域（5地域）と条件（平日/休日、朝8・昼12・夕17時、許容時間20/30/45/60分）を選ぶ
2. 案A・B・Cに、止める路線を選ぶ（例として案A・Bに影響の大きい路線を仮に入れてある。路線は選択肢に影響人数付きで並ぶ）
3. 比較表（現状／案ごと。病院・小中学校別に、行けなくなる人・うち65歳以上・人口比・影響地区数）と、地区別の内訳、地図（選んだ案で行けなくなる500mメッシュと止める路線）
4. CSVダウンロード（比較表・全地区の内訳・前提・出典。UTF-8 BOM付き）

## 何を計算しているか・できないこと

- データは公共交通オープンデータチャレンジ向け住民向けアプリ（`contests/odpt-2026/app`）の生成結果（診断結果と、路線ごとに「その路線の全便を止めて時刻表から再計算した」差分）。このアプリは**人数を新たに計算・推定していない**。「行けていたのに行けなくなる」メッシュの人口を集計するだけ。
- 対応: **路線の廃止（全便停止）**。
- 未対応（画面にも明記）: **減便（本数を減らす）**（本数を減らした時刻表の再計算が事前計算に無く、根拠を示せないため）、停留所の移設、乗継の変更、運賃、代替交通・デマンド交通。将来推計人口も未対応（現在の人口＝令和2年国勢調査のみ）。
- 複数路線を1案に入れた場合: 単独停止の差分を**セル単位の和集合**にして重複を1回だけ数え、「**少なくとも**」の下限として表示する（ある路線で行けなくなる地区は、他の路線も止めれば当然行けないままのため下限になる）。複数を同時に止めたときだけ新たに行けなくなる人は含まない。人数の単純な足し合わせはしない。厳密な値には、odpt の `lifemap` で組み合わせごとの再計算（GTFSの再取得が必要）が要る。
- 「地区」は行政区画ではなく、**最寄りの収録停留所の名前（メッシュ中心からの直線で最も近いもの）でまとめた500mメッシュの集まり**。町丁・小学校区の名称は持っていない。
- 歩いて許容時間内に着ける地区は、路線を止めても影響なしとして数える。基準日は水曜（平日）・日曜（休日）で、祝日・臨時ダイヤは未反映。診断の前提（徒歩モデル等）の全文は画面の「出典・ライセンス・前提」と `contests/odpt-2026/app/README.md`。
- 収録は5地域のバス等（東京は都営バス・都営地下鉄等）。JR・大手民鉄、デマンド交通は未収録。事前計算が無い路線（基準日に便がない路線）は選べない。
- 事業性・市場規模・効果の数値は画面に載せていない。

## データと出典・ライセンス

`web/data/` は `contests/odpt-2026/app/web/data/` のコピー（`python3 build_data.py` で再コピー・整合検証。odpt 側は読むだけ）。

| データ | 出典 | ライセンス・条件 |
|---|---|---|
| バスGTFS（熊本・富山・徳島・飯田） | GTFSデータリポジトリ（gtfs-data.jp）。フィード別の事業者・ライセンス（CC BY 4.0／CC0 1.0／CC BY 2.1 JP 等）・更新日・有効期間は画面の「出典・ライセンス・前提」とCSVにフィード別に表示 | フィードごと。事業者名表示と加工の明記 |
| 都営バス・都営地下鉄等のGTFS | 公共交通オープンデータセンター（東京都交通局・公共交通オープンデータ協議会） | CC BY 4.0（カタログ記載） |
| 人口・65歳以上人口 | 政府統計の総合窓口(e-Stat) 令和2年国勢調査 地域メッシュ統計（250m→500m集約）を加工して作成 | e-Stat利用規約（出典明記） |
| 病院・小中学校 | 国土数値情報 医療機関P04-20（病院のみ）・学校P29-21（国土交通省）を加工して作成 | 国土数値情報の利用規約 |
| 鉄道駅（位置の目安） | 国土数値情報 鉄道N02-22（国土交通省）を加工して作成 | 同上 |
| 背景地図 | 地理院タイル（淡色地図） | 国土地理院の利用規約 |
| 描画 | MapLibre GL JS 4.7.1 | BSD-3-Clause |

利用規約は変わりうる。公開前に各出典元で最新の条件と、データの有効期間（画面に表示）を確認すること。e-Stat・国土数値情報の規約全文は本リポジトリでは確認していない。

## ファイル

```
web/            公開する静的サイト（index.html, app.js, lib.js, style.css, data/）
build_data.py   odpt-2026 の web/data からのコピーと整合検証
tests/          lib_test.js（計算の単体試験）, test_app.py, ui_check.mjs（画面確認）
screenshots/    画面確認のスクリーンショット
```

## テスト

```
cd contests/ichibiz-2026/app/business
python3 -m unittest discover -s tests          # 単体試験（node が必要）
node tests/ui_check.mjs http://127.0.0.1:8824/ screenshots   # 画面確認（要 google-chrome、サーバー起動後）
```

- `lib_test.js`: 合成データでの集計（重複の除去・下限性・徒歩で着く地区・別条件）、実データ5地域×全路線×全条件で odpt の `Lib.lostPopulation` と人数・メッシュが一致すること、複数路線の和集合が「単独の最大以上・単純和以下」であること、CSVのエスケープ。
- `test_app.py`: データが odpt と同一、参照整合・ライセンス表示、POST・外部送信がないこと、画面に未対応と下限の注意があること。
