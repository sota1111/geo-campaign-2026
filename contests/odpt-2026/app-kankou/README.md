# 観光バスを避ける生活ルート（odpt-2026 比較用の案）

現行の案（`../app/` 生活アクセス診断マップ、`../app-teiji/` バス定時性カルテ）には手を入れず、並べて比較するための別案です。

## 目的
観光地の近くを通るバスは、時間帯によって観光客でふくらみ、住民が通院・通勤・通学で乗りにくくなることがあります。時刻表（GTFS）と観光地点のオープンデータから「観光地点の近くを通る系統・時間帯」を推定し、
1. 住民が出発地と目的地（病院・駅・学校）を選ぶと、観光系統を避けた経路と通常の経路・所要時間の差を示す
2. 自治体・事業者向けに「観光客が集中しやすい系統×時間帯」の一覧とCSVを出す

対象地域: 浅草・上野・押上周辺（台東区・墨田区を中心とした東京都心東部）。

## 使ったデータと出典・ライセンス
| データ | 出典 | ライセンス | 取得 |
|---|---|---|---|
| 都営バス GTFS | 東京都交通局（公共交通オープンデータセンター `b_bus_gtfs_jp-toei`） | CC BY 4.0 | `https://api-public.odpt.org/api/v4/files/Toei/data/ToeiBus-GTFS.zip`（トークン不要） |
| 台東区コミュニティバス（めぐりん）GTFS | 台東区（同 `tokyo_taito_city_megurin_ccby40`） | CC BY 4.0 | `https://api-public.odpt.org/api/v4/files/odpt/TokyoTaitoCity/megurinCCBY40.zip?date=current`（トークン不要） |
| 観光地点 | 国土数値情報 観光資源 P12-14（平成26年度版、国土交通省） | **非商用**（データ詳細ページ記載） | nlftp.mlit.go.jp |
| 病院・学校・鉄道駅 | 国土数値情報 P04-20（病院）・P29-21（小学校・中学校・中等教育学校・高等学校）・N02-22（駅） | 国土数値情報の利用規約（出典明記） | nlftp.mlit.go.jp |
| 背景地図 | 地理院タイル（淡色地図） | 国土地理院の利用規約 | 実行時にブラウザが取得 |

画面の「出典・ライセンス・前提」にも同じ内容を表示します。ODPT のアクセストークンは使いません（`kankou/fetch.py` は認証API・非公開ホストを拒否します）。

## 推定の方法と限界
- 混雑度のリアルタイムデータ: 都営バスの GTFS-RT 車両位置（`https://api-public.odpt.org/api/v4/gtfs/realtime/ToeiBus`）を 2026-11-15 に1回取得（7台分）して確認したところ、occupancy 系のフィールドは含まれていませんでした。台東区コミュニティバスのリアルタイム情報は ODPT カタログで見つかりませんでした。1回の取得での確認なので「確認した範囲では無い」という扱いです。そのため推定は「観光地点の近くを通るか」だけに基づきます。
- 観光地点に近い停留所: 観光地点から 300 m（直線、仮定）以内。
- 観光系統: 系統の停留所のうち観光地点に近いものの割合が既定10%以上（画面のスライダーで変更可。10%は仮定）。
- 観光客が多い時間帯: 既定 9:00〜17:00（**仮定**。データから求めた値ではない。画面で変更可）。
- 避ける対象: 観光系統に、上の時間帯に乗り、乗る区間が観光地点に近い停留所を含む場合。
- 一覧の数値（便数・停車回数）は時刻表から数えた事実の値。観光客の人数ではありません。
- 経路探索は RAPTOR（バスのみ、乗換3回まで）。徒歩は直線距離×1.25 を毎分80mで歩く概算（既存の `../app` と同じ前提）。
- 鉄道は経路に含めません（時刻表を使っていない）。駅は目的地の候補としてのみ表示。
- 観光資源データは2014年度版で、新しい施設や人気スポットは含まれません。時刻表は基準日（平日=水曜・休日=日曜）1日分です。

## 起動方法
Python 3.10 以上（標準ライブラリのみ）、node（試験用）。
```
python3 -m kankou.build --today 2026-11-16   # データ取得と web/data/ の生成（ネットワークが必要。cache/ に保存）
cd web && python3 -m http.server 8000        # http://localhost:8000/ を開く
```
ビルド済みの `web/data/kankou.json`（約1MB）と `route_hour.csv` を同梱しているので、ビルドなしでも起動できます。サーバー・APIキーは不要で、外部へ送信するのは地図タイルと部品（MapLibre GL JS）の取得だけです。

## 試験
```
python3 -m unittest discover -s tests   # Python と、node の lib_test.js（経路探索・観光系統の回避・CSV）
node tests/ui_check.mjs http://127.0.0.1:8000/ /tmp/shots   # 画面の点検（Chrome が必要。任意）
```

## 構成
