# 子連れお出かけ診断（東京都区部）

> **現状（2026-11-14）: 行き先データを同梱していない。** 国土数値情報 P13・P27 の使用許諾条件が「非商用」で、事務局の文書回答が得られるまで「使えない」扱い（総司令官補佐の決定 `reports/command/decision-20261114-odpt-kodure.md`）。リポジトリは公開のため、P13・P27 から作った行き先の名称・座標・種別（`web/data/meta.json` の東京356か所、`web/data/osaka.json` の大阪239か所）と、行き先ごとの行列（`web/data/m_*.json`）をこのブランチの先頭から外した（`.gitignore` の `web/data/*.json`。**履歴には残っている**）。画面は残り、データが無いときは「行き先データ（国土数値情報 P13・P27）は許諾確認中のため同梱していません」と表示する。`python3 build.py` で手元には生成できる（下の「ビルド」。生成物は追跡されない）。許諾の回答・差し替えが決まるまで、既定ブランチへの統合・公開・応募はしない。

odpt-2026 の**別案**。既存アプリ `../app`（生活アクセス診断マップ）・`../app-teiji` とは別に追加したもので、既存のファイルは変更していない。既存アプリの前処理ライブラリ `../app/lifemap`（取得・GTFS読み込み・停留所の統合・メッシュ処理）を **import して再利用**し、到達計算・行き先・画面は新規に書いた。

問い: 「休日、家（500mメッシュ）を午前に出て、**ベビーカーでも無理のない徒歩**で、公園・動物園・水族館・博物館などへ片道何分で行けるか。さらに夕方に行き先を出て、**家に許容時間内に帰れるか**」。主な指標は「**行き帰りとも行ける**」。

- 地域: 東京都区部（既存 tokyo と同じ bbox・フィード＝ODPT 15データ）。大阪は**時刻表のオープンデータが無いため未対応**で、行き先の位置だけを地図に出す（時間は出さない）。
- 切り替え: 行きの出発時間帯（9時台・10時台）、帰りの出発時間帯（16時台・17時台）、片道の許容時間（30/45/60/90分）、徒歩1回の上限（直線300/500/800m）、乗換回数（なし／1回まで／制限なし）、行き先の種類（6種）。
- 2つの見方: (a) 地区をタップ → そこから行ける行き先の一覧（行き・帰りの所要、最少乗換回数、帰宅時刻の目安）。(b) 行き先を選ぶ（地図の点または一覧）→ 行ける地区の塗り分けと、0〜14歳人口・総人口での集計。何も選ばないときは「行き帰りとも行ける行き先の数」で塗り分け。
- 既存アプリの良い点を引き継いだもの: 収録範囲（JR等未収録）の常時表示、未収録鉄道の駅が近い地区は灰色「未評価」、色覚に配慮した配色（青の濃淡とオレンジ。赤緑を使わない）、スマホ表示（結論を最初の画面に固定、下部パネルの開閉）、出典・ライセンス・ODPT開発者ガイドラインの通知事項の表示、共有リンク、住所・駅名検索。

## 子連れの条件（値と根拠。**「仮定」は根拠となる調査値を確認していない**）

| 項目 | 値 | 根拠 |
|---|---|---|
| 徒歩速度 | 分速60m | **仮定**。既存アプリ（分速80m。不動産表示の徒歩分数の一般的な目安に合わせた値）の75%と置いた。ベビーカー連れの実測値・公的資料は確認していない |
| 道のり | 直線距離×1.25 | 既存アプリと同じ概算（道路網・坂・段差・信号は未考慮） |
| 1回の徒歩の上限 | 直線 300 / 500 / 800m（道のり換算でおよそ6/10/17分） | 選択肢の値は**仮定**。「出発地→最初の停留所」「最後の停留所→到着地」「乗らずに歩いて着く場合」のそれぞれに適用 |
| 乗継の余裕 | 5分以上 | **仮定**（既存アプリは3分）。ベビーカーでの乗り換えに余裕を見た |
| 徒歩乗換 | 直線300m以内の別の停留所群へ歩いて乗り継げる。徒歩時間は上と同じ徒歩モデル（直線×1.25÷分速60m）で加算し、そのうえで乗継の余裕5分以上が要る | 300mは**仮定**（浅草・大手町・日比谷など、同名・近接でも別ノードになる乗換駅を扱うため。アグレッサー指摘 W1）。乗換回数には、歩いた乗り換えも1回と数える。出発地→最初の停留所の徒歩とは別の徒歩で、徒歩の上限（300/500/800m）は掛けない |
| 乗換回数の上限 | なし（乗車1回）／1回まで（乗車2回まで）／制限なし | 利用者が選ぶ条件 |
| 出発時刻 | 行き 9時台・10時台、帰り 16時台・17時台。**時刻1点ではなく幅で判定**: 時間帯の先頭（h:00）から30分後（h:30）まで5分おきの7通りに出発し、所要時間（待ち時間込み）の**中央値**（4番目に短いもの）を5分刻み（切り上げ）にする。半分以上の出発で90分以内に着けなければ「行けない」 | 総司令官の指示の例の時間帯。9:00ちょうど1点だと5分ずらしただけで結果が大きく入れ替わる（アグレッサー指摘 W2: 行ける組の22.0%が9:00発と9:05発で入れ替わった）ため。幅（30分）と間隔（5分）は**仮定**。帰宅時刻の目安は、帰りの幅の最後（h:30）に出た場合 |
| 許容時間 | 片道 30/45/60/90分 | 利用者が選ぶ条件。待ち時間・乗継の待ちを含む |
| 休日 | 日曜のダイヤ | 各データの有効期間内で生成日以降の最初の日曜。**土曜・祝日・臨時ダイヤは反映していない** |

## 行き先の入口（公園の外周）と、最寄りの停留所が遠い行き先

- 公園は点データ（P13）で形が分からない。中心点で判定すると、大きい公園は入口までの距離が大きく違う（10ha以上42か所のうち15か所は、中心から直線500m以内に収録停留所が無かった）。そこで、**面積と同じ面積の円を仮定**し、中心から等価半径（半径 = √(面積/π)、上限700m）だけ離れた外周の8点と中心のうち、**最も近い点から出入り**するものとして徒歩の距離・時間を測る（行きは外周の点→停留所、帰りは行き先の外周の点から出発）。例: 駒沢オリンピック公園（41.4ha）は半径約360m。**実際の入口の位置・公園の形ではない仮定**で、細長い公園・入口が限られる公園では実際と違う。動物園・水族館・博物館等は施設の点のまま。
- 各行き先について、入口の点から最も近い収録停留所までの直線距離（2km以上は2kmとして記録）を `meta.json` の `dests[i][6]` に持つ。画面は、これが選んだ徒歩上限を超える行き先に「停留所が遠い（約○m）」と表示し、「行けない」の中に、収録していない交通で行ける可能性があることを注意書きする。徒歩の上限が300mのとき109か所、500mのとき63か所、800mのとき45か所（入口の点を使った後の数）が該当する。

## ビルド（データの再生成）

Python 3.10以上、標準ライブラリのみ。取得済みの `cache/` があればインターネット不要（無ければ GET で取得）。

```
cd contests/odpt-2026/app-kodure
python3 build.py --today 2026-11-14 --workers 22     # 約90秒（24コア・並列。出発を7通りずつ探索するため以前の約4倍）。--workers 1 でも動く
```

- 行列: 行き（家→行き先）は家ごと、帰り（行き先→家）は行き先ごとに前方探索（乗車回数の層を同時に持つ）。出発時刻（行き2×帰り2）× 徒歩上限3 × 乗車回数の層3 = 36ファイルを書き出す。各ファイルは「行き先ごとの、メッシュ別の所要時間の符号」の RLE（0の連続は10進数、符号 A=5分以内 … R=90分以内）。画面は条件に合う6ファイル（行き・帰り × 層1〜3）だけを読む。
- 基準日: 各データの有効期間内で `--today` 以降の最初の日曜。公開前に最新のGTFSで作り直すこと（小田急バスは2026-11-30、京王バス・西武バス・北区Kバスは2026-12-31で終わる）。
- 診断範囲: 収録停留所から2km以内の人口メッシュ（1,945メッシュ、総人口 約856万人、0〜14歳 約93万人＝10.9%）。
- 行列の1つの値は、出発時刻の幅の7通りの探索の中央値（上の「出発時刻」）。乗換のある探索は、別の停留所群への徒歩乗換の辺（近い順に直線300m以内）も使う。

## 診断結果の例（既定の条件。収録した交通だけ・上の仮定のもと。`python3 stats.py` で再計算できる）

行き9時台・帰り16時台（それぞれ先頭30分の幅の中央値）・片道45分以内・徒歩1回500m以内・乗換1回まで:
- 行き帰りとも行ける行き先が1か所以上（徒歩のみで着く公園を含む）ある地区に住む0〜14歳: **80.2%**（以前の定義（9:00ちょうど1点・徒歩乗換なし・公園は中心点）では76.2%）。徒歩上限を300mにすると60.8%、800mにすると92.4%。乗換なしだと78.4%、許容30分だと76.5%、60分だと81.0%。

## 診断の前提と限界

- 「行ける」: 指定した時間帯（先頭30分）に5分おきにメッシュ中心（行き）／行き先の入口の点（帰り）を出て、徒歩→公共交通（乗継可。近くの別の停留所へは歩いて乗換）→徒歩で、片道の許容時間内に着ける所要時間の中央値。待ち時間を含む。「行き帰りとも行ける」は行きの診断と帰りの診断の両方を満たすことで、**現地に滞在できる時間は考慮していない**。
- 収録は ODPT の15データだけ。**JR・東急・京急・京成・京王線・小田急線・西武線等は未収録**。未収録の鉄道の駅が近い地区は、行けなくても赤にせず灰色（未評価）。「行けない」の中には、未収録の交通で行ける地区が含まれる。
- 行き先は、公園は中心付近の点を元に、面積から仮定した外周の点で判定（約1割の公園は元データで位置が特定できず含まれない。形・実際の入口は不明）、文化施設は点。細長い公園・入口が限られる公園では実際と違う。データは P13=2010年3月時点、P27=2013年度版で、閉園・閉館・新設は反映されない。
- 0〜14歳人口は国勢調査メッシュの値。人数が少ないメッシュは秘匿で0として集計しているが、診断地区の合計は総人口の10.9%で、一般的な割合と大きくは違わない。
- エレベーター・ベビーカーでの乗降のしやすさ・混雑・授乳室・おむつ替え・施設の開館時間・入場料・運賃・バスの遅延は評価していない。
- 大阪は ODPT・GTFSデータリポジトリのどちらにも大阪市の地下鉄・バスの時刻表が見当たらない（情報部、2026-11-13確認）ため、所要時間を出さず、行き先の位置だけを出す。
