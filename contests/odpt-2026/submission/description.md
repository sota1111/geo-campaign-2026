# 作品名

生活アクセス診断マップ

## 公開URL

（総司令官が静的ホスティングへ公開後に記入）

## 概要

地区ごとに、平日・休日の朝・昼・夕に、歩くか公共交通で病院や小・中学校へ行けるかを、地図の塗り分けと人口の割合で診断するWebアプリです。500mメッシュの中心を指定した時刻に出発し、20分から60分以内に着けるかを時刻表から計算します。徒歩だけで着ける地区も同じ徒歩モデルと許容時間で判定します。結果は「歩いて行ける」「公共交通で行ける」「行けない」「鉄道駅が近い（未評価）」の4色で表示します。GTFSに収録していないJR等の鉄道は評価せず、その駅の近くを「行けない」と誤読されないよう灰色で区別し、収録範囲を画面に常時表示します。東京都区部（都営・東京メトロ等の鉄道とバス）、熊本市周辺、富山市周辺、徳島市周辺、飯田市・下伊那の5地域に限って収録し、大都市と地方を比べられます。地図をタップすると近くの停留所の本数・終発・路線が分かります。路線を1つ選んで「止めたら」を試すと、行けなくなる人数と地区が表示されます。サーバー不要の静的サイトで、スマートフォンからも無償で使えます。

## 解決したい課題

地方や自治体のバスの維持・再編を考えるとき、議論は便数や乗車人数に偏りがちです。住民にとって大切なのは、通院や通学といった生活の目的地へ、必要な時間帯に行けるかどうかです。コミュニティバスは本数が少なく、時刻が1本ずれるだけで行けなくなるため、待ち時間と乗継を含めて「着けるか」で見る必要があります。本作品はこの差を、専門知識がなくても地図と数字で確認できるようにします。例えば平日朝8時に出て20分以内に病院へ行ける人（歩く場合を含む）は、東京都区部で95.0%、熊本市周辺で73.3%、徳島市周辺で70.1%、富山市周辺で60.5%、飯田市・下伊那で39.4%でした。飯田市・下伊那では、歩いて行ける人が39.2%で、公共交通で行けるようになる人は0.2%にとどまります。一方、東京都区部では歩いて行けない人のうち32.4%が公共交通で行けます（いずれも収録した交通だけ・本アプリの前提での計算。JR・大手私鉄等の鉄道は評価していません）。自治体職員、議員、住民が同じ画面で現状と変更の影響を話し合う材料にできます。

## 使用データ

東京都区部の診断には、公共交通オープンデータセンターが配信するGTFS 15データを使います。東京都交通局（都営バス、都営地下鉄・都電荒川線・日暮里・舎人ライナー）、東京メトロ・りんかい線・つくばエクスプレス、関東バス・京王バス・西武バス・小田急バス、区のコミュニティバス6データ（江戸バス・目黒区・品川区・B-ぐる・風ぐるま・Kバス）です。ライセンス（CC BY 4.0、公共交通オープンデータ基本ライセンス）とクレジットをデータごとに画面に表示し、開発者ガイドラインが求める通知（センター提供であること・正確性を保証しないこと・事業者へ直接問い合わせないこと）も記載しています。地方4地域には、GTFSデータリポジトリのバスGTFS（熊本5、富山11、徳島6、飯田・下伊那8の計30データ）を使い、事業者・データ名・ライセンス・更新日・有効期間・診断の基準日（有効期間内の水曜と日曜）を画面に表示します。人口は政府統計の総合窓口（e-Stat）の令和2年国勢調査地域メッシュ統計（250mメッシュを500mに集約）、施設は国土数値情報の医療機関データ（病院）と学校データ（小学校・中学校）、GTFSに無い鉄道の駅の位置は国土数値情報の鉄道データ、背景地図は国土地理院の地理院タイルです。各データの出典と、停留所の集約・本数集計・到達時間の計算という加工を行った旨を、画面の「出典・ライセンス・診断の前提」に明記しています。データは前処理で生成し、静的ファイルとして配信します。

## 特徴

1. 「本数」ではなく「行けるか」を診断します。出発時刻、待ち時間、乗継を含めた所要時間で判定し、歩いて行ける地区と公共交通で行ける地区を分けて表示します。
2. 平日と休日、朝8時・昼12時・夕17時の6通りと、許容時間（20・30・45・60分）を切り替えて比較できます。人口と65歳以上人口の両方で集計します。
3. 「行けない」は、歩いても公共交通でも許容時間内に着けない場合だけです。収録していない鉄道の駅から徒歩圏の地区は、赤ではなく灰色にして区別します。
4. 事業者をまたぐ乗継を扱うため、近接する停留所を1つの停留所群に統合しています。
5. 「路線を止めたら？」で、事業者・路線名でまとめた路線ごとに全便を除いた再計算の結果を事前に用意し、ブラウザ上で即座に表示します。
6. 赤と緑の対比を避けた配色、スマートフォンで最初の画面に結論を固定表示、データの有効期限切れの警告を備えます。診断ロジックは、独立に書いた別の計算方法と一致することを自動テストで確認しています。

## 使い方

1. ページを開き、「診断地域」を選びます。画面上部に、収録したデータの件数と、JR等の鉄道が未収録であることが常に表示されます。
2. 「行き先」（病院／小・中学校）、「曜日」、「出発」の時間帯、「許容時間」をボタンで選びます。
3. 地図の薄い青は歩いて行ける地区、濃い青は公共交通で行ける地区、オレンジは行けない地区、灰色は鉄道駅が近い（鉄道は未評価）地区です。パネルの上部に、行ける人の割合と、平日・休日×朝昼夕の比較表が出ます。
4. 地図をタップすると、その地点の診断（病院・学校それぞれの最短所要）と、600m以内の停留所の本数・終発・路線が出ます。
5. パネル下部の「路線を止めたら？」で路線を選ぶと、行けなくなる地区がピンクで表示され、人数が曜日・時間帯別の表で分かります。
6. 「出典・ライセンス・診断の前提」で、収録事業者・データの出典・更新日・有効期間、計算の前提を確認できます。スマートフォンでは下部のパネルを開閉できます。

## 今後の展開

今回は病院と小・中学校を対象にしました。次の段階として、買い物施設（商業施設データの入手方法を確認のうえ）、診療所や避難所などの行き先の追加を考えています。東京では公共交通オープンデータセンターのデータで東京メトロ等の鉄道と民営バスを加えており、同じ方法でほかの地域にも広げられます。JR・大手私鉄の時刻表を取り込めれば、残る「鉄道駅が近い（未評価）」の地区も評価できます。また、徒歩区間を道路網やほこナビのデータで計算すること、運賃やデマンド交通の予約可否の反映、バスロケーション（GTFS-RT）による現在の遅れの表示にも取り組みたいと考えています。さらに、自治体の担当者へのヒアリングで使い勝手を改善し、収録地域は、データとライセンスの確認ができたところから順次追加します。
