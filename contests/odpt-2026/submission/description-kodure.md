# 作品名

子連れお出かけ診断（東京都区部）

## 公開URL

（総司令官が静的ホスティングへ公開後に記入）

## 概要

休日に子連れで、ベビーカーでも無理なく、公園・動物園・水族館・博物館などへ公共交通で何分で行けて、夕方までに帰れるかを、東京都区部の地図で診断するWebアプリです。家（500mメッシュ）を午前9時台または10時台に出て行き先へ着けるかに加え、行き先を夕方16時台または17時台に出て家に帰れるかも時刻表から計算し、「行き帰りとも行ける」を主な指標にしています。出発は時刻1点ではなく、時間帯の先頭30分の間に5分おきに出た場合の所要時間の中央値で判定し、近くの別の駅・停留所（直線300m以内）へは歩いて乗り換えられるものとしています。徒歩はゆっくり（分速60m。ベビーカー連れの仮定）で、1回の徒歩距離の上限（300・500・800m）、乗換回数の上限（なし・1回まで・制限なし）、片道の許容時間（30〜90分）を切り替えられます。見方は2つで、地区をタップするとそこから行ける行き先の一覧（所要・乗換数・帰宅時刻の目安）、行き先を選ぶと行ける地区の塗り分けと0〜14歳の子どもの人数での集計が出ます。収録していないJR・東急等の鉄道は評価せず、その駅の近くは灰色の「未評価」にして、収録範囲を画面に常時表示します。大阪は時刻表のオープンデータが無いため未対応で、行き先の位置だけを表示します。サーバー不要の静的サイトで、スマートフォンからも使えます。

## 解決したい課題

子連れの休日のお出かけは、行き先の候補を調べても「ベビーカーで乗換や徒歩が無理なく行けるか」「夕方に帰れるか」が地図や乗換案内だけでは一覧しにくく、行き先選びに時間がかかります。本作品は、徒歩の距離や乗換の回数を子連れ向けに絞り、行きだけでなく帰りも含めて、行ける地区と行ける行き先を地図と一覧で示します。収録した交通だけ・分速60mの仮定で計算した例では、行き9時台・帰り16時台、片道45分以内、徒歩1回500m以内、乗換1回までの条件で、行き帰りとも行ける行き先が1か所以上ある地区に住む0〜14歳は80.2%でした（徒歩だけで着く近所の公園を含み、公園だけでは78.9%、文化施設だけでは64.9%、動物園・水族館だけでは23.6%）。徒歩1回の上限を300mにすると60.8%、800mにすると92.4%で、徒歩の条件で結果が大きく変わります。行き先による差もあり、東京都恩賜上野動物園は行きだけなら行ける子どもが5.7%、行き帰りとも行けるのは5.4%でした（片道60分なら14.7%）。ただし動物園の最寄りの収録停留所は約420m先で、JR上野駅は未収録のため、実際より低く出ている可能性があります。そうした最寄りの収録停留所が遠い行き先は、画面に「停留所が遠い」と表示します。行きは行けても帰りは行けない地区があることも示せます。

## 使用データ

公共交通オープンデータセンター（ODPT）の東京の15データを使いました。都営バス・都営地下鉄等・文京区・千代田区・北区のコミュニティバス（CC BY 4.0）と、東京メトロ、東京臨海高速鉄道、首都圏新都市鉄道、関東バス、京王バス、西武バス、小田急バス、中央区・目黒区・品川区のバス（公共交通オープンデータ基本ライセンス。開発者登録で得たアクセストークンで取得）です。チャレンジ限定ライセンスのデータは使っていません。公開データには個々の便の時刻を含めず、所要時間を5分刻みにした結果だけを出力しています。行き先は国土数値情報の都市公園（P13、面積1ha以上）と文化施設（P27の動物園・水族館・博物館等）で、いずれも提供元の一覧ページで使用許諾条件が非商用と表示されており、条件を画面と資料に明記しています。人口は政府統計の総合窓口（e-Stat）の令和2年国勢調査地域メッシュ統計（総数と0〜14歳）、未収録鉄道の駅は国土数値情報の鉄道データ、背景地図は地理院タイルです。出典と、停留所の集約・日曜ダイヤでの所要時間の計算という加工、ODPT開発者ガイドラインが求める通知事項を、画面の「出典・ライセンス・診断の前提」に表示しています。

## 特徴

1. 「行き帰りとも行ける」を主な指標にしました。午前に家を出て行き先へ着けるかと、夕方に行き先を出て家に帰れるかを、それぞれ待ち時間・乗継を含めて計算し、片道だけ行ける地区を区別して示します。
2. 子連れの条件を切り替えられます。ゆっくりした徒歩、1回の徒歩距離の上限、乗換回数の上限を変えると、行ける地区と行き先がその場で変わります。徒歩速度・乗継の余裕は根拠のある調査値ではなく仮定であることを画面に明記しています。大きい公園は中心の点ではなく、面積から半径を仮定した外周の点（入口の代わり）までで判定します。
3. 地区から行き先の一覧を見る使い方と、行き先から行ける地区と子どもの人数を見る使い方の2つがあります。人数は0〜14歳人口と総人口の両方で集計します。
4. 収録範囲を常時表示し、JR等の未収録鉄道の駅が近い地区は赤ではなく灰色（未評価）にします。大阪は時刻表のデータが無いことを明記し、時間を出さず位置だけを示します。
5. 赤と緑の対比を避けた配色、最初の画面に結論を固定表示（スマートフォン・PC）、データの有効期限と取得できなかったデータの警告を備えます。乗継・時間帯の中央値・公園の入口などの計算は自動テストで確認し、乗継つき探索は別に書いた参照実装と合成の交通網で一致することを確認しています（外部の乗換案内との突き合わせはしていません）。

## 使い方

1. ページを開くと、東京都区部の地図に、行き帰りとも行ける行き先の数が色で出ます。画面上部に、収録範囲（JR等は未収録）とデータの期限が常に表示されます。
2. 「行きの出発」「帰りの出発」の時間帯、「片道の許容」時間、「徒歩1回の上限」、「乗換」の回数、「行き先の種類」（公園・動物園・水族館・博物館等）を選びます。
3. 「地区から探す」では、地図で家のある地区をタップするか住所・駅名で探すと、行ける行き先の一覧が出ます。各行き先の行き・帰りの所要、最少の乗換回数、帰宅時刻の目安が分かります。
4. 「行き先から探す」では、地図の行き先の点か一覧から選ぶと、行き帰りとも行ける地区が濃い青、片道だけの地区が水色で塗られ、行ける子ども（0〜14歳）の人数と割合が出ます。
5. 「大阪」を選ぶと、時刻表が無いため所要時間は出さず、行き先の位置だけを表示します。
6. 「出典・ライセンス・診断の前提」で、データの出典・ライセンス・有効期間、仮定と限界を確認できます。

## 今後の展開

駅のエレベーター等のバリアフリー情報（ODPTの駅情報の項目を確認のうえ）を乗継の余裕に反映すること、徒歩速度（ベビーカー）の実測根拠の確認と画面での切り替え、公園の実際の入口・形状（現在は面積から仮定した外周の点）に基づく判定に取り組みたいと考えています。授乳室・おむつ替え、児童館などの行き先や属性の追加も、座標と利用条件を確認できたデータから進めます。JR・東急等の時刻表を取り込めば、灰色の「未評価」の地区も評価できます。大阪は、地下鉄・バスの時刻表が公開されれば同じ仕組みで診断できます。国土数値情報の都市公園・文化施設の「非商用」の利用条件は、公開前に提供元で確認します。
