# 偵察: 提案A デモの実衛星データ化（2026-11-21、偵察隊。参謀長が本文を保存）

総司令官の指示「衛星データを使ってアプリを仕上げてください」（対象: contests/satellite-2026/app/proposal-a/、締切 11/30 12:00）。

## 結論（推奨）
**豊中市（大阪府）で、衛星・道路・下水道を全部実データに置き換える案A。** 衛星は国土地理院の干渉SAR成果の地理院タイル、道路は OSM、下水道は豊中市オープンデータの管渠（竣工日つき）。総司令官の操作は不要（取得はすべて GET）。
ただし豊中市は地表変位がほぼ平坦で、衛星の点数ではほとんど絞れない。これは隠さず「絞れない地域では台帳と過去調査の重みが前に出る」結果として見せる。

## 1. アカウント不要の衛星変位データ（取得して確認）
- 成果: 国土地理院「衛星SAR地盤変動測量成果」。全国の干渉SAR時系列解析の変位速度。2026-03-31 公開分は 2014-08〜2025-11 の観測、だいち2号・4号（Lバンド）。**Sentinel-1 ではない**
- 配布: `https://insarmap.gsi.go.jp/xyz/merge_sbas_regular_japan_20260331_{dr,ar,qu}_u16/{z}/{x}/{y}.png`（dr=南行、ar=北行、qu=準上下）。z5〜18（実質 z15 まで）。GET・認証なしで 200。レイヤ定義 `sarprod.gsi.go.jp/gsiMaps/sar/layers_txt/layers_for_sar.txt`。地理院タイル一覧（ichiran.html）には該当レイヤなし
- 画素 約90m。GSI は「数百m四方より狭い変動の把握は困難」と明記（生活道路単位は本来の用途の外）
- 色→値: 凡例 `tsa_bcyr2_qu_-3_3cm.png` は -3〜+3 cm/年を16階級（1階級 3.75 mm/年幅）。タイル色は凡例色にほぼ一致。値は階級幅としてのみ言える（±約1.9 mm/年の丸め）。dr/ar の凡例が同じ16階級かは未確認
- 連続値（GeoTIFF）は「衛星SAR地盤変動測量成果ダウンロードサービス」（sarprod.gsi.go.jp）。画面操作が POST のため未取得、ログイン要否未確認、最新年度のみ
- 利用条件: 地理院コンテンツ利用規約。クレジット『解析：国土地理院 原初データ所有：JAXA』。加工した旨の明記。**基本測量成果の複製・使用に申請が要る場合がある（SAR 解析結果は個別条件）。静的な派生データの公開可否は憲兵の確認か地理院への問合せが要る**
- その他: J-GMS（東大 IIS、Sentinel-1、約30m）は閲覧のみでダウンロード条件未確認。COMET-LiCSAR は配布元に接続できず未確認

## 2. アカウントが必要な道（作成・ログインはしていない）
- ASF HyP3: 無料枠 月8,000クレジット、InSAR 80m 画素 10クレジット/件。出力は1ペアの解除位相とコヒーレンスで、速度には MintPy 等の時系列解析が別途必要。8日で間に合う見込みは低い。推奨しない

## 3. 下水道の公開データ（管路単位・竣工年つき）
- **豊中市**のみ確認: CC BY 4.0、BODIK `272035_gesuido`（ZIP 約27MB、シェープ）。管渠 46,037本、延長 約1,078km、竣工日 1954〜2025、JGD2011 平面直角6系（EPSG:6674）、属性 `SYUNKOU_BI`（竣工日）・`HYOUJI_KEI`（管径）・`KANSYU`（管種）。竣工日 9999（不明）が 3,074本（6.7%）。コード凡例は未確認（使うのは竣工年と管径）
- 不採用: 半田市（JS 認証で取得不可）、新潟市・仙台市・米沢市・国土数値情報 P22（施設の点のみ）、静岡県（流域幹線、属性未確認）、神戸市・岡山市・中津市（閲覧のみ）
- OSM 道路: Overpass の GET 可（UA ヘッダ必須、無いと 406）。豊中の bbox で道路 9,735本（residential 7,286）。ODbL（クレジット、同一ライセンスでの配布）

## 4. 実データの試験（豊中市、qu レイヤ）
| 階級（mm/年） | 全タイル画素 | 管渠サンプル（2,302本の中点） |
|---|---|---|
| -3.75〜0 | 6.0% | 153本（6.6%） |
| 0〜+3.75 | 93.7% | 2,149本 |
| +3.75〜7.5 | 0.3% | 0本 |
- 衛星階級・竣工年・管径の結合は動いた（年代判明 2,138/2,302）。実質は平坦。神戸ポートアイランドは強い沈下（-30〜0 mm/年帯に約8割）だが台帳の公開データがない
- 管渠と OSM 道路の突き合わせは未試験

## 6. 工兵への要点
- 実データにする: 道路網・区画・衛星指標・台帳の竣工年。地中レーダの結果は `sim_cavity` のまま（架空と画面・README・出典に明記）
- 区画: 90m 格子。衛星は階級の中央値と階級幅を持たせ、小数で精度を装わない
- 衛星の表記: 「ALOS-2/4（Lバンド）、国土地理院解析、約90m、階級 3.75 mm/年幅」。**Sentinel-1 とは書かない**。提案書（Sentinel-1 を主に想定、ALOS-4 は比較検証）との関係を画面で説明
- 台帳: 「竣工年（台帳の竣工日）」、不明は独立区分（6.7%）
- 結合: OSM 道路を区間に分け、管渠を最近傍で紐づけ。突き合わせ率を先に測る。座標変換 EPSG:6674→4326
- 出典: GSI のクレジット文、© OpenStreetMap contributors（ODbL）、豊中市（CC BY 4.0）、加工した旨
- 立場: 「衛星は空洞を直接見つけず、地上調査の投入先を選ぶ」
- 憲兵へ: GSI 成果の静的派生データの公開可否
