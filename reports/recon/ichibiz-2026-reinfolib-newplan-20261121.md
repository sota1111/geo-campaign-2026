## 2. 案ごとの詳細

### A 「同じ土地、四つの値段」（推奨・条件付き）

- 題材: 同じ土地に、公示価格・相続税の路線価・実際の取引・収益から見た価格と、複数の「ものさし」がある。国が作った鑑定評価書は、標準地ごとに取引事例比較・収益還元・原価・開発の各価格と、その内訳（取引事例 a〜e、還元利回りなど）を持つ。これを、地点から近い標準地ごとに「なぜその価格か」の形で並べる。相続・売却・税の説明で価格の違いに戸惑う人向け。
- 海外事例: 米国クック郡（シカゴ）の固定資産税評価。ProPublica Illinois と Chicago Tribune の調査報道「The Tax Divide」（2017年）が、高額の住宅が過小評価、低額が過大評価という逆進的な評価を示し、独立研究でも確認され、改革につながった（出典: https://www.propublica.org/series/the-tax-divide ／ 改革の効果: https://www.cookcountyassessoril.gov/news/cook-county-homeowners-saved-19-billion-under-fritz-kaegis-reforms-university-chicago-study ）。評価の「ものさし」を公開データで見える化すると、市民の判断が変わるという型。注意: 本件は固定資産税評価そのものは扱えない（ライブラリに無い）。調査の型を借りるだけで、同じ分析を日本でするとは言わない。検索では「評価モデルのオープンソース化」までは確認できなかったので、事例には書かない。
- 使う API と確認済みの事実（マニュアル。実打ちは未実施）:
  - XCT001: パラメータは year（2022〜2026、直近5年だけ）、area（都道府県コード）、division（00 住宅地、03 宅地見込地、05 商業地、07 準工業地、09 工業地、10 調整区域内、13 現況林地、20 林地(県調査)）。出力は gzip。項目に「公示価格」「1㎡当たりの価格」「変動率」「緯度・経度」「路線価 相続税路線価」「路線価 倍率」「取引事例比較法比準価格」「収益還元法 収益価格」「還元利回り」「法令上の規制（区域区分・用途地域・指定建蔽率・容積率・防火地域）」「接面道路」「供給処理施設」「交通施設」、取引事例 a〜e の内訳などがある（https://www.reinfolib.mlit.go.jp/help/apiManual/xct001/ ）。
  - XPT002: 1995年〜最新年の標準地。同じ標準地の前年価格と変動率が項目にある（https://www.reinfolib.mlit.go.jp/help/apiManual/xpt002/ ）。
  - XIT001: 取引価格（地区単位）。既に現行案で使い方が確立済み（reports/ops/reinfolib-integration-20261112.md）。
- 実際に叩いた結果: **未実測**。probe-all.mjs は XCT001 を福岡県の住宅地・商業地で呼び、件数と「路線価・取引事例・収益価格・還元利回り」の埋まり具合を出す。見る点: 件数（標準地の数）、路線価欄の埋まり率、収益価格が住宅地で空でないか。県は福岡県を仮置きした（都心から郊外まで価格の幅があるはず、という仮説。件数で決め直す）。
- 規約・制約（コンテンツ出典ページ。XCT001 の独立した行は無く、地価公示（No.1）の備考で鑑定評価書の CSV が言及される）:

  - 社会: 3。相続・売却時の価格の戸惑いを減らす。件数・被害など公的事実を未取得のため3。
  - 実現: 4（実測前の仮置き）。取得が少なく、タイル処理が要らない。
  - 事業: 3。払い手の仮説は、税理士・不動産会社・金融機関の説明資料作成。価格の根拠なし。
  - 発表: 4。「同じ土地に、値段が四つある」で伝わる。

- 主なリスク: (1) XCT001 の項目の埋まりが薄い場合、価値が落ちる（実打ちで判定。薄ければ B へ）。(2) 固定資産税評価額はライブラリに無く、「四つ」のうち実データは3〜4つ。四つ目は文章の説明にとどめ、出典を付ける（「公示価格の○割」など一般に言われる比率は、国交省等の一次情報で確認してから書く。偵察隊は未確認）。(3) 年次が2022〜2026年の直近5年だけで、時系列の分析には向かない（時系列は XPT002 で補う）。(4) 標準地は点で、町全体の値段に見える誤読。
- 転用: 不動産部門に固有。転用候補なし。
- 本人の体験の差し込み先: 相続・売却・固定資産税の通知書を見て戸惑った経験、または税理士・不動産会社への聞き取り1件。背景300字は本人が書く（生成AI条項）。

### B 「計画線チェック」

- 題材: 都市計画道路の区域に入る土地は、都市計画法 第53条の建築許可が要る。計画決定から長く着手されない路線もある。買う前・持っている土地が予定地にかかるかを、住所から確認できるようにする。
- 日本の事実: 国土交通省資料で、全国の都市計画道路は計画延長約6.4万km、うち未着手約2.1万km（32.2%）、約8割の自治体が見直し済み（検索結果の要約。一次資料の閲覧は未了。https://www.mlit.go.jp/common/001250461.pdf ）。東京都の特別区・広島市などは、3階建てまでの許可に緩和（要件の例: 階数3以下・高さ10m以下・地階なし）。
- 海外事例: 英国 Groundsure の HS2 レポート。高速鉄道 HS2 の計画路線・保全区域（safeguarding）・補償区域に物件が入るかを、距離つきで「検出／非検出」で示す購入前調査（https://todaysconveyancer.co.uk/new-groundsure-energy-hs2-crossrail-report-at-searches-uk/ ）。注意: HS2 の保全区域は2024年1月に第2a期の多くで解除、2025年7月に第2b期東側の多くで解除と、状況が変わる（https://www.gov.uk/government/publications/hs2-safeguarding-guidance-for-property-owners ）。つまり「計画線は変わる」前提で、確認日と情報源の表示が要る。
- 使う API: XKT030（都市計画道路。項目: 種別、決定日、最初の決定日、告示番号、決定権者。形状が線か面かはマニュアルに記載なし＝未確認）、XKT023 地区計画、XKT024 高度利用地区。いずれも商用「〇」（都市計画決定GISデータ 令和7年度）。
- 実際に叩いた結果: **未実測**。probe-all.mjs は福岡市中心の1タイル（z14）で XKT030・XKT023・XKT024 の件数と形状種別を出す。
- 審査基準ごとの見込み（主観）: 独創3（自治体の Web GIS が多数ある可能性。国内競合は未調査）。社会3。実現3（形状と、計画幅員の項目が無い点が未確認）。事業4（払い手の型が明快: 不動産会社・金融機関・自治体の窓口対応）。発表4。
- 実装の規模（仮説）: 5〜7人日（点と線の距離計算、タイル取得、断定しない文言設計が主）。
- 主なリスク: (1) 計画幅員が項目に無いと、「かかるか」の判定が粗い。(2) 「かかる」と出すと価値下落の誤解につながる。確認日・出典・自治体窓口への誘導に限る。(3) RN3（前回の宅建士案）と XKT030 が重なる。
- 転用: なし。

### C 「原野商法ガード」

- 題材: 昔買った原野などを「売れる」「買い手がいる」と電話し、測量・広告費などの名目で支払わせる二次被害。売る前に、その土地の相場・取引の有無・規制を、公的データで確認できるようにする。
- 日本の事実（二次情報。一次資料の確認が必要）: 検索で確認できた範囲では、政府広報の記事が国民生活センターのデータを引き、原野商法の二次被害の相談件数は2018年度1,589件、2019年度509件、2023年度301件、2024年度258件（2025年2月28日までの登録分）、平均支払額は2024年度約258万円（2023年度約110万円）、契約者の年代は70歳代が約4割（京都府のページが国民生活センターの調査として記載）。政府広報の元記事は取得できず（HTTP 403）、検索要約の記述を使っている。本文で使う前に、国民生活センター（https://www.kokusen.go.jp/news/data/n-20180125_1.html ）などの一次資料で再確認すること。
- 海外事例: 英国の land banking（土地の区画投資）詐欺。「計画許可が下りれば大きく値上がりする」と勧誘するが、許可は申請もされない、またはグリーンベルト等で下りない。FCA は損失を最大2億ポンド規模と推計し、確認には自治体の計画担当・FCA の Firm Checker を勧める。FCA は土地の売買自体は規制しない（https://www.fca.org.uk/scamsmart/land-banking-investment-scams ）。公的な情報で「その土地の開発可能性」を先に確認させる型。
- 使う API: XPT001（取引価格のポイント。landTypeCode: 10 農地、11 林地。period は from/to で YYYYN 形式、2005年第3四半期〜）、XKT019 自然公園地域（一部非商用。非商用の自治体は岡山県と記載）、XKT001・XKT002（区域区分・用途地域）、XPT002（近くに標準地があるか）。取引価格は地区単位で、近くに取引が無い場合は XIT001 が 404 を返す（マニュアルの記載）。
- 実際に叩いた結果: **未実測**。probe-all.mjs は栃木県那須町付近・北海道釧路付近の1タイルで、林地・農地の取引ポイント件数と、那須町付近の自然公園地域の件数を出す。
- 審査基準ごとの見込み（主観）: 独創3。社会5（高齢者の財産被害、1件の平均支払額が大きい）。実現3（「取引が無い」を「売れない」と読ませない設計が難しい）。事業2（払い手は消費生活センター・自治体・金融機関の高齢者見守りなど仮説。市場規模の出典なし）。発表4。
- 実装の規模（仮説）: 5〜7人日。
- 主なリスク: (1) 現行案 R0（相続した土地の国庫帰属）と題材が近く、同じ審査チームには同種に見える。(2) 取引が少ない地域で、データが空のまま画面が成り立たない恐れ。(3) 個別の業者・事例を名指ししない運用が必須。
- 転用: なし。

### D 「まちの変わり目」（見送り）

- 題材: 地価の長い時系列と、地区計画・高度利用地区などの開発系の区域を重ね、住民が住み続けにくくなる圧力の兆しを見る。
- 海外事例: 米国ニューヨークの Displacement Alert Project（ANHD。市の公開データから、規制家賃住宅の減少・取引・苦情・工事許可などで建物の立ち退きリスクを示し、借家人団体の活動に使う。https://thenyhc.org/projects/displacement-alert-project ）、UC バークレーの Urban Displacement Project（国勢調査等から地区の変化を類型化。https://www.urbandisplacement.org/ ）。
- 使う API: XPT002（year は1995年〜）、XPT001、XKT023、XKT024。
- 実際に叩いた結果: **未実測**。probe-all.mjs は福岡市中心の同じタイルで2015年と2025年の標準地数を出し、継続性を見る。
- 見送りの理由: 海外事例の核は「借家人・立ち退き・苦情」の個票データで、ライブラリには無い。地価上昇だけで「立ち退きの圧力」と言うのは飛躍で、根拠のない効果になる。多年×多タイルの取得量が大きく、実現2点。
- 転用: なし。

## 3. 推奨と理由

**推奨: A「同じ土地、四つの値段」。ただし、実打ちで XCT001 の項目が埋まっていることを確認する条件付き。**

理由（偵察隊の判断）:
1. 他の案より API の使い方が深い。XCT001 は鑑定評価書の内訳（取引事例・収益価格・還元利回り・路線価）を持ち、ほかの応募でもあまり使われないと推測する（確認はしていない）。部門の趣旨（ライブラリのデータで新しい活用を示す）に近い。
2. 取得が県×用途区分の数回の呼び出しで済む見込みで、締切（12/10）までの時間に収まりやすい。B・C・D はタイル取得と形状処理が要る。
3. 現行案（相続土地の1枚シート）・RN1（立地の先行き）と題材が重ならない（価格の見方）。同じ審査チームには別の型に見える。
4. 海外の型（クック郡の評価の見える化）が「情報の非対称を公開データで埋める」型で、社会的効果の語りに使える。

条件・不利な点:
- XCT001 の路線価・収益価格が薄い、または 404/空の場合は A の価値が落ちる。その時は B（計画線）へ切り替える（B は XKT030 の形状確認が前提）。
- 社会的効果の「公的な事実」が弱い。A を選ぶなら、相続・売却時の価格の混乱を示す一次資料を情報部に探してもらう。
- 国内の既存の同種サービスの調査が未了（情報部に依頼）。
- C は社会的効果が最も強いが、R0 と近い。総司令官が「社会」を最重視し R0 との近さを許容するなら C が代替。

## 4. 工兵への実装の要点（A を選んだ場合）

- 画面（現行 biz-realestate・RN1 の隣に追加。置き換えない）: (1) 地点を入れる（住所検索または地図で指す）→ (2) 近くの標準地3〜5件を距離順に出す → (3) 各標準地を1枚のカードにし、「公示価格」「路線価」「取引事例の価格」「収益から見た価格（利回り）」を同じ単位（円/㎡）で並べ、値の差を「なぜ違うか」の短い説明つきで出す → (4) 出典・加工・責任の表示と、「標準地の価格で、この土地の価格ではない」の併記。モバイルで横スクロールを出さない。
- データ取得の流れ: 事前にローカルで取得して静的 JSON に同梱する（ブラウザからは API を呼ばない。キーを出さない。現行 fetch-reinfolib.ts と同じ方針）。XCT001 は 県×用途区分（00・05 を優先）の数回、XPT002 は同じ範囲のタイル、XIT001 は市区町村単位。間隔は 300〜500ms 以上。キーは環境変数 REINFOLIB_API_KEY だけ。
- 地域: 1県を選ぶ。仮置きは福岡県（都心〜郊外の幅）。実打ちの件数と路線価の埋まり率で最終決定。徳島県は現行案が使っているので避ける。
- 使う API: XCT001（核）、XPT002、XIT001。
- 最初の確認（0.5日）: probe-all.mjs 相当で XCT001 の件数・各項目の埋まり率・レスポンスサイズ（gzip の扱い）を確認。薄ければ停止して総司令官に戻す。
- 規約: 現行案の `reinfolib.ts` の定数（クレジット・出典・加工・責任の文）を流用。同梱 JSON の置き場所は現行案と同じ方針。キー混入の確認は「真偽のみ出力」の方法を踏襲。
- してはいけない表現: 「査定」「適正価格」「相場より安い・高い」の断定。サービス名に「不動産情報ライブラリ」を使わない。

## 5. 要確認事項（優先順）

1. API の実打ち（本レポートの最大の未了）。hook により偵察隊は実行できなかった。probe-all.mjs の実行を総司令官側で。
2. XCT001 の応答サイズ・埋まり率・レスポンス形式（マニュアルは gzip と記載）。
3. 国内の既存サービス調査（A の独創の点は仮置き）。情報部へ。
4. 「一物四価」の各価格の関係（公示価格に対する相続税路線価・固定資産税評価額の水準）は一次資料で確認が必要。偵察隊は未確認で、数値を書いていない。
5. 同梱 JSON の二次配布の明示の条文は未確認（前回偵察の抜け6）。新しいデータを置く前に再確認。
6. 原野商法の統計は政府広報の元記事が取得できず、検索要約。使うなら国民生活センターの一次資料で再確認。
7. 都市計画道路の全国統計は検索要約。XKT030 の形状種別は未確認。
