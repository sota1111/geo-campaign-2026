# odpt-2026 開発者サイト「チャレンジ2026 関連情報」調査（取得日 2026-11-12）

取得方法: WebFetch では本文が取れなかった（JS描画）。参謀長が Chrome でページを開き、本文とリンクを抽出した。読むだけで、ログイン・フォーム送信・トークン画面の閲覧はしていない。
締切などの変更: なし。応募終了は 2027/1/11（月・祝）23:59 JST で、registry と一致。[P1]

## 要約（失格・実装に効く事項を先に）
1. **応募フォームの提出物が判明**（既存レポートの未確認1を解消）。必須: 作品名・公開URL・説明（約400字、最初の一文で概要）・紹介資料PDF・**YouTube動画（3分以内）**・スクリーンショット（5枚以内）・マニュアルURL（作品に埋め込みなら不要）・使用オープンデータ一覧・アンケート。[P1]
2. **提出後は修正不可**。保存→「提出」の2段階で、保存中は何度でも直せる。[P1]
3. **データのライセンスは3種類あり、アクセス方法が違う**。[P1][P2]
   - CC0 / CC BY 4.0 / ODC BY 1.0 / ODbL 1.0: 登録不要。データ説明ページのAPI URLをそのまま使う。
   - 公共交通オープンデータ基本ライセンス: 登録が必要。「ODPTセンター用アクセストークン」を使う。
   - **公共交通オープンデータチャレンジ限定ライセンス**: 「チャレンジ2026専用アクセストークン」を使う。**チャレンジ期間中だけ利用できる**。
4. **限定ライセンスのデータは再配布禁止**（第8条4項）。複製物や、元データの全部または大部分を復元できる派生データを、第三者が再利用できる状態で公開してはいけない。静的サイトに生データや復元可能なJSONを置く構成は抵触するおそれがある（解釈は推測。要監査）。[P3]
5. **限定ライセンスは 2027/3/12 で終了**し、終了後はデータを削除する義務がある。利用目的がチャレンジ応募以外にもあると判断されると、利用停止や法的措置の対象になる。[P3]
6. **JR東日本データには特定利用条件がある**。競合サービスの開発・改善に使わない、特許出願したら協議会へ通知する、知的財産権をJR東日本に行使しない。これらはコンテスト終了後も続く。[P3]
7. **アプリへの表示義務**（開発者ガイドライン。基本ライセンスのデータが対象で、限定ライセンスも第4条3項・第10条3項でガイドラインに従う）。[P4][P3]
   - 動的データ: `dc:date` を画面に表示する。`odpt:frequency` の間隔で更新する。`dct:valid` を過ぎたデータは使わない。
   - 静的データ: 取得日時を、すぐ見られる画面に表示する。更新通知から1週間以内に更新する。
   - 3点を必ず表示する: ①データは公共交通オープンデータセンターが提供していること、②正確性・完全性は保証されないこと、③開発者の問い合わせ先（メール等）。事業者へ直接問い合わせないよう案内する。例文はガイドライン3.1にある。
   - ロゴ・路線ラインカラーは加工しない。機械翻訳を使う場合はその旨を示す。
8. **連携オープンデータ（推奨）の一覧が判明**（下のリンク一覧）。

## 使い方（手順順）
1. **開発者登録**: developer.odpt.org でユーザー登録する。確認に最大2営業日かかる（既存レポートと一致）。※ 11/12 時点で、Chrome の challengeinfo ページのヘッダーには「ログイン中」と表示されていた。総司令官のアカウントは登録済みとみられる。ただし、ほかのページでは「ログイン」と表示された。
2. **データを探す**: 公開データの詳細 https://ckan.odpt.org/ で各データセットのライセンス欄を確認する。ライセンスによって手順4が変わる。[P1]
3. **トークンを確認する**: ヘッダーの「ログイン中」→「ODPTセンター用アクセストークン」または「チャレンジ2026専用アクセストークン」。チャレンジ用は https://developer.odpt.org/challengeeditkeys で確認・追加発行できる。[P1]（参謀長はトークン画面を開いていない）
4. **APIを呼ぶ**: データ説明ページに載っているAPI URLの「アクセストークン」部分を、上のトークンに置き換える。CC系ライセンスのデータはURLをそのまま使う。[P1]
   - 既存実装は `api.odpt.org/api/v4`（要トークン）、`api-public.odpt.org/api/v4`（トークン不要）、`api.gtfs-data.jp/v2` を参照している（contests/odpt-2026/app 内のURLを grep した結果）。
5. **GTFSデータリポジトリ**: https://gtfs-data.jp/ で利用方法と条件を確認する（今回はリンク先を未読）。[P1]
6. **作品を公開する**: 誰でもアクセスできる状態にする。アプリはストアのURL、Webサービスはそのサービスの URL を登録する。[P1]
7. **応募する**（2026/10/1〜2027/1/11 23:59）: 「作品を応募する」(https://developer.odpt.org/applicationlist) →「応募作品を追加する」→ 入力して保存 → 一覧で「提出」。[P1]

## 提出物の詳細（応募フォーム）[P1]

| 区分 | 項目 | 要否・条件 |

| 作品 | マニュアルURL | 必須。ただし作品に埋め込んであれば不要。PDFやHTML |

| アンケート | 公開時期／利用者数／チャレンジ後の公開予定（3択）／データへの意見 | 回答必須。審査には影響しない |

使用データの記述例（公式）: 「* 公共交通オープンデータセンター: https://ckan.odpt.org/ − JR東日本のGTFS・GTFS-RTデータ …」のように、提供元ごとに箇条書きする。
