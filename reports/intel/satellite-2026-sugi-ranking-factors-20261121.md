# satellite-2026 sugi案: 区分1の中の順位づけ — 要因と重みの根拠整理（500mメッシュの点数式に向けて）

- 作成: 情報部（intelligence）／取得日: 2026-11-21（すべての出典の取得日）
- 依頼: 参謀長経由（総司令官指示「花粉症の論文を参照して、順位を付けてください」）。対象 contests/satellite-2026/app/proposal-sugi/（関東版）。実装はしない。
- 既存報告 reports/intel/satellite-2026-sugi-countermeasures-20261121.md（以下「前報告」）の内容は省略し、[R1]〜[R6]・[F1]・[F6] などの番号はそのまま使う。本報告で新しく読んだ資料は [N1]〜[N7]。
- 信頼度: ◎ 公式PDF・論文PDFの本文（画像）を直接読んだ／○ ページ取得を要約ツール経由で読んだ／△ 検索結果の要約のみ（確定扱いにしない）
- 先に結論（3点）
  1. 「林齢」は区分1の中の順位を分けない。林分あたりの雄花量は林齢が一定以上（資料により30〜50年生）で頭打ち、区分1は26年生以上が過半の所で、関東のスギ人工林の97%が26年生以上（README）。順位を分けるのは「面積」「人への近さ（人口）」「まとまり」になる。
  2. 距離による減り方の式、風下の重み、林齢別の雄花量の関数は、公的資料・論文では数値として見つからなかった。点数式の距離・風の重みは「仮置き」にするしかない。仮置きの置き方と確かめ方は2章に書いた。
  3. 林野庁・環境省・都県が「花粉への影響の大きさ」でスギ林に順位を付けた公開済みの方法は見つからなかった。確認できた最も近いものは、森林総研の首都圏の発生源推定（人口×飛散を発生源別に集計）[R1]と、森林総研が「ゾーニング手法の開発」を研究中と示した資料 [N1]。

### 1-6 優先度の付け方（公的な方法）
- 国の方法は2段: (ア) 都市から50km圏のまとまったスギ人工林、(イ) 分布・気象から大量飛散のおそれを都道府県が特に認める森林 [F1]。(イ)の判断基準・手順は文書に無い（前報告）。
- 林野庁・環境省・都県の資料で、花粉の影響を点数化して順位を付けた方法は、今回の範囲では見つからなかった。神奈川・埼玉・東京の重点区域の選定基準も検索で確認できなかった（△）。
- 近いもの: 森林総研「ゾーニング手法の開発」を研究課題に掲げ、「雄花量の判別（ドローン写真）→ 雄花量の地域性 → AIを使った雄花量の多い林の条件の探索」と整理（2023年の説明資料） [N1] スライド5-6 ◎。成果の公開は確認できていない。
- 実行面の障害として、都道府県は「採算面の課題による森林所有者の主伐意欲の低下」「少花粉苗木の供給」「労働力」を挙げる [N7] p.5 ◎。傾斜・路網での優先づけは文書に無い（前報告 2-7, 2-8）。

### 1-7 年による変動（順位の安定性）
- 雄花生産量は年によって100倍以上違うことがある（茨城県八郷町7林分、1988〜2000年）。前年の雄花量と前年夏の日射量でかなり説明できる（決定係数 0.67・0.49・0.77）。豊作の翌年は少ない [N3] p.6 ◎。
- 関東の県別推定値でも2010・2012年は埼玉18,000〜19,000個/m2、2009・2011年は約2,000個/m2 [N4] 図1 ◎。
- 含意: 地点別の単年の雄花量や飛散数で500mメッシュの重みを決めない。順位は年によらない量（面積・位置・人口）で作り、実測との照合は複数年の平均で行う（[R1]の「数年間の集計」と同じ考え方）。

## 2. 推奨する点数式（根拠の強さ別。工兵向け）

記号: 500mメッシュ i（kanto.js の cells）。a26_i = n26_i × 0.04 ha（20mセル25個=1ha）。dist_i = 最短の起点までの km（cells.dist）。Pop_j = 人口メッシュ j の人口。d_ij = i と j の距離 km。

### 2-1 根拠あり（出典で裏付け。式に入れてよい）
| 項目 | 内容 | 根拠 |
|---|---|---|
| 対象の絞り込み | 区分1（既存の判定）のメッシュのみ順位づけ。重点区域の市町村内・50km圏内は既存の判定に含まれる | [F1][F6] |
| 発生源の強さ E_i | E_i = a26_i（ha）。26年生以上のスギ人工林面積。林齢が26年生以上なら、林齢で重みを変えない | [R1][R2]、頭打ち [N2][N3] |
| 曝露の構造 | 「発生源の量 × 到達 × そこに住む人口」の積を発生源別に集計するのが森林総研の方法。点数もこの形にする（積の形） | [R1] |
| 人口の使用 | 発生源の優先度には人口を使う（居住者が浴びる花粉を評価） | [R1][N6][N7] |

### 2-2 根拠は方向だけ（出典はあるが数値の重みは無い。形は採用し、数値は2-3の仮置き）
| 項目 | 方向を示す出典 | 出ていない数値 |
|---|---|---|
| 人への近さ（距離による減り方） | 近い地点ほど雄花量の影響が大きい（東京12地点の回帰係数 0.39〜2.91）[N4]。近接林・風向に左右される（△） | 減衰の式、距離の尺度 |
| まとまり（周囲のスギ林の密度） C_i | 森林総研は4kmメッシュ・5kmメッシュの面積割合で発生源を示し [N3][R2]、政策も「まとまった」人工林 [F1] | 割合の閾値と重み |
| 風下 | 年・気象で変わる、数年集計が必要 [R1][N5] | 方位別の重み |
| 実行しやすさ（傾斜・路網） | 採算が主伐意欲を左右する [N7] p.5 | 傾斜・路網の閾値 |

### 2-3 仮置き（作成者の基準。画面に「仮置き」と書く）
推奨する形（1本の式）:

```
S_i = a26_i × X_i
X_i = Σ_j Pop_j × K(d_ij)          （風を使う場合のみ ×W_ij、後述）
K(d) = 1 (d ≤ R) / 0 (d > R)       R は 10・20・30 km を切り替え、初期値 20 km（仮置き）
```
- 順位は区分1の中のS_iの百分位（上位10%・25%・50%…）で示す。S_iの値そのものを「花粉量」「効果」と呼ばない。
- R=20kmの理由（出典は内部の検証結果で、強い根拠ではない）: README記載の東京12地点の2026年累積飛散数との相関が、周囲の26年生以上スギ面積の半径10km/20km/30kmでρ=0.88/0.92/0.87（n=12、単年、風向なし）。20kmが最大だが差は小さく、「20kmが正しい」とは言えない。工兵は東京都の9年分（2009〜2017の12地点、[N4] 表2）か、[R6] の13年分で同じ照合をやり直し、3通りのRで順位がどれだけ変わるかを画面の感度表に出す。
- 人口 Pop_j は地域メッシュ統計（250m、令和2年国勢調査、READMEの旧版で使用済みの e-Stat 統計表 T001102）。kanto.js には人口が入っていないので、関東全域分を追加取得して集計する必要がある（取得すべき1次メッシュの番号は工兵が確認。当方は未確認）。READMEは「人口・風向は旧版のみ」と記載。
- 人口を追加できない場合の代替（根拠は弱い）: X_i = max(0, 1 − dist_i/50)（直近の起点までの距離で線形に1→0）。50kmは政策の目安線 [F1] であって減衰の法則ではない。この代替を使うなら画面に「人口は使っていない」と書く。
- 風（任意・初期値はオフ）: W_ij は i から見て j が風下になる日の割合×16（旧版の定義）。単一地点・3年の最多風向は限界が既知なので、使うなら「感度確認用」とし、順位の初期値には入れない。使う場合は複数年（3〜5年）の集計 [R1][C1]。
- まとまり C_i = i を中心とする9×9メッシュ（約4.5km四方、[N3] の4kmメッシュに近い）内の a26 の合計 ÷ その面積。順位の式には入れず、地図に濃さや補助列で出す（「周囲もスギ林で占められる所」の確認用）。式に入れるなら S_i × C_i（指数1、仮置き）を感度確認として別列にする。
- 実行しやすさ（傾斜）は点数に混ぜず、別の軸（表示や絞り込み）にする。効果の軸（S_i）と実行の軸が混ざると「どちらで高いのか」が読めなくなる（推測。設計上の助言）。傾斜の閾値は既存の仮置き（25度）のまま、根拠なしと明記。

### 2-4 使うべきでない（根拠がない、または反対の証拠がある）
| 項目 | 理由 |
|---|---|
| 林齢を連続的に重みにする（例: 年齢が高いほど高得点） | 26年生以上で頭打ち、標準伐期齢以降も減らない [N2][N3][N1]。区分1の97%が26年生以上で差も付かない（README） |
| 県別の雄花花芽調査値を500mメッシュの重みにする | 県の平均値で年変動が大きい（2倍・100倍の例）。READMEの照合でも26年生以上面積とρ=-0.39。地点値は未入手 |
| 有病率・受療率をスギ林面積と結び付けて重みにする | 結び付ける根拠が見つからず、受療率はスギ林占有率と負の相関という要約がある（△）。有病率は飛散期間・湿度・都市要因にも左右される |
| 飛散距離の具体的な数値（夜50〜60km・昼500km以上など） | 個人コラム・業者サイトのみ（前報告 2-10）。「数十km」以外に査読・公的な数値が無い |
| 標高・斜面の向きによる雄花量の補正 | 該当する論文が見つからなかった（前報告 2-9、本報告の検索でも見つからず） |
| 間伐や林分の密度を優先度に入れる | 強度の間伐で雄花が増える例がある [R5][N3]。関東は林分密度のデータも無い |
| 「花粉がX%減る」などの効果の数値 | 前報告の禁止表現。国民森林会議が単年比較・根拠不明の数値を批判 [C1] |
| スギだけで花粉量とする | 実測はスギ・ヒノキ亜科の合計で、ヒノキの寄与が予測と観測のずれの一因と推察される [R6]。ヒノキを入れないことを画面に明記する（READMEの限界記述と同じ） |
| NDVIなど衛星指標で林齢・樹種を代用 | 前報告 §1-5 の判断のとおり、分離の公開論文なし |
