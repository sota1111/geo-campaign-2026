#### 1-4 H5 への答え（確定部分）
- 国土数値情報由来の7項目（XKT004・006・010・011・013・026・029。XKT007 は加工データ）は、徳島市分について、商用利用・公開（複製・公衆送信）を禁じる記載は見つからなかった。条件は、出典表記・加工した旨の記載・国作成と誤認させないこと。アプリへの同梱・公開と、有償提供は、規約上は成り立つ見込み。
- 訂正（重要）: アグレッサー依頼文・README は XKT003 を「国土数値情報由来」と扱っているが、XKT003 は国土数値情報ではなく「都市計画決定GISデータ」。利用ルールが別で、商用・再配布の条項が見当たらない。9項目のうち、規約が最も不明確なのは XKT003。
- 出典表記の確定事項: API利用規約の第7条のクレジット、サイト規約の「出典：国土交通省　不動産情報ライブラリ」、国土数値情報の「出典：国土交通省国土数値情報ダウンロードサイト（当該ページのURL）」と加工の旨、の3つが要る。README は第7条のクレジットと加工の旨を実装済みと書いている。国土数値情報の出典文（ダウンロードサイト名・URL）が画面にあるかは、情報部は確認していない（要確認 C-6）。

#### 2-1 ライブラリの地図機能（出典: https://www.reinfolib.mlit.go.jp/map/manual/ ）
確定できること:
- 「重ね表示: 土地・不動産関連情報を地図上に一度に重ね合わせて閲覧できます」（マニュアルの記載）。コンテンツをカテゴリごとに選び、決定ボタンで反映する。
- 条件設定タブで、条件に合うものだけを表示でき、「塗りつぶしあり」でポリゴンに色が付く。
- 地図上のコンテンツをクリックすると、名称と代表的な属性がポップアップで出る。
- 地域検索は、住所（都道府県・市区町村）または路線・駅名。縮尺は8段階。国土地理院地図に切り替え可。凡例タブあり。
- 掲載テーマ（国交省2024年の公表資料）: 周辺施設（学校・小中学校区・医療機関・福祉施設）、防災（洪水浸水想定区域・土砂災害警戒区域・津波浸水想定・高潮浸水想定区域など）、都市計画（用途地域・立地適正化区域など）、価格。公式例に、地価・洪水浸水想定区域・周辺施設を重ねる使い方がある。出典: https://www.mlit.go.jp/report/press/content/001753284.pdf ほか（検索結果の要約。PDF原文は未照合）。
- 地図と API では、原典・整備時期が違う。ライブラリの「コンテンツの出典」ページは、津波・高潮・洪水・土砂について「地図表示とは原典データおよび整備時期が異なります」と明記している（API は国土数値情報、地図はハザードマップポータルサイト）。つまり RN1 が API で取った災害データは、ライブラリの地図に出るものと同一ではない。

マニュアルページに記載がなく、確認できなかったこと: 重ねられるレイヤ数の上限、印刷・画像保存、透過度。H1 の「複数を同時に重ねられるか」への答えは「重ねられる（記載あり）。上限は不明」。
- 「重ねていない」（service.md の差の説明）は、公式の記載に反する。公式が「重ね合わせ」を機能として説明している。差の言い方を変える必要がある（根拠は、アグレッサー H1 の見立てと一致）。
- 残る差として言えるのは、事実としては次の点。マニュアルに「住所を指定して1枚にまとめる」「各行に聞くことを添える」「印刷用シート」の記載はない（記載がないことの確認であり、「ない」の証明ではない）。

## 第3部 registry更新提案・RN1資料の更新提案（registry.json は変更していない）
registry.json に直接関わる差分は見つからなかった（今回の調査は不動産部門の締切・字数・審査基準に触れていない）。以下は RN1 の README・提出文への提案（変更するのは工兵・総司令官）。

1. README「規約」の記述の訂正: 「国土数値情報由来の8項目」から XKT003 を外す（XKT003 は都市計画決定GISデータで規約が別。XKT007 は加工データ）。
2. service.md の差の説明「ライブラリの地図でも個別の情報は見られるが、複数を重ねて…」は、公式マニュアルが「重ね合わせ」を機能として記載しているので、そのままでは事実に反する。差は「地図の上で重ねる」ではなく、別の点で書く（何を言うかは作戦研究班・総司令官）。
3. README 未解決4の更新: 国土数値情報由来分は、徳島市分について規約上の障害が見つからなかった（第1部1-3）。残る論点は XKT003（C-2）と、API規約の再配布の解釈（C-1）。
4. README の限界欄に追記: 津波・高潮・液状化は API にあり（XKT028・027・025）、徳島県は原典にある。津波・高潮の浸水深は区分名で返る（コード定義の問題がない）。
5. README「取得したデータ」に、API（国土数値情報）と、ライブラリの地図表示は原典・整備時期が異なることを注記（ライブラリ自身が明記）。
6. 画面・シートの出典に、国土数値情報の「出典：…ダウンロードサイト（URL）」と、原典の注意書き（C-6・第1部1-4）を入れるかを憲兵が確認。
7. 提出文（title）の「分かる」: 原典が「公式な資料としては扱えない」（小学校区）、「実際の津波は想定より大きい場合がある」と書く以上、断定に近い語は避ける。これは推測（事実ではなく、減点リスクの見立て）。
