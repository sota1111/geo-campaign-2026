# odpt-2026 子連れお出かけ診断: 国土数値情報 P13・P27 の「非商用」の意味と利用可否（追補）

## 0. 結論（先に）

**判定: 「問い合わせが必要」。回答が出るまでは「使えない」扱い（公開物に P13・P27 由来の点データを入れない）。**

根拠は3点。

1. P13・P27 は、どちらも版が1つだけ（P13=2011年度版、P27=2013年度版）で、どちらも使用許諾条件は「非商用」。年度ごとの違いは無い。【確定】
2. 旧規約第1条は「非商用」を「非商用目的のみでの利用（ただし**複製物の再配布を除く**）」と定義する。公開Webアプリが357件の座標・名称を JSON として配る形は、「複製物の再配布」にあたる可能性が高い（推測。規約に「Webアプリ」「コンテスト」の記載は無い）。【確定: 定義文／推測: 当てはめ】
3. 同第3条は、GIS形式やExcel形式などの**データベースとして**使う場合は「データベースの著作権の侵害のおそれがあるため事務局に問い合わせ」と求める。例外として認められるのは「GISで空間演算した結果（データベースでないもの）」を出典と加工者名つきで使う場合だけ。【確定】

「賞金のあるコンペへの応募」そのものが商用にあたるかは、規約にも FAQ にも定義・記載が無く、確定できない。ただし、上の2・3で、応募の是非とは別に公開アプリへの組み込みが引っかかる可能性が高い。コンペ応募だけなら安全、とは言えない。

## 1. 確定事項

### 1-1. P13・P27 の個別の許諾条件（年度・版ごと）

| データ | 掲載されている版 | 使用許諾条件の表示 | 許諾条件ページへのリンク | 出典 |
|---|---|---|---|---|
| P13 都市公園 | 2011年度（平成23年度）版のみ | 「非商用」 | 「このデータの使用許諾条件」→ `/ksj/other/agreement_02.html` | [K1] |
| P27 文化施設 | 2013年度（平成25年度）版のみ | 「非商用」 | 同上 | [K2] |

- 年度ごとに条件が変わる余地は無い（版が1つだけのため）。
- P13 の原典: 「国土交通省都市局が全国の都道府県・市区町村から情報を収集して作成した都市公園リスト」。位置を特定できなかった約1割は除外。ページに再配布条件の個別記載は無い。【確定】[K1]
- 両ページとも、個別の追加条件（第三者権利の注記など）は確認できなかった。

### 1-2. 旧規約の該当箇所
名称: 国土数値情報ダウンロードサービスコンテンツ利用規約（旧国土情報利用約款準拠版）。制定 令和2年4月1日、改正 令和2年7月1日。【確定】[K3]

| 条 | 内容（引用は短く） |
|---|---|
| 第1条 | 「商用可」=「出典・加工者等表示のうえ、原著作者等の許諾上、商用目的での利用（複製物の再配布を含む）が可能なもの」。「非商用」=「出典・加工者等表示のうえ、原著作者等の許諾上、非商用目的のみでの利用（ただし複製物の再配布を除く）が可能なもの」 |
| 第1条 | 行政機関等が公的目的で使う場合に範囲が不明確なときは、事務局に問い合わせる |
| 第2条 | 位置の誤差は概ね数100m、時間的ずれは1〜5年程度。適用限界を理解し伝達する。ナビゲーション・公共測量・各種証明への利用は想定外 |
| 第3条 | 出典を記載する。加工したらその旨を別に記載する。「非商用」でも「GISによって空間演算した結果（データベースでないもの）等」は、出典と加工者名の明示で利用可。「GIS形式やエクセル形式等のデータベース」の場合はデータベースの著作権侵害のおそれがあるため事務局に問い合わせ |
| 第4条 | 無償。違法・権利侵害・公序良俗違反は禁止。利用目的・方法は利用者の判断と責任 |
| 第5・6条 | 予告なく公開停止・変更・削除がある。損害は利用者負担。準拠法は日本法、管轄は東京地裁 |

- 第三者提供・承認申請に関する明示条項は見当たらない。
- 注意: 第1条・第3条の引用は WebFetch（要約モデル）経由の短い引用。逐語の完全一致は未検証。原文ページ [K3] を人の目で確認することを推奨。【要確認（引用の精度）】

### 1-3. 新規約との関係
- 新規約（2026年3月23日施行）は、「商用可」「非商用」のデータと、許諾条件の記載がないデータは、上の旧規約に従うと定める。ページ内に「非商用」「商用」の定義は無い。【確定】[K4]
- 出典の記載: 「出典：国土交通省国土数値情報ダウンロードサイト（当該ページのURL）」の形。【確定】[K4]

### 1-4. 「非商用」の運用解釈（国交省の FAQ）
FAQ に載っている範囲（短い引用）。【確定】[K5]
- Q6「非商用」で認められる利用の代表例: 「著作権法が定める範囲での利用」「行政目的での利用」「学術目的での利用（学術論文への引用等を含む）」「民間企業内部における検討での利用」。禁止の一覧は無い。
- Q7: 行政機関からの有償受託の検討業務は、行政機関内の検討にあたるため利用可。
- Q8: 「不特定の行政機関への販売を予定した製品への使用は商用利用となる」ため使えない。
- Q1・Q3: 販売する書籍への掲載、ソフトウェアへの同梱販売は不可。
- コンテスト・ハッカソン・無償公開Webアプリについての記載は、規約にも FAQ にも**無い**。
- 読み取れること（推測）: 想定されている許容は「内部検討・学術・行政・著作権法の範囲」。外部の利用者にデータを配る公開アプリは、Q6の例に含まれない。

### 1-5. 「コンペ応募・無償公開Webアプリ」が該当するか
| 論点 | 判定 | 根拠 |
|---|---|---|
| 賞金つきコンペへの応募は「商用」か | **不明（規約に定義無し）** | [K3][K4][K5] に記載なし。営利目的か否かの線引きは書かれていない |
| 無償公開は「非商用」の範囲に入るか | **不明。ただし再配布の除外に当たる可能性が高い（推測）** | 「複製物の再配布を除く」。アプリが同梱する JSON は357件の座標と名称の複製物 |
| 点データを JSON で公開するのは「データベース形式」か | **該当する可能性が高い（推測）** | 第3条で、データベース形式は事務局への問い合わせが必要とされる |
| 診断結果だけ（点データを持たない）の表示 | 第3条の「空間演算した結果」に近い。ただし範囲は事務局が決める | 第3条。判断が割れるため、文書で確認するまで安全とは言えない |

## 3. 代わりに使える商用可データの候補（東京都区部。大阪は下に別記）

### 3-1. 公園: 東京都都市整備局「緑のオープンデータ」（有力候補）
- 公開: 2026-02-02。カタログ `https://catalog.data.metro.tokyo.lg.jp/dataset/t000008d2000000024`。【確定: 公開と所在】[T1]
- 内容: ファイル一覧（令和8年2月2日時点）の確認結果。【確定】[T2]
  - 都立公園、区市町村立公園（都市公園）、国営公園、海上公園、植物園・動物園・水族館等、庭園など。いずれも**区域（ポリゴン）**で、点データは庭園のみ。
  - GISの時点は令和6年4月1日（P13の2010年3月より約14年新しい）。
  - 原典は公園調書（東京都建設局、令和6年4月1日時点）等。留意事項に「公園調書に掲載されている公園についてデータを作成」。
  - 「植物園・動物園・水族館等」の区域もあるので、P27 の動植物園・水族館の一部の代わりになる可能性がある（推測）。
- 座標: ポリゴンのみ。点にするには重心を計算する必要がある（工兵作業）。
- 範囲: 「本土部」（島しょを除く）と告知にある。【確定】[T3]
- **ライセンス**: 検索結果の要約は「CC BY 4.0」と記すが、公式ページではまだ確認できていない。定義書には「無断転載、複製を禁ず」との記載もあるとする要約があり、CC BY 4.0 と食い違う可能性がある。**併記して要確認（V4）**。確認前に採用しない。
- 属性（面積・種別）の列構成は定義書（令和8年2月3日版）にあるが、PDFから取れていない。
