## 結論（先に）
1. 「①市の立地適正化計画の区域か」は、東京・大阪では**そのままでは成り立たない見込みが高いが、「23区・大阪市に1つも無い」とは確認できていない**。国交省の市区町村別一覧（作成状況）は、PDF が読み取れず入手できなかった。確認できたのは、大田区が策定中（公表前）であること、調布市・三鷹市・堺市が策定済みと市の資料に書かれていること、の3点のみ。
2. XKT003 の公式仕様に「対象地域」の記載はない。区域データが返るかどうかは、各自治体が GIS データを公表しているかに左右される（都市局ページに「公表していない自治体がある」旨の記載）。一覧（xlsx）は読めていない。
3. 代替候補は XKT002（用途地域）・XKT001（都市計画区域／区域区分）・XKT014（防火・準防火地域）。いずれも zoom 11〜15、仕様ページに提供地域の注記なし。ただし「誘導する区域」ではなく「規制する区域」なので、①と意味が違う（意味づけは作戦研究班・総司令官の判断）。
4. 要項に、対象地域の制限・地方への加点・大都市の不利を示す記述は**見つからなかった**（募集要項 PDF の P.1〜P.8 を目視。P.9 以降は未読）。

### 2. XKT003 が東京・大阪の市で区域データを返すか（問い2）
- XKT003 は「都市計画決定GISデータ（立地適正化計画）API」。zoom 11（市）〜15（詳細）。仕様ページに**提供地域の記載なし**。出力は GeoJSON か pbf。項目は prefecture、city_code、city_name、decision_date、kubun_id、kubun_name_ja、area_classification_ja など。データなし時の挙動は記載なし。原典は都市計画決定GISデータ（令和7年度）。出典: https://www.reinfolib.mlit.go.jp/help/apiManual/xkt003/
- 原典側の説明（国交省都市局）: 全国の都市計画決定情報の GIS データ。**「一部の自治体は GIS データを公開していないため、一部の決定が含まれない」旨の記載**（要約ツール経由）。収録自治体は「公表自治体及び掲載データ一覧.xlsx」（令和8年10月26日時点）に載る。出典: https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000087.html 、一覧 https://www.mlit.go.jp/toshi/tosiko/content/001864274.xlsx
- この xlsx は取得したがバイナリで中身を読めなかった。**東京・大阪の各市区が収録されているかは未確認**（要確認 T-2）。
- 確実に言えること: 計画が無い市区（例: 大田区は令和9年3月まで公表前）には、区域データは存在しないはず。この点は推測ではなく、計画が無ければデータの元が無いという論理。ただし「無い」市区の特定は 1-2〜1-4 のとおり未了。

1. 審査基準: brief は「独創性／社会的効果／実現可能性／事業性」の4つ。募集要項は「独創性／社会的インパクト／実現可能性（特にビジネス部門）／持続性（継続可能な仕組み・収益性）（特にビジネス部門）／プレゼンテーション力」の5つで、「例えば…重視されることが考えられます」という書き方。**実現可能性と持続性が「特にビジネス部門」**である点が、不動産部門の戦略に効く。brief の表記を要項に合わせる提案。
2. 提出物の表: 不動産部門の独自項目「アイデアで活用する不動産情報ライブラリの情報」が brief にない。追加を提案（RN1 の submission にこの項目の文面があるかは未確認）。
3. business.md の「要確認」: 要項では、ビジネス部門独自は「市場・顧客ニーズ（400字以内）」「事業化・成長に向けた課題（400字以内）」。上限が確定した。
4. 補足資料の上限: 「10ページ以内／10MB以下／書式自由」（brief は10ページのみ）。10MB を追記。
5. 日程の補足: 不動産・アイデア部門の一次審査結果は 12/24（予定）。brief にない。
6. 応募フォーム: 要項の URL は https://g-idea.go.jp/2026/entry 。フォームの開設は 2026-10-01 予定（brief の URL は /application/）。

### RN1 の README・提出文への提案（変更するのは工兵・総司令官）
1. 東京・大阪へ移す場合、①の節は「計画がある市区だけで表示し、無ければ『計画の公表なし』と出す」か、別の指標へ置き換えるかの設計判断が要る。どちらでも T-1・T-2 の確認が先。
2. 代替は XKT002（用途地域）等。ただし意味が違う（第1部 3）。置き換える場合、提出文（problem・service）の「立地適正化」に関する主張も書き換えが要る。
3. 東京は津波（T-4）、大阪は福祉施設の非商用（T-6）が空欄・制約になりうる。
4. 対象を広げるほど「空」の市区が出る。「データが無いこと」を「安全」と読ませない表示が要る（前報告の注意書きの方針と同じ。これは推測ではなく設計上の注意）。
5. 要項に大都市を不利にする記述は見つからなかったので、対象を東京・大阪にしても、要項上の障害は見つかっていない。
