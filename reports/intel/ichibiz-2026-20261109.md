# イチBizアワード2026 情報部レポート（取得日 2026-11-09）

注: 任務指示の報告先は ichibiz-2026.md だが、交戦規定の形式に従い ichibiz-2026-20261109.md とした。

## 結論
- 字数は公式PDFとWebで一致し、確定。brief.md の title50/problem400/service700/background300 は正しい。
- brief.md はビジネス部門の business.md を「要確認」としていたが、実際は2項目に分かれる。市場・顧客ニーズ400字、事業化・成長に向けた課題400字。
- 応募資格は個人・グループ・法人を問わない。実績要件の記載はない。ビジネス部門にも個人が出せる。2025年は個人がビジネス部門の優秀賞を受賞した。
- 賞金は総額200万円（予定）。受賞数と個別額は未定で、最優秀賞の額も公表されていない。期待値の定量計算は根拠がなく、できない。
- 複数アイデアの応募は可。同一アイデアの複数部門同時応募は公式に明記なし（要確認）。
- 締切は 11/30（ビジネス）と 12/10（アイデア・不動産）。送信は総司令官が行う。

## 確定事項（出典一致）
### 1. 入力項目・字数・提出方法
- 全部門共通
  - 応募者情報
  - タイトル50字
  - 解決したい課題・対象400字
  - アイデア・サービス内容700字
  - 背景・きっかけ300字
  - 補足資料は任意。PDFまたはPPT、書式自由、10ページ以内、10MB以下。
- ビジネス部門のみ: 市場・顧客ニーズ400字、事業化・成長に向けた課題400字。
- アイデア部門: 独自項目なし。
- 不動産情報活用部門のみ: 「アイデアで活用する不動産情報ライブラリの情報」。字数は記載なし（未確認）。
- 提出は公式サイトの応募フォーム https://g-idea.go.jp/2026/entry/ から行う。
- ビジネス部門のPPTフォーマット（アイデア整理シート）は任意。
- 出典: 募集要項PDF p.4 / https://g-idea.go.jp/2026/application/（2026-11-09取得）。

### 2. 賞・賞金
- 受賞アイデアを対象に賞金総額200万円（予定）。受賞数と個々の額は未定。
- 協賛企業の審査により、協賛企業から独自の副賞が出る場合がある。
- 賞金・副賞は「アイデアに対して」授与される。個人でもグループでも同内容（FAQ）。
- 部門ごとの賞金配分は記載なし。賞金がない部門があるとも書かれていない。
- 表彰式は 2027/3/19 G空間EXPO（東京ビッグサイト）、原則対面。
- 出典: PDF p.6 第7・8章 / https://g-idea.go.jp/2026/faq/

### 3. 応募資格
- 個人・グループ・法人を問わず、個別連絡先がある者。国籍・居住地は不問。応募と審査は日本語。年齢制限なし。
- 法人要件・実績要件は、PDFとWebのどちらにも記載なし。
- 出典: PDF p.3

### 4. 複数応募・重複応募
- 同一人物から複数アイデアの応募が可能。応募フォームでは個別に登録する（PDF p.3、FAQ）。
- 他コンテスト・学校の規則との重複: 本アワードとしては構わない。他コンテスト側の規則は応募者が確認すること（FAQ）。
- 出典: https://g-idea.go.jp/2026/faq/

### 5. 不動産情報活用部門のデータ
- 国土交通省「不動産情報ライブラリ」https://www.reinfolib.mlit.go.jp/ のオープンデータ（取引価格、都市計画、防災情報など）を活用する。国土交通省連携企画。
- 「活用必須」を明示する文言は見当たらない。ただし独自項目で活用する情報の記載を求めているため、実質的に必須と読むのが安全（推測）。
- 出典: PDF p.3-4

### 6. 審査
- 審査方法
  - 審査は提案内容のみが対象。
  - 一次は事務局の書類選考。二次は事務局によるビデオ選考。最終は有識者へのオンラインプレゼン。
- 審査員が重視しうる点（例示）
  - 独創性
  - 社会的インパクト
  - 実現可能性（特にビジネス部門）
  - 持続性（継続可能な仕組み・収益性。特にビジネス部門）
  - プレゼンテーション力
- 協賛企業は協賛企業賞の審査を別に行う。
- スケジュール（予定）
  - ビジネス部門: 一次結果12/14、プレゼンセミナー、二次1月下旬、最終2月中旬。
  - アイデア・不動産部門: 一次結果12/24、プレゼンセミナー。アイデア・不動産部門の二次・最終の有無は図から読み取れず、未確認。
- 一次通過者向けに任意のブラッシュアップ支援がある。ビジネス部門は専門家の個別面談。
- 出典: PDF p.5

### 応募上の注意（PDF p.7-8、失格・取消に関わる）
- 第三者の知財の盗用・侵害は禁止。所属機関の知財に関わる場合は事前承諾が必要。
- 生成AIは補助利用なら可。出力をそのまま用いたもの、応募者の独自性が認められないものは応募を控える。
- 応募内容は協賛企業・外部審査員に提供される。完全に秘匿したいアイデアは応募を控える。
- 通過後の条件
  - 二次・最終のプレゼンへの参加
  - 表彰式への現地参加
  - 名前（ニックネーム可）・都道府県・タイトルの公表への同意
  - 未成年は保護者の同意
  - 結果の事前非開示
  - 落選理由を問い合わせないこと
- 起業状況などの現況調査に、応募時・終了時・その後数年程度まで協力すること。
- 協力団体・協賛企業へ、直接または事務局経由で交渉してはならない。
- 安全保障貿易管理と反社会的勢力排除の確認事項がある。
- 手続きが必要なテーマ（倫理委員会承認など）は事前に事務局へ相談する。

## 要確認事項
1. 賞金の部門別・賞別配分。公式PDFは「個々の額は未定」。2025年実績の額も取得できなかった。期待値計算の前提が欠けている。事務局への問い合わせ（総司令官判断。情報部は送信しない）か、2025年の募集要項・結果ページ・Q&A（https://g-idea.go.jp/2025/ 配下）の追加調査が必要。
2. 同一アイデアを複数部門に同時応募できるか。公式に明記なし。FAQにも記載なし（FAQの「複数応募」は同一人物の複数アイデアの意味と読める）。
3. 不動産部門の「活用する不動産情報ライブラリの情報」欄の字数・形式。応募フォーム（https://g-idea.go.jp/2026/entry/）は未取得。
4. アイデア・不動産部門の二次審査・最終審査の有無とスケジュール。
5. 2025年度の公式募集要項の審査基準。2024年度以前の公式要項との比較は未了。
6. 受賞者の法人・個人の別は名称からの判断で、公式の区分ではない。
7. 表彰式の現地参加は、受賞の前提条件として記載されている。事務局に免除規定があるかは未確認。
8. WebFetchの要約は、モデルによる抽出である。上記の字数・資格・賞金はPDF原本（画像で目視）と一致を確認した。FAQ・2025受賞者一覧はWeb要約のみ。
