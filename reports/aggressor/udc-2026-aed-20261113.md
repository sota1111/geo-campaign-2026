## 弱点（重大度順）

### 重大

**S1. 「平日午前3時に使えるAED 14台」の中身は2か所。13台は町田市民病院（同じ座標）で、そこに「救急車内」が入っている**
- data/aed.json の町田市の24時間AED 14台は、町田市民病院が13台（座標 35.55718, 139.4384 がすべて同じ）、薬師池公園警備室が1台。病院の13台には「救急車内」「南棟10階病棟内廊下（105号室前）」「東棟1階口腔外科外来」が含まれる。
- 提出文（実測表）、IN1 problem.md（「288台のうち、平日午前3時に使えるのは14台」）、README のどれも「14台」とだけ書いている。町田市の職員や消防が読めば、最初に「救急車の中のAEDを、夜に住民が取りに行けるAEDに数えたのか」と指摘されるだろう。数字の信用がそこで崩れる。
- 圏外の人口（97.9%）にはほとんど影響しない（2か所 × 半径500m）。この問題は表現と、データを鵜呑みにしている点にある。
- 直し方の例: 「14台（2か所。うち13台は市民病院の院内・救急車内）」と書く。設置位置に「車内」「病棟」などがあるものは一般利用不可の候補として印を付け、数から外すか分けて数える。逆に、「夜に確実に使えるのは市内で実質2か所」は、正しく書けば強い主張になる。
- 失敗テスト: `test_aggressor_aed_data.py::TestMachida24h::test_ambulance_is_not_a_public_24h_aed`、`TestEntry3Claims::test_14_units_row_says_two_sites`。事実を記録するテスト `test_fact_fourteen_24h_aeds_are_two_sites` は緑。

**S2. 自由記述パーサーが「開館日」の「日」を日曜、「4月～9月」の「月」を月曜と読む。福岡市で約48台が誤読され、しかも「読めた」に数えられている**
- tools/aed_time.py の `_days_in_segment` は、範囲の直前にある「月」「日」の1文字を曜日として拾う。福岡市の元CSVを同じ関数で解析したところ、時間指定と判定された544台のうち、結果が「日曜だけ」21台、「月曜だけ」22台、「月日」3台、「土日」2台、計48台で、ほぼ全部が誤読だった。658台（読めた数）の約7%にあたる。代表例:
  - 「開館日の9時～21時まで使用可能」→ 日曜 9-21時だけ（早良市民センター、市民福祉プラザ等）
  - 「4月～9月は9時～19時、10月～3月は9時～17時」→ 月曜 9-19時だけ（博多の森陸上競技場、小戸公園、霊園3か所等）
  - 「12月29日～1月3日を除く9時～17時」→ 月曜だけ
  - 「休館日以外の9時～18時 ※休館日：毎週月曜日」→ 日曜だけ（正しくは火～日）
  - 「休園日以外の9時～17時 ※休館日：毎週土、日、祝日」→ 日曜だけ（**意味が逆**）
  - 「年末年始の休日を除く 午前9時～午後10時」→ 土日だけ
- このほかに見つけた誤り:
  - 「毎日 午後1時～5時」→ 13時～翌5時の夜またぎになり、**深夜3時に使えると判定される**。「午後」が後ろの時刻に掛からないため。`_find_ranges` には対処しようとした `pass` が残っている。
  - 曜日欄「土日休」→ 土日だけ使える（逆）。「月曜休館 9時～17時」→ 月曜だけ（逆）。
  - 「24時間使用可能（土日除く）」→ 毎日24時間。「平日 終日 土曜日 終日」→ 日曜も24時間。
  - 「①12月29日～…、②・③24時間、④…」（大濠公園4台）→ NFKC で ① が 1 になって「112月29日」とつながり、4台とも月曜だけになる。
- 「解釈できない値は不明として推測で埋めない」という README の方針と、実装の挙動が食い違っている。技術者の審査員なら必ず何件か抜き取って確認する。抜き取った中に「開館日→日曜」が1件でもあれば、完成度は大きく下がる。
- 失敗テスト: `test_aggressor_aed_time.py` の15件（すべて @known_bug。実データの記載またはその最小形）。

### 中

**M1. 「平日」は実際には月曜で計算している**
- プリセット「平日 午前3時／14時／20時」はどれも d=0（月曜）。月曜は祝日（ハッピーマンデー）と月曜休館が多く、平日の中で最も条件が悪い日になる。平日14時の圏外は、月曜20.4%、火曜19.9%、水曜19.8%。差は小さいが、「平日」と書く根拠が示されていない。
- 失敗テスト: `TestEntry3Claims::test_weekday_means_monday_is_stated`

**M2. 「不明も使える（最大見積）」は深夜も「施設の開館時間」のAEDを使える扱いにしており、幅が広すぎて結論にならない**
- 福岡市の平日3時の圏外は、確認できたAEDのみで72.0%、最大見積で12.8%。「施設の開館時間」「学校使用時のみ」と書かれたAEDが午前3時に使える根拠はない。見出しに「12.8%～72.0%」と並べても、審査員は「結局どちらなのか」と問うだろう。

- 失敗テスト: `lib_attack.test.cjs`「最大見積でも、午前3時に施設の開館時間のAEDを使える扱いにしない」（todo）

- 失敗テスト: `test_locked_at_night_is_not_plain_24h`、`test_shujitsu_with_listed_days_excludes_sunday`

**M4. 4市はデータの母集団が違い、市どうしを比べられない。民間の24時間AEDが無い影響は、町田市が最も大きい**
- 福岡市のデータは「福岡市AED設置施設登録制度」によるもので、ホテル（東横イン、ANAクラウンプラザ等）や商業施設など民間を多く含む。町田市は市の施設だけで、外部利用不可の列も全行空欄。福岡の3時の圏外72%と町田の97.9%を並べると、「町田は夜の空白が大きい」という誤った比較になる。
- 町田市にコンビニ等の24時間AEDの協定や設置があるかは、今回確認できていない（要確認。文京区・新宿区の例は提出文にある）。もし町田市が協定でコンビニに置いているなら、97.9%は「市が自分で公開していないデータ」の空白を示しているにすぎない。その場合、町田市の職員は「うちのコンビニAEDを見ていない」と反論するだろう。

**M5. 作品①（GTFS診断マップ）と同じ型。③には差別化の節がなく、①の差別化の節は②としか比べていない**

**M7. Geoshape（CC BY-SA 4.0）。UDC の作品は原則公開**
- README 自身が「総司令官の確認が必要」と書いている。公開すれば data/boundaries.geojson（単純化した境界）は派生物として SA の対象になる可能性が高い。aed.json のメッシュの選別も対象になるかは判断がつかない。12/27 の公開前に、国土数値情報 N03 の原データに切り替えるか、SA で公開するかを決める必要がある。概要登録のデータ欄の書き方にも関わる（冒頭の2）。

**M8. 倉敷市は時間帯で差が出ず、作品の主張を示せない**
- 倉敷市は24時間が114台、残り159台は不明（156台が未記入）、時間指定は0台。何時に設定しても圏外は同じ（確認できたAEDのみで56.9%、最大見積で43.5%）。「時間帯で変わる」という作品の中心の主張を、4市のうち1市では示せない。逆に、学校の屋外収納ボックスに置いて24時間使えるようにしている例として紹介すれば、強みにできる（設置位置に「外壁の収納ボックス」と書かれている）。

**M9. 半径の根拠と判定の粒度**
- 既定の半径は直線500m。道のりは直線より長くなり、往復もある。250mメッシュの中心で判定しているので、メッシュの角では最大約177mずれる。300mの設定では、この誤差が半径の半分以上になる。
- 医療系の審査員からは「心停止から何分以内」の基準（日本救急医療財団「AEDの適正配置に関するガイドライン」等）と既定値の関係を問われるだろう。提出文には根拠が書かれていない。ガイドラインの記述は今回確認していないので、情報部に確認を頼むこと。

### 軽微

- **L1. 壊れた共有URLでアプリ全体が止まる。** `#m=%E0` のように壊れたURLを開くと、`parseHash` の decodeURIComponent が URIError を投げる。app.js の catch に入り、「データを読み込めませんでした。python3 -m http.server で配信して…」と、原因と違うメッセージが出る。SNSでURLが途中で切れた場合に起こりうる。失敗テスト: `lib_attack.test.cjs`（todo）。
- **L2. 分が60以上でも受け付ける。** 「17:75」は 18:15 として扱われる。失敗テスト: `test_minute_over_59_is_rejected`。
- **L3. 人口の注記の向きが逆。** README と提出文は「人口は夜間にその場にいる人数ではない」と書いているが、国勢調査は常住人口なので、深夜の在宅人口には近い。ずれが大きいのは14時（昼間人口）の方。今の書き方は、深夜3時という一番強い数字の信頼を自分で下げている。
- **L4. データの版の日付。** 福岡市のCSVのファイル名は aed_202512040821.csv で、2025年12月の版と思われる。README の「取得 2026-11-13」と並べて、版の日付も書く。
- **L5. 空データの区別がない。** coverage() はメッシュ0件でも popOut=0 を返す。見出しは「約0人（0%）」になり、「データなし」と区別できない（失敗テスト todo）。いまの4市では起きない。
