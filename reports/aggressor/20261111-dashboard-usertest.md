## 改修の要点
- 第1回後: 試験の答えを含む例ボタン（「富山市大町で試す」）を削除。最終便を主従に整理、徒歩の根拠（最寄り病院と徒歩の目安）、昔の写真を独立した段階に、住所検索、判定ロジックの修正（下限値が相手の確定値を上回る場合は「確定」）、保存不具合（Radix Select がクリックを奪う）を標準 select で回避、ポータルに対象者を表示、7枚を1画面に。
- 第2回後: 「目的の達成状況チェックリスト」と「次にやること」を3アプリに導入（結論を見て止まる被験者が最後の操作まで進むように）。段階表示のバグ、行頭「。」の崩れ（grid 構造が原因）を修正。
- 総司令官の指示で、各アプリを独立ページ（apps/<id>/）に分離し、統合ダッシュボードはポータルに。各アプリに「← 統合ダッシュボード」。

## 第3回で残った指摘（未対応・小）
- 生活アクセス: 「大町」だけの検索で他市の同名地が先に選ばれる（選択中の地域を優先すべき）
- 盛土巡視台帳: 結果のセレクトを閉じた直後の1回目の「記録する」が反応しない（第1回の地名の記憶マップと同じ Radix Select の現象）。結果の初期値が「是正対象」
- 地名の記憶マップ: 「サンプルの語りを写す」が効いていないように見えた、確認済み後も案内文が「未確認」のまま
- 路面下リスク・1枚シート: 長い画面で次のボタンが見つけにくい、地図上のホイールで地図が拡大されページがスクロールしない
- 盛土ウォッチ: 一覧へ自動スクロール直後のずれで誤選択
- 共有リンクは手元のアドレス（127.0.0.1）。公開後の URL で解消する

## 追加改修と第4回試験（手順サイドバー）
- 第3回の残り指摘をすべて修正。共通部品では、地図上のホイールでページがスクロールするようにした（Ctrl/⌘＋ホイールで拡大）。Select を閉じた直後の1回目のクリックが届かない不具合も直した（原因: 閉じるアニメーション中に body の pointer-events:none が残る）。
- 総司令官の指示で、各アプリに左の手順サイドバーを追加した（スマホは上部ステッパー）。上から順に進めると目標の成果を達成できる手順を登録し、各手順に済／いまここ／未着手の状態を表示する。
- 第4回試験（Sonnet 7名、使用目的のみ伝達、各アプリの独立ページから開始）: **全アプリで目標の成果をすべて達成**。路線比較の書き出しは、今回も文章コピーで行われた。
- 第4回で見つかったサイドバーの不整合を修正した。衛星A・路線比較では、目標は達成したのに済にならない手順があった。地名の記憶マップは手順2の移動位置、1枚シートは位置確定後の自動スクロールに問題があった。進捗の表記は「必須 5 のうち 3 完了（任意 1）」に直した。路線比較には、65歳以上で結果が逆転する場合の注意表示を追加した。各工兵が、サイドバーを上から順に押して全手順が済になることをヘッドレスChromeで確認した。この修正後の初見ユーザー試験は行っていない。
