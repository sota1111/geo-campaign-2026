## 結論
1. **PR #19 はマージしない。**
2. **国土数値情報 P13・P27 の扱いは「使えない」とする。** 事務局から文書で「可」の回答を得るまで、この扱いを続ける。P13・P27 から作った点データ（名称・座標・種別）は、どの公開物にも入れない。公開物とは、既定ブランチ、GitHub Pages・デモ URL・Artifact・Notion、応募の資料とスクリーンショットのこと。情報部の結論をそのまま採る。
3. **公開ブランチ上のデータは減らす。** これは #18 とは扱いを変える点で、理由は下に書く。工兵が新しいコミットで、P13・P27 から作ったデータをブランチの先頭から外す。強制 push はしないので、履歴には残る。
4. **事務局への問い合わせは総司令官が送る。** 補佐・部隊は送らない。文案は下に付けた。
5. **期限は 2026-12-11（金）18:00。** この時点で文書の「可」がなければ、差し替えに進む。差し替えデータで案が成り立たなければ、本案は出さない。ODPT の候補は既存の app（生活アクセス診断マップ）と app-teiji に戻る。

## 理由
- **SOP**: 最新の audit（odpt-2026-kodure-20261114）に失格級が残っている。B1 は候補、B2 は本人欄。提出物（contests/odpt-2026/）を含む PR なので、マージの条件を満たさない。憲兵は「マージを止める理由は憲兵側にない」と書いているが、マージするかどうかは補佐の SOP で決める。#18 と #21 も、失格級（候補を含む）が残る間はマージしていない。同じ基準を当てる。
- **#18 の方針との整合**: 「確認が取れるまでは、これ以上公開を広げない。既定ブランチへのマージをしない」。既定ブランチは公開リポジトリの入口なので、マージは公開を広げることになる。
- **失格しないこと（最優先）**: 旧規約第1条は「非商用」を「非商用目的のみでの利用（ただし複製物の再配布を除く）」と定めている（情報部 1-2。確定事項）。公開アプリが名称・座標の JSON を配る形は、再配布やデータベースとしての利用に当たる可能性が高い（情報部の推測）。要項に第三者データの条件を守れという明文はない。それでも、権利の侵害が疑われる作品を出せば、審査やヒアリングで突かれ、失格の判断を受けるおそれがある。
- **公開ブランチからデータを外すのは、#18 と違う判断になる**:
  - #18 の認定情報は、利用ルールに再配布の禁止がなかった。国自身が個別設備まで公表しているので、集計しても新しく出る情報はほとんどない。だから消さなかった。
  - P13・P27 は違う。規約自体が「複製物の再配布」を許される範囲から外している。公開ブランチに JSON を置くこと自体が、再配布に当たりうる。履歴には残るが、先頭から外せば普通に見られる経路（ブランチの閲覧、raw の URL）は減る。これは PACE の「変更を戻す」側に当たる。
  - ページの削除ではない。画面・ページ・タブは残し、行き先データだけを外す。画面には「許諾確認中のため同梱していない」と出す。
- **締切との関係**: ODPT の締切は 2027-01-11 23:59。他の戦域は 11/15（UDC）、11/30（衛星・イチBiz ビジネス部門）、12/10（イチBiz アイデア・不動産部門）が近い。そこで、問い合わせの期限を 12/11 にした。その後の約4週間で、差し替えと再監査をする。
