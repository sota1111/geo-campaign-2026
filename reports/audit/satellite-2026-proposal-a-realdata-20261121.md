## 減点級
### 減点-1: OSM（ODbL）由来データの再配布条件の表示が不足
- 根拠: README「OSM … ODbL。クレジット、同一ライセンスでの配布」（recon §3）。
- 内容: data/toyonaka.json は OSM の道路形状・way ID・名称を含み、道路区間を抽出・加工したデータベース（ODbL 上の派生データベースに当たる可能性が高い）。リポジトリで共有・公開する場合は ODbL での提供と明示が要るが、json の note・README・モーダルのいずれにも「このデータは ODbL で提供」「openstreetmap.org/copyright へのリンク」が無い（クレジットと「ODbL」の語のみ）。
- 影響: 公開しなければ応募上の問題にはならない。公開前に直す。修正は工兵。

### 減点-2: 地図上の帰属表示がスマホ幅で折りたたまれる
- 根拠: app.js の AttributionControl（compact: true）。
- 内容: 狭い画面では帰属が「i」ボタンに畳まれ、初期表示では出ない。出典モーダル（ボタン1回）と衛星の折りたたみ注記には全文があるので、条文違反とまでは言えないが、地理院・OSM・豊中市のクレジットが初期画面で見えないことは、利用規約の「出典の明示」を厳格に読むと弱い。compact を外すか、パネル内に一行の常設表示を置くとよい。

## 軽微
1. README の突き合わせの記述が読みにくい: 「紐づかない 187」とあるが、88.2% から計算すると紐づかないのは 3,418−3,016＝402 区間（生活道路 187＋幹線 215）。コードと件数の足し算（998＋2,233−215＝3,016）は整合する。モーダルも「紐づかない区間は台帳なしとして点数の対象外」とあるが、地図の「台帳なし」は生活道路の 187 のみ（幹線は「調査済み・架空」に入る）。誤解を避けるため 402 の内訳を書くとよい。
2. 画素の比率の出所: README の「0〜+3.75 が約91%、+3.75〜7.5 が 2.6%」と、偵察の試験（93.7%、0.3%）は範囲が違うため数値が違う。範囲の違いは README に書いてあるが、偵察側の値との差は説明がない。いずれも build_data.py の統計から出た値で、根拠のない数値ではない。
3. 「通し確認で衛星の重みが 20% に下がった」は、乱数（seed 20261121）の架空結果に対する値で、README に「架空の結果に対する値」とある。これは較正の仕組みを見せる数字にとどまる。sim_cavity が台帳の古さと衛星階級から確率を作っている（build_data.py 220行）ため、AUC は構造的に高く出る。画面に「実際の精度・効果ではない」旨が入っているので許容。
4. vendor/ の MapLibre（BSD-3-Clause）のライセンス全文の同梱を確認できていない（バンドルの先頭コメントに含まれていれば足りる）。公開前に確認。
5. 選んだ地区の経緯（豊中市周辺で階級が複数に分かれて見えた所を選んだ）は README・モーダルに開示済み。恣意的選択ではなく開示されているため問題なしだが、この点は審査員の質問で出やすい。
