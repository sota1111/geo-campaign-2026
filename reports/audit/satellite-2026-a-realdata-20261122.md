## 軽微
1. 前回の減点-1（ODbL の提供表示）は解消: About.tsx、app.js のモーダル、README、toyonaka.json の note に「Open Database License（ODbL）で提供」と openstreetmap.org/copyright へのリンクがある。
2. 説明用デモ用の見本 CSV（data/format_sample_by_point.csv など）は、実在の緯度経度の点に「あり」を入れた書式見本。画面・README に「調査結果ではない」とあるが、ファイルそのものには注記が無い（1行目は見出しのみ）。ダウンロードされて一人歩きすると、豊中市に空洞があるように読める。ファイル名に sample を含み、画面で「仮の値」と書いているため許容。ファイル内にコメント行を入れられない形式なら、ファイル名を format_sample_NOT_RESULT_… などにするとさらに安全。
3. 「検証」タブの「偶然だけでは出にくい差ですが、原因を示すものではありません」は、1年度・38件・町ごとに 0〜3 件の集計に対して、順列検定の p 値（0.2%／0.6%）を並べている。複数の指標を見ており、多重比較の補正はしていない。限界は同じ画面に書かれており、因果・精度は言っていないので許容。強調を弱めるなら「ばらつきの範囲を超える傾向」程度に。
4. README の「情報部の報告にある『20%』は 14.9% の誤りとみられる」は、reports/intel 側の表（下水道 1,289「20%」、政令市「25%」、特別区「52%」）が同じ誤りを含むことを意味する。アプリは正しい値（14.9%、21.6%、48.1%）を使っている。情報部の報告の訂正は情報部の作業で、アプリの問題ではない。この食い違いのまま、情報部の値を他の資料に流用しないこと。
5. 検証タブ・About の「要確認」の語は、審査員向けの画面にそのまま出る。内部の状態表示としては正直だが、デモを添付・公開するなら、確認が終わった後で文言を整える必要がある。
