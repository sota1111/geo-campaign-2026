# 統合ダッシュボード 初見利用評価

## 1. 総評
4つのアプリを見つけ、19目標を達成した（徳島駅の例と架空の聞き取り記録で試行）。
主な迷いは、例の回答と本人入力の区別、手順完了条件、人口の分母・候補順位の解釈だった。
1280×765のヘッドレスChromeをCDPで操作し、12枚の画像を見て判断。PDF・GeoJSON・CSVの保存操作を行った。

## 3. 迷った点・不明点
所要時間は失った時間の概算で、ツール待機・報告作成時間を除く。

### 目的7：相談前の1枚シート

1. **中／約25秒**。場所：トップ中央と左メニュー（01）。しようとしたこと：土地相談の入口を探す。
   不明点：中央は提出不可・締切・総司令官の情報が中心で利用者の入口が分かりにくい。対処：左の土地所有者向けを読んで選んだ。改善案：中央にも使用目的から選ぶ入口を置く。

2. **中／約30秒**。場所：例ボタン→手順4（02・03）。しようとしたこと：土地の条件を確認する。
   不明点：例を押すだけで手順2が完了し、未入力なのに建物あり・登記まだが「あなたの回答」と出た。対処：シートの「例・架空」を読み直した。改善案：「例の回答による」と表示する。

3. **中／約15秒**。場所：左手順バー（03）。しようとしたこと：手順3を開く。
   不明点：完了に伴い段の高さが変わり、前の位置を押して手順4に入った。対処：手順名を読み直して選び直した。改善案：各段の高さを固定する。

4. **低／約10秒**。場所：手順5（04）。しようとしたこと：印刷する。
   不明点：印刷より先に料金・運用構想が大きく表示される。対処：構想欄の下の印刷ボタンを押した。改善案：印刷を上部に置き構想は折りたたむ。

### 目的10：住む場所の先行き

1. **中／約25秒**。場所：埋め込み内のスクロール（05〜08）。しようとしたこと：結果を順に読む。
   不明点：前のアプリとスクロール範囲が異なり、結果の先頭を飛ばした。対処：上下に戻し区域・人口・校区を探した。改善案：固定の節ナビゲーションを置く。

2. **中／約20秒**。場所：計画と人口の並列欄（08）。しようとしたこと：将来も住みやすいか考える。
   不明点：区域内で人口減という表示を区域の効果や居住可否と結びつけかけた。対処：因果関係を示さない注記と市への質問を読んだ。改善案：因果を示さない説明を見出し付近にも置く。

3. **低／約10秒**。場所：XKT003などのラベル（06〜08）。しようとしたこと：情報を理解する。
   不明点：コードの意味が初見で分からず目に入る。対処：本文・注記を優先した。改善案：コードは出典詳細へ移すか説明を付ける。

### 目的6：地名の記憶マップ

1. **中／約35秒**。場所：手順3の写真と進捗（10・11）。しようとしたこと：写真を見比べて次に進む。
   不明点：見比べても手順3が未完了。どう完了を伝えるか分からない。対処：写真を確認して手順4へ進んだ。書き出し後も未完了表示が残った。改善案：「比較を終えた」ボタンを置き完了条件を具体化する。

2. **中／約25秒**。場所：手順5の確認済み操作。しようとしたこと：公開用ファイルを出す。
   不明点：裏づけのない架空の話を確認済みにしてよいか迷った。対処：自分が確認役を兼ねるデモの説明を読み、架空記録だけを確認済み・公開にした。改善案：出典の所在確認と内容の検証を区別し、架空の練習を明示する。

3. **低／約10秒**。場所：保存直後の入力欄。しようとしたこと：保存を確認する。
   不明点：欄が空に戻るので内容が消えたように感じる。対処：保存メッセージと地図の？マークを確認した。改善案：保存後の記録カードを表示する。

### 目的11：夜も使えるAED診断マップ

1. **中／約25秒**。場所：診断の圏外率。しようとしたこと：町田市の圏外人口を答える。
   不明点：主数値96%は市全体でなく市境800m以内を除いた人口。98%とどちらを使うか迷った。対処：分母と注記を読み、内側と全体を分けた。改善案：見出しに「市境付近を除く」を入れる。

2. **中／約15秒**。場所：診断の11台（2か所）。しようとしたこと：利用できるAED数を読む。
   不明点：11か所と読みかけた。対処：台数と地点数を併記した。改善案：台数と地点数を別指標で表示する。

3. **中／約25秒**。場所：候補・出力の一覧（12）。しようとしたこと：増設候補を比較する。
   不明点：各行が独立した1台設置の比較かと思ったが、1台ずつ圏を埋める順次選定だった。対処：説明を読み、任意地点4,000人と候補1位12,700人を区別した。改善案：各行に前の候補を設置後の追加人数と明示する。

4. **低／約15秒**。場所：候補・出力のCSV。しようとしたこと：任意地点の試算を保存する。
   不明点：押した任意地点がCSVに入るか確信できない。対処：候補と全時間帯を出し、任意地点の収録は未検証とした。改善案：選択地点専用の書き出しを置く。

## 4. 不具合（再現手順）

- 地名の記憶マップ：手順3の完了表示が観察行為と一致しない。再現：ぬま田を選ぶ→手順3の昔と今の写真を見比べる→手順4で保存→確認済み・公開→書き出す。写真を見たのに手順3が未完了のまま（10・11）。観察のみを検出できない仕様の可能性があり、機能故障とは断定しない。

ほかに明確な機能故障は確認しなかった。土地シートは手順5を開いた時点で5/5完了となったが、「開けば完了、印刷は任意」と明記されているので仕様と理解した。読了や内容確認を保証する進捗ではない。

## 5. 確認できなかった範囲

- 徳島駅付近以外の住所検索、境界の判定、実在の相続土地の本人入力。
- 実在する聞き取り、第三者の確認、外部への掲載。架空サンプル1件のみ使用した。写真の個別撮影年や地名との因果も確定していない。
- AEDの現地利用可否、道路経路・坂・横断、隣接市・未登録民間AED、祝日、設置可否。任意地点の座標は控えていないが12の地図のピンが位置を示す。
- ダウンロードファイルの存在は確認したが、GeoJSON・CSVの内容完全性・再読込・他ソフト利用、任意地点がCSVに入るかは未検証。
- 対話式印刷ダイアログでのPDF保存、PDFのページ数・紙面品質は未確認。アプリのボタン操作とCDPによるPDFファイル保存まで実施。
- 画面の出典データを外部資料と照合していない。ソース・README・禁止フォルダのファイルは読んでいない。トップの画面テキスト取得に下方の既存評価も含まれたが、今回の判定には用いていない。
- 操作に使ったChromeだけを終了し、プロファイルを削除。ダッシュボードのサーバーは停止・再起動していない。

補足：memory-comparison.txtは後で画面を再訪した際の「先に地名を選んでください」という表示で、初回の突き合わせ結果の証拠には用いていない。
