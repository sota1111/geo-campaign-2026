# 統合ダッシュボード: 各アプリの使用目的と目標の成果（2026-11-11 参謀長）

試験では、被験者（Sonnet）に「使用目的」だけを伝え、使い方・画面構成・目標の項目は伝えない。
評価者（参謀長）は被験者の報告を「目標の成果」と照合し、全項目が達成されるまで改修と再試験を繰り返す。
開始地点は常にダッシュボードのトップ。被験者は自分で該当アプリを探す。

達成の判定: 各項目について、被験者が**正しい答えを自力で得た**（報告の値が画面の事実と一致）＝達成。誤読・未到達・推測＝未達。
加えて全アプリ共通で、(C1) 架空データ／実データの区別を被験者が正しく理解している、(C2) 被験者が「迷って先へ進めなかった」箇所がない、を満たすこと。

## 試験の手順
1. 被験者ごとに新しいタブで、ダッシュボードのトップを開かせる。
2. 伝えるのは上の「使用目的」だけ。ソース・READMEの閲覧は禁止。
3. 報告: 得た答え（値）、操作の経過、迷った箇所、達成できなかったこと。
4. 参謀長が目標の成果と照合し、未達の原因を改修に回す。全項目が達成されるまで繰り返す。
