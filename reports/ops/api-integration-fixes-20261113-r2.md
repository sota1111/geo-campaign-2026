# 工兵: デザイン再審査 r2 の指摘への対応（PR #9）　2026-11-13

- 対象: ブランチ claude/engineer-api-integration-20261112 の worktree。指摘元は reports/design/api-integration-20261113-r2.md
- 結果: 中3件（A・B・C）と軽微4件をすべて直した。検査はすべて通過した（下記）。
- 外部への通信:
  - 中A・中Bは、国土地理院の地名検索（msearch.gsi.go.jp）への要求を CDP の Fetch で止め、応答しないまま保留して確かめた。要求は外部に出ていない。
  - 不動産の印刷は、e2e-check.mjs の既存の差し替え（地名検索・逆ジオコーダ）を使った。それ以外の地図タイル等は通常どおり読み込んだ。

## 指摘ごとの対応

### 中A（ダッシュボード版 doSearch）: 地名検索が応答しないと、範囲内の駅でも「診断範囲外」と出る
ファイル: contests/dashboard/src/apps/odpt/index.tsx、lib.ts

1. 停留所名から探した候補にも `inCell`（`cellIdx[meshCodeAt(lon, lat)] != null`）を付けた。あわせて、診断できる停留所を先に並べる。
2. 停留所名に切り替えた時は、次の案内を出す。
   - 「住所検索が応答しないため、停留所名から探しました（「王子駅前」を選びました）。違う場合は下の候補から選ぶか、地図をタップしてください。」
   - 地名検索は応答したが0件だった時は、冒頭が「住所検索で見つからなかったため」になる。
   - 選んだ停留所が診断範囲外だった時は「…停留所名から探しましたが、「…」は診断範囲外でした。地図をタップして場所を選んでください。」と出る。
3. 住所らしい入力では、停留所名の部分一致を並べない。判定は `looksLikeAddress()` で、数字（全角を含む）・「丁目」・「番地」を含むものを住所とみなす。
   - この場合、地名検索が時間切れなら「住所検索が応答しません…地図をタップして場所を選んでください。」と出る。
4. 「該当する場所が見つかりませんでした」の文にも「地図をタップして場所を選ぶこともできます」を足した。

### 中B（単体版 app.js）: 地名検索が応答しないと「検索中…」のまま止まる
ファイル: contests/odpt-2026/app/web/app.js、lib.js

- fetch を8秒で打ち切る（AbortController）。AbortController の無い古いブラウザでも止まらないよう、Promise.race で時間切れの保険も掛けた。
- 結果の表示を `showSearch()` に分け、中Aと同じ考え方を最初から入れた。
  - 地名検索で見つからない時は、停留所名から探す。候補に inCell を付け、診断できるものを先にする。
  - 切り替えた旨と「地図をタップ」の案内を出す。
  - 住所らしい入力では、停留所名の部分一致を並べない。
  - 時間切れ・接続失敗の時は「地図をタップ」の案内を出す。
- 範囲内だが診断範囲外の候補には「（診断範囲外）」を付けた。
- 検索を続けて押した時は、古い応答で表示を上書きしない（searchReq）。
- `searchStops` と `looksLikeAddress` を lib.js に足し、lib_test.js で検査した。

### 中C（不動産・印刷）: 最長ケースで本文が印刷範囲の下端まで埋まる → A案で詰めた
ファイル: contests/dashboard/src/apps/biz-realestate/index.tsx、e2e-check.mjs

- 「データにない項目」と「ライブラリで確認する項目」を1つの枠にまとめた（data-testid=check-items）。
  - 画面は従来どおり2段の箇条書き。
  - 印刷は全幅で、各項目を見出しに続けて「／」区切りで並べる（各1〜2行）。
- 用語の説明: 印刷で、見出しのあとに用語を続けて書くようにした（見出しだけの1行をなくした）。
  - 表示する用語は、もともとシートに出た用語だけ（glossaryFor にシートの本文を渡す方式）だった。今回、その範囲は変えていない。
- この土地の条件: 「洪水（想定最大規模）」の項目名が折り返して行が増えていた。印刷では項目名を折り返さず、必要な時だけ幅を広げる。
- 1枚シートの枠: 共通部品 Card の `gap-6`（約18pt）が印刷でも効いていた。印刷のときだけ `gap-1` にした。共通部品は変えていない。
- 記号の見かた（印刷だけ）の短縮:
  - 「＝不動産情報ライブラリのAPIから取得」→「＝ライブラリのAPIから取得」。正式名は規約の段落に残る。
  - 「＝一般的な確認のみ」→「＝一般的な確認」。
  - 項目の間隔を gap-x-3 から gap-x-2 にした。
- 残したもの:
  - 文字の大きさ（6.5〜9pt）は変えていない。
  - 「ライブラリ由来」の印、「この土地の価格ではない」「個別の物件の価格ではない」は残した。
  - 規約の段落（break-inside-avoid）は分割されない。
- e2e-check.mjs に余白の検査を足した。
  - 方法: 各ケースのPDFの1ページ目を `pdftotext -bbox` で読み、いちばん下の文字の下端を求める。
  - 基準: 印刷範囲の下端（842pt − @page の余白 6mm ≒ 825pt）から 40pt 以上離れていること。
  - 対象は既存の6ケースで、八万町・4問回答を含む。どれか1つでも満たさなければ NG にする。
