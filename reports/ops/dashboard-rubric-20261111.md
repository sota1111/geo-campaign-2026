# 統合ダッシュボード 評価基準（2026-11-11 参謀長）

評価者（Sonnet）は、統合ダッシュボードのトップ（ポータル）から出発し、ポータル → 担当コンペの各アプリの順に、実際に画面を操作して採点する。
ソースコード・README・reports/ は読まない（画面だけで判断する。審査員も画面しか見ない）。

各項目は **0〜5点**。点には必ず画面上の根拠（見た文言・操作の結果・スクリーンショット）を1つ以上付ける。根拠がない点は付けない。
- 5: 審査員・初見の利用者が迷わず、強みとして評価する水準
- 4: 小さな難点はあるが、目的は問題なく果たせる
- 3: 目的は果たせるが、明らかな改善点がある
- 2: 目的を果たすのに苦労する／誤解のおそれがある
- 1: 目的をほとんど果たせない
- 0: 機能しない・該当する表示がない

## A. ポータル（統合ページ）— 全評価者が採点（25点）
| # | 観点 | 見るところ |
|---|---|---|
| A1 | コンペの理解しやすさ | 4コンペそれぞれの趣旨・募集内容が、ポータルだけで一読して分かるか |
| A2 | 審査基準の明確さ | 各コンペの審査基準が正確・簡潔に示され、「確定」と「未確認・例示」の区別がつくか |
| A3 | 締切・提出物・注意点 | 締切（残り日数）、提出物、失格につながる条件が見落とせない形で示されているか |
| A4 | アプリへの導線 | コンペ ↔ アプリの対応が分かり、目的のアプリへ迷わず進めて戻れるか |
| A5 | 情報設計と視覚階層 | 情報量に対して画面が整理されているか（無駄なスクロール、重複表示、詰め込みすぎがないか） |

## B. 各アプリの操作性・デザイン（共通、1アプリ35点）
| # | 観点 | 見るところ |
|---|---|---|
| B1 | 目的の伝わりやすさ | 開いて5秒で「誰が何のために使うか」が分かるか |
| B2 | 操作の導線 | 手順に沿って最後の成果（書き出し・コピー・保存・印刷など）まで迷わず到達できるか。行き止まりがないか |
| B3 | 視覚階層・一貫性 | 主操作が目立つか、ポータル・他アプリと見た目や用語がそろっているか |
| B4 | フィードバック | 操作の結果（済・保存・コピー・エラー）がはっきり返るか |
| B5 | 無駄の少なさ | 不要なスクロール、同じ機能の重複、意味の分からない表示がないか |
| B6 | アクセシビリティ | 色だけに頼らない表示、文字の読みやすさ（コントラスト）、キーボード（Tab/Enter）で主要操作ができるか |
| B7 | データの誠実さ | 実データ／架空データの区別、出典、限界（未接続・推定）が画面で正しく伝わるか |

可能ならスマホ幅（約390px）でもポータルと1アプリを確認し、B3・B5 の根拠に加える。

## C. コンペの審査基準による評価（アプリが属するコンペの基準で採点）
審査員になったつもりで、そのアプリ（＝応募作品のデモ）が各基準でどう評価されるかを採点する。
ポータルに書かれた審査基準を読んだうえで採点すること（ポータルの説明と食い違う場合は、その点も報告する）。

### ODPT（公共交通オープンデータチャレンジ2026）— 生活アクセス診断マップ
C-ODPT1 社会課題解決への寄与／C-ODPT2 オープンデータ活用のインパクト（公共交通オープンデータの使い方が作品の核になっているか）／C-ODPT3 技術的完成度（実際に動くか、不具合・遅さ）／C-ODPT4 UI/UXの完成度

### UDC（アーバンデータチャレンジ2026）— 生活アクセス診断マップ（作品①として）・みんなの盛土ウォッチ（作品②）
C-UDC1 実用度（地域課題と手法・価値が合っているか）／C-UDC2 完成度（実装の程度・仕上がり）／C-UDC3 挑戦度（新規性、広がり、持続性、関係者の多様性）
※ 作品①と②が「同一・類似作品」に見えないか（差別化）も一言で評価する。

### 衛星データ活用アワード2026–2027 — 路面下リスクの二段階調査（提案A）・盛土巡視台帳（提案B）
C-SAT1 募集テーマ合致性（衛星×地中でインフラリスクの可視化、またはインフラ管理・防災）／C-SAT2 事業スコープ・衛星データ活用の妥当性（衛星データの重要性が高いか）／C-SAT3 事業の実現性・収益性（顧客・付加価値・差別化が画面から想像できるか）／C-SAT4 事業化による社会発展性（拡張性・社会インパクト）／C-SAT5 システム開発の進捗（加点項目。デモの完成度）

### イチBizアワード2026 — バス路線見直し案の比較（ビジネス）・地名の記憶マップ（アイデア）・相談前の1枚シート（不動産）
C-BIZ1 独創性／C-BIZ2 社会的インパクト／C-BIZ3 実現可能性／C-BIZ4 持続性（継続できる仕組み・収益性。特にビジネス部門）
※ 不動産情報活用部門は「不動産情報ライブラリ」の情報の活用が画面で分かるかも一言で評価する。

## 報告の書式（評価者ごとに1ファイル）
1. 総評（3行以内）
2. A・B・C の点数表（項目・点・根拠）。小計と、満点に対する割合
3. 改善提案（優先度 高／中／低、各1〜2行。どの画面のどこをどう直すか）
4. 迷った箇所・不具合（再現手順つき）
5. ポータルの記載とアプリの内容の食い違い（あれば）
