# 報告と判断ログの書式

報告は2層で残す。
- **詳細**: 各部隊が reports/<部隊>/ に書くファイル（記録として残る）
- **要約**: 参謀長が PR 本文に書くもの（総司令官が最初に読む。`.github/pull_request_template.md` の書式）

どちらも次の順で書く（各エージェント定義の報告形式がこれを具体化している）。

1. **結論**: 1〜3行
2. **成果物**: 作成・変更したファイル
3. **検査結果**: テスト、check_limits.py、チェックリスト
4. **未解決・要確認**
5. **判断ログ**: 指示にない判断をした箇所、その理由、取らなかった選択肢

## エスカレーション（reports/escalations/<YYYYMMDD>-<topic>.md）
```
発生部隊:
戦域（contest-id）:
状況:
止めた理由（どの交戦規定・意図に関わるか）:
総司令官に決めてほしいこと:
選択肢と各々の影響:
```
判断ログは振り返り（AAR）で読み、繰り返す失敗は各エージェントの SOP に追記する。
